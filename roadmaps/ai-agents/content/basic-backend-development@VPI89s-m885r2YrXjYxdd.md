# Desenvolvimento Básico de Backend

Antes de começar a aprender como construir agentes AI, recomendamos que você tenha um conhecimento básico de desenvolvimento backend. Isso inclui conhecimento de linguagens de programação, interação com banco de dados e os fundamentos das APIs.

Visite os seguintes recursos para saber mais:

- [@artigo@Introdução ao lado do servidor](https://developer.mozilla.org/pt-BR/docs/Aprender/Servidor-side/Primeiros_passos/Introdução)
- [@artigo@O que é uma API REST? - Red Hat](https://www.redhat.com/pt-br/topics/api/o-que-e-uma-api-rest)
- [@artigo@O que é um Banco de Dados? - Oracle](https://www.oracle.com/database/what-is-database/)
