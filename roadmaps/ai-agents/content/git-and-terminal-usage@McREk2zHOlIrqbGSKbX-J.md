# Uso de Git e Terminal

Git e o terminal são ferramentas essenciais para agentes de IA e desenvolvedores. O Git permite que você rastreie alterações no código, trabalhe com branches e colabore de forma segura com outros. Ele armazena instantâneos do seu trabalho para que você possa desfazer erros ou mesclar ideias. O terminal (linha de comando) permite que você navegue em arquivos, execute programas, configure servidores e controle ferramentas como o Git rapidamente sem uma interface gráfica.

Acesse os seguintes recursos para saber mais:

- [@oficial@Básico do Git](https://git-scm.com/doc)
- [@oficial@Introdução ao Terminal](https://ubuntu.com/tutorials/command-line-for-beginners#1-overview)
