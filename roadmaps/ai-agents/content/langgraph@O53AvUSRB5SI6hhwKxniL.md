# LangGraph

LangGraph é uma biblioteca Python projetada para ajudar os desenvolvedores a criar aplicativos de IA conversacional robustos e com estado, frequentemente chamados de Agentes AI. Ele permite que você estruture fluxos complexos de agentes definindo estados (dados mantidos durante toda a conversa) e arestas (transições entre estados baseadas em decisões do agente ou eventos externos), criando uma representação gráfica do processo de raciocínio do agente. Isso torna mais fácil gerenciar o fluxo das conversas e construir agentes AI mais confiáveis e explicáveis.
