# Codificação

A codificação é uma habilidade fundamental para cientistas de dados. Você precisa ser capaz de escrever código para manipular dados, construir modelos e implantar soluções. As linguagens de programação mais comuns usadas em ciência de dados são Python e R. O Python é uma linguagem de programação geral que é fácil de aprender e tem um grande número de bibliotecas para manipulação de dados e aprendizado de máquina. O R é um ambiente de software livre para cálculos estatísticos e gráficos. Ele é amplamente usado para análise estatística e visualização de dados.

Acesse os seguintes recursos para saber mais:

- [@oficial@O Tutorial do Python](https://docs.python.org/3/tutorial/)
- [@oficial@Manuals do R (CRAN)](https://cran.r-project.org/manuals.html)
- [@curso@Python para Ciência de Dados, Inteligência Artificial e Desenvolvimento](https://www.coursera.org/learn/python-for-applied-data-science-ai)
- [@curso@Kaggle Learn: Python](https://www.kaggle.com/learn/python)
- [@artigo@Introdução à Ciência de Dados com Python (Harvard)](https://pll.harvard.edu/course/introduction-data-science-python)
