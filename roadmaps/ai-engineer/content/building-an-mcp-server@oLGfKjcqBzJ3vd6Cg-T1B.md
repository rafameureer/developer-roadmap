# Construindo um Servidor MCP

Um servidor MCP (Model Context Protocol) atua como intermediário entre agentes de IA e várias fontes de dados ou ferramentas. Ele fornece uma maneira padrão para que os agentes acessem e interajam com informações externas, permitindo-lhes realizar tarefas que requerem contexto além do conhecimento interno dos agentes. Construir um servidor MCP envolve definir os endpoints da API, lidar com solicitações dos agentes, recuperar dados de fontes relevantes e formatar as respostas de uma maneira que os agentes possam entender.
