# Contexto vs Engenharia de Prompt
 
A engenharia de prompt se concentra em como uma única instrução é formulada para obter uma resposta melhor do modelo. A engenharia de contexto é mais amplo: ela lida com toda a informação que chega ao modelo, de onde vem, na ordem e no formato, em um aplicativo ou fluxo de trabalho de agente inteiro. Um bom prompt escrito ainda pode falhar se o modelo não tiver os dados, ferramentas ou histórico certos para agir sobre ele. A engenharia de contexto trata o prompt como apenas uma parte de um sistema maior que também inclui a recuperação, memória e saídas de ferramentas.
