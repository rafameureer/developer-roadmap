# Embedding do Gemini

A API do Gemini oferece métodos para converter texto, imagens ou outros tipos de dados em representações vetoriais numéricas chamadas embeddings. Esses embeddings capturam o significado semântico e as relações entre diferentes pedaços de informações, permitindo uma busca eficiente de similaridade, agrupamento e outras tarefas de aprendizado de máquina. Esses modelos proprietários são oferecidos como um serviço, geralmente através de uma API, e exigem pagamento ou assinatura.
