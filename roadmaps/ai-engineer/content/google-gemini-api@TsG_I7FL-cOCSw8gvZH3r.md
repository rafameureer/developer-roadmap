# API do Google Gemini

A API do Google Gemini oferece aos desenvolvedores acesso programático ao conjunto de modelos AI multimodal da família Gemini da Google. Ela permite que as aplicações entenda e gere conteúdo em texto, imagens, áudio e vídeo. Os desenvolvedores podem usar esta API para construir funcionalidades como interfaces conversacionais, ferramentas de criação de conteúdo e sistemas que possam analisar e responder a dados multi-sensoriais complexos.
