# LLMs

Um LLM (Large Language Model) é um IA treinada em grandes conjuntos de dados de texto para entender e gerar linguagem semelhante ao humana através da previsão do próximo token. Embora ele manipule nativamente tarefas como tradução, resumo e escrita, capacidades como navegação na web ou execução de código vêm de camadas de software envolventes ao redor do modelo. Apesar de ser extremamente versátil, os LLMs requerem uma enorme quantidade de poder computacional e podem refletir viéses presentes em seus dados de treinamento.
