# Llama Index

LlamaIndex, anteriormente conhecido como GPT Index, é uma ferramenta projetada para facilitar a integração de grandes modelos linguísticos (LLMs) com fontes de dados estruturadas e não estruturadas. Ele atua como um quadro de dados que ajuda os desenvolvedores a construir aplicativos de geração-augmentada por recuperção (RAG) indexando vários tipos de dados, como documentos, bancos de dados e APIs, permitindo que os LLMs consultem e recupere informações relevantes eficientemente.
