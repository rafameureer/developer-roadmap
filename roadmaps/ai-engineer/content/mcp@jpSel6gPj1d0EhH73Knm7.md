# MCP

O MCP, ou Protocolo de Contexto do Modelo, é um padrão aberto que permite que aplicativos de IA se conectem a ferramentas externas, fontes de dados e serviços de uma maneira consistente. Em vez de escrever uma integração personalizada para cada ferramenta que um modelo possa precisar, os desenvolvedores expõem essa ferramenta através de um servidor MCP, e qualquer cliente compatível com MCP pode então chamá-la. Isso reduz o número de integrações ad-hoc necessárias conforme os agentes se conectam a mais sistemas. O Anthropic introduziu o MCP, e ele foi adotado por outros provedores de modelos e construtores de ferramentas.
