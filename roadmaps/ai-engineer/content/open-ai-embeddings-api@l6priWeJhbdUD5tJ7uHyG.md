# API de Embeddings do OpenAI

A API de Embeddings do OpenAI oferece uma maneira simples de transformar texto em representações vetoriais numéricas chamadas embeddings. Esses embeddings capturam o significado semântico do texto, permitindo que você execute tarefas como busca semântica, agrupamento e comparação de similaridade analisando as relações entre esses vetores. A API simplifica o processo de geração desses embeddings, abstrayendo as complexidades de treinamento e gerenciamento de modelos de embedding.

Acesse os seguintes recursos para saber mais:

- [@oficial@API de Embeddings do OpenAI](https://platform.openai.com/docs/api-reference/embeddings/create)
