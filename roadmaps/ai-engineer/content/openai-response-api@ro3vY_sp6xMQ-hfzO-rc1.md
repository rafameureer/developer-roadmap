# API de Respostas do OpenAI

A API de Respostas do OpenAI permite aos desenvolvedores interagir com vários modelos de IA oferecidos pela OpenAI. Ela fornece uma maneira estruturada de enviar solicitações a esses modelos e receber texto gerado, código ou outros tipos de saída. Você pode controlar aspectos como o prompt, temperatura, comprimento máximo e outros parâmetros para personalizar a resposta às suas necessidades específicas. Ela está planejada para eventualmente substituir a API Assistants e a API de Completions de Chat para novos projetos.
