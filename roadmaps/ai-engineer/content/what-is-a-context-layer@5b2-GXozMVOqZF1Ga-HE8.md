# O que é uma Camada de Contexto?

A camada de contexto é a parte de um sistema de IA responsável por coletar, organizar e entregar as informações corretas para um modelo antes de ele gerar uma resposta. Ela se encontra entre fontes de dados brutos, como bancos de dados, documentos e APIs, e o próprio modelo, decidindo o que será incluído e o que será excluído. Alguns times construem essa camada por conta própria usando pipelines de recuperação e armazenamentos de memória, enquanto outros dependem de plataformas de contexto dedicadas. O objetivo é fornecer ao modelo informações relevantes e confiáveis sem sobrecarregá-lo com tudo disponível.
