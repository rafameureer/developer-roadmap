# Codex

Codex é ideal para traduzir uma exigência claramente definida em código funcional. Descreva o comportamento específico que você deseja; ele gera a implementação. Funciona bem para adicionar uma nova função, reescrever um bloco mal estruturado ou converter lógica de um padrão para outro. Mantenha o escopo narrow; quanto mais específico for a entrada, mais útil será a saída.
