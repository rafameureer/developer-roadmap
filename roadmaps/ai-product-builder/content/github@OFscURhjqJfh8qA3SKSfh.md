# GitHub

O GitHub é a plataforma mais amplamente utilizada para hospedar e gerenciar código. Ele rastreia todas as alterações no repositório de código, torna fácil colaborar com outros e integra-se com a maioria dos ferramentas CI/CD. Configurar um repositório do GitHub deve ser uma das primeiras coisas que você faz após gerar o repositório de código.

Acesse os seguintes recursos para saber mais:

- [@roadmap@Visite o Caminho Dedidado Git & GitHub](https://roadmap.sh/git-github)
- [@oficial@Documentação do GitHub](https://docs.github.com/en/get-started/quickstart)
