# MongoDB / Atlas

O MongoDB é um banco de dados baseado em documentos que armazena dados em um formato flexível, semelhante ao JSON. O Atlas é o serviço de nuvem gerenciado do MongoDB, que lida com backups, escalonamento e monitoramento automaticamente. Ele é uma boa escolha para aplicativos onde a estrutura dos dados provavelmente mudará à medida que o produto evoluir.
