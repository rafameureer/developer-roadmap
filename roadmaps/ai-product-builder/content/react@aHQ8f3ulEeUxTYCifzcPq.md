# React

React é a biblioteca mais amplamente usada para construir interfaces web. A maioria dos front-ends gerados pelo AI usa React por padrão. Você precisará de uma compreensão básica de componentes, props e estado quando fizer alterações direcionadas à camada UI de uma aplicação gerada.

Acesse os seguintes recursos para saber mais:

- [@roadmap@Visite o Caminho do React dedicado](https://roadmap.sh/react)
- [@oficial@Documentação do React](https://react.dev/reference/react)
- [@vídeo@Curso Completo de Desenvolvedor Full Stack em React](https://www.youtube.com/watch?v=Bvwq_S0n2pk)
