# Proteção de APIs

Os membros da equipe Vermelha de IA testam rigorosamente a segurança das APIs que fornecem acesso aos modelos de IA. Eles investigam vulnerabilidades OWASP API Top 10 como autenticação/autorização quebrada, falhas de injeção, configurações de segurança incorretas e falta de limitação de taxa, especificamente avaliando como esses problemas podem levar à mal utilização ou comprometimento do próprio modelo de IA.

Acesse os seguintes recursos para saber mais:

- [@artigo@Protegendo APIs com IA para Proteção contra Ameaças Avançadas](https://adevait.com/artificial-intelligence/securing-apis-with-ai)
- [@artigo@Protegendo APIs de Aprendizado de Máquina (IBM)](https://developer.ibm.com/articles/se-securing-machine-learning-apis/)
- [@artigo@Projeto OWASP API Security (Top 10 2023)](https://owasp.org/www-project-api-security/)
