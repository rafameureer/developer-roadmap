# Testes de Segurança em LLMs

A área principal de aplicação para muitos membros da equipe Vermelha em IA hoje envolve especificamente testar Modelos de Linguagem Grande por vulnerabilidades como injeção de prompts, desarme, geração de conteúdo perigoso, viés e problemas de privacidade dos dados usando prompts especializados e quadros de avaliação.

Acesse os seguintes recursos para saber mais:

- [@course@Cursos de Equipes Vermelhas em IA - Aprenda a Prompting](https://learnprompting.org/blog/ai-red-teaming-courses)
- [@article@SecBench: Um Conjunto de Dados Multidimensional Compreensivo para Benchmarking de LLMs na Segurança Cibernética](https://arxiv.org/abs/2412.20787)
- [@article@O Guia Último sobre Equipes Vermelhas em LLMs e Prompts Adversários (Kili Technology)](https://kili-technology.com/large-language-models-llms/red-teaming-llms-and-adversarial-prompts)
