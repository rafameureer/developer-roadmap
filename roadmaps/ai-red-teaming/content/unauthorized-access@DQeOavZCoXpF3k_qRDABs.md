# Acesso Não Autorizado

As equipes vermelhas de IA testam se vulnerabilidades no sistema de IA ou em suas interfaces permitem que os atacantes ganhem acesso não autorizado a dados, funcionalidades ou infraestrutura subjacente. Isso inclui tentativas de escalonamento de privilégios via prompts, exploração de endpoints de API inseguros conectados ao AI ou manipulação do AI para acessar recursos de sistema restritos.
