# Atividade

Uma Activity representa uma única tela em um aplicativo Android com uma interface do usuário. Os aplicativos geralmente são compostos por várias atividades que os usuários navegam entre. As atividades têm um ciclo de vida gerenciado pelo sistema operacional, e lidar corretamente com esse ciclo de vida é essencial para construir aplicativos estáveis.

Acesse os seguintes recursos para saber mais:

- [@oficial@Activity do Android](https://developer.android.com/reference/android/app/Activity)
