# Apollo-Android

Apollo Android é um cliente GraphQL para Android e Kotlin que gera modelos de Kotlin seguros em tempo de compilação a partir de esquemas e arquivos de consulta GraphQL. Ele lida com a execução de consultas, caching e assinaturas, e integra-se com coroutines do Kotlin. Apollo-Android permite trabalhar com APIs GraphQL de uma maneira estruturada e segura em tempo de compilação.

Acesse os seguintes recursos para saber mais:

- [@official@Apollo Android](https://www.apollographql.com/docs/kotlin/v2/)
- [@official@Apollo Docs](https://www.apollographql.com/docs/kotlin/)
- [@opensource@apollographql/apollo-kotlin - GraphQL for Android](https://github.com/apollographql/apollo-kotlin)
