# Layout de Caixa

O layout de caixa permite organizar elementos da interface do usuário em uma única direção, seja vertical ou horizontal. É um método simples e eficaz para organizar exibições em linha ou coluna, fornecendo controle sobre como eles são empilhados e espaçados. Este layout é útil quando você deseja criar disposições lineares de componentes da interface do usuário em seu aplicativo Android.
