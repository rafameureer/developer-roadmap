# Column e Row em Compose

Column e Row são componentes de layout fundamentais no Jetpack Compose usados para organizar itens verticalmente (Column) ou horizontalmente (Row). Eles oferecem uma maneira simples e intuitiva de organizar elementos da interface do usuário empilhando-os em uma única direção, permitindo o controle sobre como os itens são alinhados e espaçados dentro do layout. Isso torna muito mais fácil a criação de interfaces de usuário responsivas e visualmente atraentes.
