# Coroutines

Asynchronous programming em Kotlin é um framework de concorrência que permite escrever código assíncrono de forma sequencial e legível. Eles são leves, suportam a concorrência estruturada e integram-se com o Android Jetpack através de CoroutineScopes conscientes da vida do ciclo. As coroutines substituíram padrões mais antigos como AsyncTask e agora são a abordagem preferida para trabalho assíncrono no Android.

Acesse os seguintes recursos para saber mais:

- [@official@Coroutines](https://kotlinlang.org/docs/coroutines-overview.html)
