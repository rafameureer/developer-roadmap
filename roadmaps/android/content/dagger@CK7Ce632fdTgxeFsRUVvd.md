# Dagger
 
Dagger é um framework de injeção de dependência em tempo de compilação para Java e Kotlin. Ele gera código de DI eficiente com base em anotações, evitando reflexão em tempo de execução. Dagger tem uma curva de aprendizado afiada, mas é amplamente utilizado em grandes códigos Android por sua performance e confiabilidade.

Acesse os seguintes recursos para saber mais:

- [@official@Dagger](https://dagger.dev/)
