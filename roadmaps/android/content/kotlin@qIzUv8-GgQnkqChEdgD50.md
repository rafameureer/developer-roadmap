# Kotlin
 
O Kotlin é um idioma de programação estáticamente tipado desenvolvido pela JetBrains e oficialmente apoiado pelo Google para o desenvolvimento Android. Ele roda na JVM e é totalmente interoperável com Java. O Kotlin possui uma sintaxe concisa, segurança contra nulos, coroutines para programação assíncrona e funções de extensão que reduzem boilerplate.
