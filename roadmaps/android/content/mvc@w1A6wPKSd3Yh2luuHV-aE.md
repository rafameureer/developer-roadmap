# MVC

MVC (Model-View-Controller) é um padrão arquitetônico que divide uma aplicação em três componentes: o Model armazena dados e lógica de negócios, a View renderiza a interface do usuário, e o Controller lida com a entrada do usuário. O Android não se mapeia claramente para o MVC tradicional, pois as Activities e Fragments geralmente atuam como tanto View quanto Controller simultaneamente.
