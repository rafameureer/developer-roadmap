# Retrofit

Retrofit é um cliente HTTP de tipo seguro para Android. Ele está projetado para conectar sua aplicação com uma API ou um serviço web de back-end. Retrofit usa anotações para codificar detalhes sobre as operações e solicitações da API, como o método HTTP (`GET`, `POST`, `PUT`, `DELETE`, `HEAD`) e os parâmetros de consulta. A principal vantagem do **Retrofit** em relação a outras bibliotecas semelhantes é sua simplicidade e intuitividade, e ele eficientemente lida com todas as chamadas de rede.
