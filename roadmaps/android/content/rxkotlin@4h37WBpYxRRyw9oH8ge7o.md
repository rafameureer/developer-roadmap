# RxKotlin
 
RxKotlin é uma biblioteca de extensão leve para Kotlin baseada em RxJava. Ele adiciona funções de extensão idiomáticas do Kotlin e utilitários estilo DSL para trabalhar com observáveis do RxJava. Desenvolvedores usam o RxKotlin para escrever código Kotlin mais natural quando construindo fluxos reativos no Android.
