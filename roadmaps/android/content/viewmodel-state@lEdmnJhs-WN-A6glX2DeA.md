# Estado do ViewModel

O estado do ViewModel se refere aos dados armazenados em uma classe ViewModel que persistem durante as alterações de configuração, como rotações de tela. Ele permite que seus dados da interface do usuário sobrevivam a essas alterações, evitando a necessidade de refetechar ou recriá-los toda vez que a atividade ou fragmento é reciclando. Esses dados são geralmente observados pela interface do usuário, que se atualiza automaticamente sempre que o estado muda, garantindo uma experiência de usuário consistente.
