# Animação

O sistema de animação do Angular é baseado na funcionalidade CSS, o que significa que você pode animar qualquer propriedade que o navegador considere animável. Isso inclui posições, tamanhos, transformações, cores, bordas e muito mais.

Acesse os seguintes recursos para saber mais:

- [@oficial@Animação](https://angular.dev/guide/animations)
- [@opensource@Explorador de Animações do Angular](https://github.com/williamjuan027/angular-animations-explorer)
- [@artigo@Animações do Angular - Um Guia Iniciante](https://www.angularminds.com/blog/angular-animations-a-beginners-guide)
- [@artigo@Guia em Profundidade sobre Animações no Angular](https://angularindepth.com/posts/1285/in-depth-guide-into-animations-in-angular)
