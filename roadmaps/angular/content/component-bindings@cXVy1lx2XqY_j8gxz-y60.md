# Testes de ligação de componentes

O Angular processa todas as ligações de dados uma única vez para cada ciclo de evento JavaScript, desde a raiz da árvore de componentes do aplicativo até todos os componentes filhos. A ligação de dados desempenha um papel importante na comunicação entre um modelo e seu componente, e também é importante para a comunicação entre componentes pai e filho.
