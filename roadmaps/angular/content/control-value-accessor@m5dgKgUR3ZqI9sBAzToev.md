# Control Value Accessor

Define uma interface que atua como um ponteiro entre a API de formulários do Angular e um elemento nativo no DOM. Implemente essa interface para criar uma diretiva de controle de formulário personalizada que integre-se com os formulários do Angular.

Acesse os seguintes recursos para saber mais:

- [@official@ControlValueAccessor](https://angular.dev/api/forms/ControlValueAccessor)

- [@article@Controles de Formulário Personalizados no Angular](https://blog.angular-university.io/angular-custom-form-controls/)
