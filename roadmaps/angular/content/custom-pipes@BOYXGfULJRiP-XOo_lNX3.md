# Pipelines Personalizados

Os pipelines são usados para transformar strings, quantias monetárias, datas e outros dados para exibição. Os pipelines são funções simples em expressões de modelo que aceitam um valor de entrada e retornam um valor transformado. Os pipelines são úteis porque você pode usá-los em todo o seu aplicativo declarando cada pipeline apenas uma vez. Por exemplo, você usaria um pipeline para mostrar a data como 15 de abril de 1988, em vez do formato de string bruto.
