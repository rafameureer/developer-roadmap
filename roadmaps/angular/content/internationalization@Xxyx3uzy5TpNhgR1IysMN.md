# Internacionalização

A internacionalização, às vezes referida como i18n, é o processo de projetar e preparar seu projeto para uso em diferentes locais ao redor do mundo. A localização é o processo de construir versões do seu projeto para diferentes locais.

Acesse os seguintes recursos para saber mais:

- [@oficial@Internacionalização](https://angular.dev/guide/i18n)
- [@opensource@Transloco](https://github.com/jsverse/transloco)
- [@opensource@Ngx Translate](https://github.com/ngx-translate/core)
- [@artigo@Angular i18n](https://lokalise.com/blog/angular-i18n/)
- [@vídeo@Suporte a Múltiplos Idiomas do Angular 18](https://www.youtube.com/watch?v=hIz0OglmT0Q)
