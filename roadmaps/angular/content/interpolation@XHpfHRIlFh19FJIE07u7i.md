# Interpolação

A interpolação refere-se a incorporar expressões em texto marcado. Por padrão, a interpolação usa as chaves duplas {{ e }} como delimitadores. O Angular substitui currentCustomer pelo valor de string da propriedade correspondente do componente.

Acesse os seguintes recursos para saber mais:

- [@oficial@Interpolação](https://angular.dev/guide/templates/interpolation)
- [@oficial@Exibindo valores com interpolação](https://angular.dev/guide/templates/interpolation)
