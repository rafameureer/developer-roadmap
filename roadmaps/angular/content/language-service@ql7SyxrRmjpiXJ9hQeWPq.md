# Serviço de Linguagem

O Serviço de Linguagem do Angular fornece aos editores de código uma maneira de obter conclusões, erros, dicas e navegação dentro dos modelos do Angular (externos e em linha). Cada vez que você abre um aplicativo Angular pela primeira vez, um prompt de instalação ocorrerá.

Acesse os seguintes recursos para saber mais:

- [@oficial@Documentação do Serviço de Linguagem](https://angular.dev/tools/language-service)
- [@opensource@VS Code NG Language Service](https://github.com/angular/vscode-ng-language-service)
