# Identificação de Links

Classes CSS aplicadas a elementos `RouterLink` ativos, como `RouterLinkActive`, fornecem um sinal visual para identificar o link ativo. Infelizmente, um sinal visual não ajuda usuários cegos ou com baixa visão. Aplicar o atributo `aria-current` ao elemento pode ajudar a identificar o link ativo.

Acesse os seguintes recursos para saber mais:

- [@official@Acessibilidade - Identificação de links ativos](https://angular.dev/best-practices/a11y#active-links-identification)
- [@article@ARIA Current](https://developer.mozilla.org/en-US/docs/Web/Accessibility/ARIA/Attributes/aria-current)
