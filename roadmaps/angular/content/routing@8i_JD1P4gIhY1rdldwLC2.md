# Navegação

Acompanhar e controlar o foco em uma interface do usuário é um consideração importante na design de acessibilidade. Quando usar roteamento no Angular, você deve decidir onde o foco da página vai após a navegação.

Acesse os seguintes recursos para saber mais:

- [@oficial@Acessibilidade - Roteador](https://angular.dev/best-practices/a11y#routing)
- [@artigo@Acessibilidade - Foco](https://web.dev/learn/accessibility/focus/)
- [@artigo@Eventos do Roteador no Angular](https://medium.com/@gurunadhpukkalla/router-events-in-angular-3112a3968660)
