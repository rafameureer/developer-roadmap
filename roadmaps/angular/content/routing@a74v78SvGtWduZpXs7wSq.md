# Roteamento

O roteamento no Angular permite aos usuários criar uma aplicação de página única com várias exibições e permitir a navegação entre elas.

Acesse os seguintes recursos para saber mais:

- [@oficial@Roteamento do Angular](https://angular.dev/guide/routing)
- [@oficial@Tarefas Comuns de Roteamento](https://angular.dev/guide/routing/common-router-tasks)
