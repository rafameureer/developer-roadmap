# Configurando um Novo Projeto

A configuração de um novo projeto Angular é simplificada pelo **Angular CLI**, uma interface de linha de comando que automatiza o setup inicial. Primeiro, certifique-se de ter Node.js e npm instalados, em seguida, instale globalmente o CLI via `npm install -g @angular/cli`. Com o CLI em place, navegue para o diretório desejado e inicie um novo projeto usando `ng new seu-nome-de-projeto`, onde você será solicitado a configurar opções como roteamento e formato de folha de estilo, com a bandeira `--standalone` sendo uma adição comum para projetos modernos. Uma vez que o projeto seja estruturado e as dependências instaladas, entre no novo diretório do seu projeto (`cd seu-nome-de-projeto`) e inicie o servidor de desenvolvimento com `ng serve`, tornando sua nova aplicação Angular acessível em seu navegador, geralmente em `http://localhost:4200/`.
