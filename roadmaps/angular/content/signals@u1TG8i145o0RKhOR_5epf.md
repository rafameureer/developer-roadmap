# Sinais

O Sistema de Sinais do Angular rastreia granularmente como e onde seu estado é usado em todo o aplicativo, permitindo que o framework otimize as atualizações de renderização.

Acesse os seguintes recursos para saber mais:

- [@oficial@Sinais](https://angular.dev/guide/signals)
- [@artigo@Guia Completo sobre Sinais do Angular](https://blog.angular-university.io/angular-signals/)
- [@vídeo@Desvendando os Sinais: O Guia Completo](https://www.youtube.com/watch?v=6W6gycuhiN0&t=169s)
