# SSR em Angular

A aplicação Angular normalmente executa no navegador, renderizando páginas no DOM em resposta a ações do usuário. O Angular Universal executa no servidor, gerando páginas de aplicativo estático que mais tarde são inicializadas pelo cliente. Isso significa que o aplicativo geralmente renderiza mais rapidamente, dando aos usuários uma chance de ver o layout da aplicação antes de se tornar completamente interativo.
