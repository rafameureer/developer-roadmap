# Formulários Tipados

Desde o Angular 14, os formulários reativos são tipados de forma estrita por padrão. Você não precisa definir tipos personalizados extras ou adicionar uma tonelada de anotações de tipo às suas declarações de formulário para aproveitar essa segurança adicional de tipo, pois o Angular inferirá os tipos a partir do valor padrão de um controle de formulário. Os formulários não tipados ainda são suportados. Para usá-los, você deve importar os símbolos `Untyped` de `@angular/forms`.
