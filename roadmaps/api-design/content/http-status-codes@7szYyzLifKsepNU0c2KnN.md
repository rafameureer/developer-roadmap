# Códigos de Status HTTP

Os Códigos de Status HTTP são uma parte essencial da design de API, fornecendo informações importantes sobre o resultado de uma solicitação feita a um servidor. Eles são números de três dígitos onde o primeiro dígito define a classe de resposta, enquanto os dois últimos dígitos não têm valor de categorização. Por exemplo, '200' significa que uma solicitação HTTP foi bem-sucedida, enquanto '404' indica que um recurso solicitado não foi encontrado no servidor. O uso eficiente desses códigos pode melhorar a robustez da API, tornando-a mais compreensível e mais fácil de depurar.
