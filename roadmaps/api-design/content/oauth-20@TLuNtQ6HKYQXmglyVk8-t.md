# OAuth 2.0

OAuth 2.0 é um quadro de autorização que permite que aplicativos obtenham acesso limitado às contas de usuários em um serviço HTTP, como Facebook, GitHub, DigitalOcean e outros. Ele funciona delegando a autenticação do usuário para o serviço que hospeda a conta do usuário e autorizando aplicativos terceiros a acessar a conta do usuário. OAuth 2.0 define quatro papéis: proprietário de recursos, cliente, servidor de recursos e servidor de autorização. Em relação à design de API, OAuth 2.0 pode ser usado para proteger os endpoints da API garantindo que apenas as aplicativos clientes com tokens de acesso válidos possam interagir com a API. Ele fornece processos de fluxo detalhados e um conjunto de protocolos para que a aplicativo cliente obtenha autorização para acessar recursos.
