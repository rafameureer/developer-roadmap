# OIDC OpenID Connect (OIDC)

OIDC (OpenID Connect) é uma camada de identidade construída sobre o OAuth 2.0. Enquanto o OAuth 2.0 lida com a autorização (o que você pode fazer), o OIDC lida com a autenticação (quem você é). Ele apresenta o conceito de um token de ID, um JWT assinado que contém declarações sobre o usuário autenticado, como seu nome, e-mail e ID do usuário. O OIDC é o padrão por trás dos fluxos "Entrar com Google / GitHub / Apple" e é a escolha correta quando sua API precisa verificar a identidade de um usuário, não apenas suas permissões.
