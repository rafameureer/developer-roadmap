# PCI DSS na Design de API

Payment Card Industry Data Security Standard (PCI DSS) é um conjunto de políticas e procedimentos amplamente aceitos com o intuito de otimizar a segurança das transações de cartões de crédito, débito e dinheiro em espécie e proteger os portadores dos cartões contra o uso inadequado de suas informações pessoais. Em termos de Design de API, construir APIs em conformidade com PCI DSS é crucial quando processar, armazenar ou transmitir informações de cartão de crédito. Ao seguir esses padrões, não apenas os desenvolvedores podem garantir endpoints de API seguros e seguros, mas também construir confiança entre os usuários protegendo seus dados financeiros sensíveis.
