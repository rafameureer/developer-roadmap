# ReBAC

Controle de Acesso Baseado em Relacionamentos (ReBAC) é um modelo de autorização que determina os direitos de acesso com base nas relações entre usuários e recursos. Em vez de depender apenas de papéis ou atributos, o ReBAC considera as conexões e associações entre entidades dentro de um sistema. Isso permite um controle fino sobre quem pode acessar o que, com base em sua relação com os dados ou recursos em questão.
