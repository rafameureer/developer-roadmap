#Modelagem de Recursos

A modelagem de recursos é o processo de decidir quais "coisas" sua API expõe e como elas se mapeiam para URLs. Um recurso é qualquer substantivo que sua API gerencia, como um usuário, uma ordem ou um produto. Modelá-lo significa definir seus limites, suas relações com outros recursos e quais dados ele carrega. Uma boa modelagem de recursos feita desde o início previne estruturas de URL desconfortáveis e formas de dados inconsistentes que são dolorosas de corrigir uma vez que os consumidores estejam dependendo da sua API.
