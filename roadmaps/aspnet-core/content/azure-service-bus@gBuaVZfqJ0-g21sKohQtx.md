# Azure Service Bus

Azure Service Bus é uma plataforma de mensageria escalável e confiável que pode lidar com um alto volume de mensagens. É fácil de usar, possui muitas funcionalidades como assinaturas, tópicos, letreiros mortos e é fácil de integrar com outros serviços do Azure. Além disso, é um serviço gerenciado, o que significa que a Microsoft cuida da infraestrutura e escalabilidade. No entanto, vale ressaltar que o Azure Service Bus é um serviço pago e o custo dependerá do número de mensagens e do tamanho dos dados que você está enviando e recebendo.
