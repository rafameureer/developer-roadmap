# Blazor

Blazor é um framework para construir aplicativos web usando C# e .NET que rodam no navegador via WebAssembly. Ele permite aos desenvolvedores escrever código C# que roda diretamente no navegador, eliminando a necessidade de JavaScript.

Blazor vem em duas variações:

*   Blazor WebAssembly, uma solução cliente que permite executar código C# diretamente no navegador usando WebAssembly. A aplicação é executada no lado do cliente e pode funcionar offline, também pode interagir com JavaScript e acessar o DOM do navegador.
*   Blazor Server, uma solução servidor que permite executar código C# no servidor e atualizar a interface do usuário em tempo real. A aplicação é executada no lado do servidor e requer uma conexão ativa ao servidor para funcionar.
