# C#

C# é um idioma de codificação moderno desenvolvido pela Microsoft que se concentra em aplicar o estilo de codificação ao C++ e torná-lo mais condensado e simples. É semelhante ao Java tanto por ser estático, forte e manifestivo quanto por essas características. Ambos usam as classes pré-construídas do Sistema para realizar certas funcionalidades como imprimir saída na tela, etc. C#, assim como Java, também contém uma coleta de lixo, que remove o código de manutenção de nível inferior do programador.
