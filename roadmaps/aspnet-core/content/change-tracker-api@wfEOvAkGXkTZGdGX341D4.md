# API do Tracker de Mudanças

A API do Tracker de Mudanças é uma funcionalidade dos frameworks de mapeamento objeto-relacional (ORM), como Entity Framework Core, que permite aos desenvolvedores rastrear as mudanças em entidades e persisti-las automaticamente no banco de dados.

A API do Tracker de Mudanças geralmente é exposta através da classe de contexto, que é a classe principal responsável pela gestão da conexão com o banco de dados e fornecendo acesso às entidades.

Visite os seguintes recursos para aprender mais:

- [@artigo@Rastreamento de Mudanças no EF Core](https://learn.microsoft.com/en-us/ef/core/change-tracking/)
- [@artigo@Introdução ao Rastreamento de Mudanças](https://www.oreilly.com/library/view/programming-entity-framework/9781449331825/ch05.html)
- [@artigo@Tracker de Mudanças no Entity Framework Core](https://www.entityframeworktutorial.net/efcore/changetracker-in-ef-core.aspx)
