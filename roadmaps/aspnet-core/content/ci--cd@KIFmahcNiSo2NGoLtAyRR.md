# CI CD

CI/CD (Integração Contínua/Entrega Contínua) é uma prática de desenvolvimento de software que envolve automatizar o processo de construção, teste e implantação de alterações de código. É uma prática popular entre equipes de desenvolvimento de software, pois ajuda a garantir que as alterações de código sejam integradas, testadas e implantadas rapidamente e confiavelmente.

No contexto do [ASP.NET](http://ASP.NET), CI/CD pode ser usado para automatizar várias tarefas relacionadas ao desenvolvimento, teste e implantação de aplicativos [ASP.NET](http://ASP.NET). Por exemplo, você pode usar CI/CD para automatizar a construção, teste e implantação de um aplicativo [ASP.NET](http://ASP.NET) em um provedor de hospedagem, como Azure ou AWS, toda vez que você empurrar código para seu repositório de controle de versão.
