# Restrições

As restrições de banco de dados são regras usadas para limitar os dados que podem ser armazenados em uma tabela do banco de dados. Essas restrições podem ser usadas para garantir a integridade e precisão dos dados na tabela, e também podem ser usadas para impor regras de negócios ou outros requisitos. Por exemplo, uma restrição pode ser usada para garantir que uma coluna contenha apenas números positivos, ou para garantir que uma coluna sempre tenha um valor único. As restrições podem ser especificadas no momento em que a tabela é criada, ou podem ser adicionadas a uma tabela existente. Alguns tipos comuns de restrições incluem chaves primárias, chaves estrangeiras e restrições NOT NULL.
