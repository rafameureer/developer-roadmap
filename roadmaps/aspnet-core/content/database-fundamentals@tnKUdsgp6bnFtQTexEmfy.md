# Fundamentos de Banco de Dados

Um banco de dados é uma coleção de dados úteis de uma ou mais organizações relacionadas estruturados de forma a tornar os dados um ativo para a organização. Um sistema de gerenciamento de banco de dados é um software projetado para auxiliar na manutenção e extração de grandes conjuntos de dados de maneira eficiente.

Um **Banco de Dados Relacional** é um tipo de banco de dados que armazena e fornece acesso a pontos de dados relacionados entre si. Bancos de dados relacionais armazenam dados em uma série de tabelas.

Os **Bancos de Dados Não-Relacionais** oferecem armazenamento e recuperação de dados modelados de maneira diferente dos "tradicionais" bancos de dados relacionais. Bancos de dados não-relacionais geralmente se concentram mais em escalabilidade horizontal, consistência eventual, velocidade e flexibilidade e são comumente usados para aplicativos de big data e streaming em tempo real.
