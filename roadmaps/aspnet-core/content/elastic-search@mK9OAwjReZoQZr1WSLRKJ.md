# Elasticsearch

O Elasticsearch é um motor de busca e análise distribuído e de código aberto que pode ser usado para indexar, pesquisar e analisar grandes volumes de dados rapidamente e em tempo real. Ele está baseado na biblioteca Apache Lucene e pode ser usado para realizar buscas de texto completo, buscas facétadas e buscas espaciais, entre outros.
