# Entity Framework Core

Entity Framework Core (EF Core) é um framework de mapeamento objeto-relacional (ORM) open source para .NET. É uma versão leve e multiplataforma do Entity Framework, o framework ORM que fazia parte do .NET Framework. EF Core permite aos desenvolvedores trabalhar com dados relacionais usando objetos específicos da domínio, eliminando a necessidade de escrever instruções SQL brutas. Em vez disso, EF Core fornece um conjunto de APIs que podem ser usadas para interagir com um banco de dados, fornecendo uma maneira simples e eficiente de realizar operações comuns no banco de dados como consulta, inserção, atualização e exclusão.
