# FakeitEasy

FakeItEasy é uma biblioteca open source para .NET que permite aos desenvolvedores criar objetos falsos para uso em testes unitários. É um poderoso e fácil de usar framework de mock que fornece uma sintaxe simples e intuitiva para criar objetos falsos e configurar o comportamento falso. No contexto do [ASP.NET](http://ASP.NET), FakeItEasy pode ser usado para criar objetos falsos para testar aplicativos web construídos usando o [ASP.NET](http://ASP.NET) framework, fornecendo uma sintaxe simples e expressiva para criar objetos falsos e configurar o comportamento falso. FakeItEasy suporta um amplo range de frameworks de teste, incluindo MSTest, NUnit e xUnit. FakeItEasy é leve e fácil de usar, tornando-se uma boa escolha para desenvolvedores que são novos em mock e testes unitários. Ele também fornece um conjunto rico de recursos, como suporte para configurar o comportamento falso, fazer afirmações sobre chamadas feitas aos objetos falsos e mais. Também tem um amplo range de pontos de extensão para personalizar os falsos conforme necessário.
