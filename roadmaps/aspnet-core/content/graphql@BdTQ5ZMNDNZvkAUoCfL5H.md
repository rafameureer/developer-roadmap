# GraphQL

O GraphQL é um idioma de consulta para sua API que permite que os clientes definam a estrutura dos dados que precisam e o servidor retornará apenas os dados solicitados. É uma alternativa aos serviços web RESTful e está ganhando popularidade devido à sua flexibilidade e eficiência.

No [ASP.NET](http://ASP.NET), o GraphQL pode ser usado para criar serviços web que expõem dados de maneira mais flexível e eficiente. Há várias bibliotecas disponíveis para implementar o GraphQL em um aplicativo [ASP.NET](http://ASP.NET), como [GraphQL.NET](http://GraphQL.NET), Hot Chocolate, e outras. Essas bibliotecas fornecem um conjunto de classes e métodos que facilitam a criação de um esquema GraphQL, o processamento de solicitações e a geração de respostas.
