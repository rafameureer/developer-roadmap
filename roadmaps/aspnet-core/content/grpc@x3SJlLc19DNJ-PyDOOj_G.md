# gRPC

gRPC é um framework de alto desempenho e código-fonte aberto para construir APIs de chamada remota (RPC). Ele usa o formato de serialização de dados Protocol Buffers e o protocolo HTTP/2 para criar APIs altamente eficientes e escaláveis. gRPC suporta uma variedade de idiomas de programação, incluindo C# e [ASP.NET](http://ASP.NET).

No [ASP.NET](http://ASP.NET), gRPC pode ser usado para criar APIs de alto desempenho e baixa latência para diversos casos de uso. gRPC permite a transmissão bidirecional de dados, o que pode ser útil para aplicativos em tempo real como jogos, negociações financeiras e mais.
