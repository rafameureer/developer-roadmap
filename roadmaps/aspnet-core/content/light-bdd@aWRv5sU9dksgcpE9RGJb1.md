# LightBDD

LightBDD é um framework de desenvolvimento orientado a comportamento (BDD) leve e fácil de usar para .NET, que permite aos desenvolvedores escrever testes de aceitação automatizados em um formato simples e legível. O LightBDD é comumente usado no contexto do [ASP.NET](http://ASP.NET) e outras tecnologias .NET para escrever testes de aceitação para aplicativos web. O LightBDD está projetado para fornecer uma maneira simples, mas poderosa, de escrever testes BDD. Ele permite aos desenvolvedores escrever testes usando uma API fluente, o que os permite descrever o comportamento do aplicativo em um formato de linguagem natural. O framework também fornece um conjunto de métodos de extensão, que podem ser usados para adicionar funcionalidades adicionais, como validar a saída de um teste, registrar resultados de testes ou integrar com outras ferramentas de teste. O LightBDD também vem com um executador de testes embutido, o que torna fácil executar os testes e visualizar os resultados. O framework suporta vários executadores de testes, como NUnit, xUnit e MSTest, e pode ser integrado a outros frameworks BDD, como SpecFlow e Cucumber.
