# MediatR

MediatR é uma biblioteca de código aberto para .NET projetada para simplificar o processo de manipulação de mensagens e comandos de maneira limpa e decuplicada. É particularmente útil em aplicativos que usam o padrão Command-Query Responsibility Segregation (CQRS) e arquitetura orientada a eventos. Ele fornece uma API simples e fácil de usar para manipular mensagens, e suporta o conceito de pipelines, permitindo adicionar comportamentos adicionais à manipulação de mensagens, como registro em log, validação e tratamento de exceções.
