# APIs Menores

As APIs Menores é uma abordagem leve para construir APIs HTTP no .NET com minimalismo. Foi projetada para simplicidade e desempenho, tornando-se ideal para microservices, aplicativos serverless e pequenos serviços web. As APIs Menores oferecem um caminho simplificado para definir rotas, lidar com solicitações e retornar respostas sem a necessidade de controladores ou configuração extensa. Eles aproveitam as declarações de nível superior, reduzindo o código boilerplate enquanto mantém flexibilidade e escalabilidade.

As APIs Menores suportam injeção de dependência, middleware, associação de modelo e validação. Elas também integram-se perfeitamente com OpenAPI (Swagger) para documentação da API. Sua simplicidade as torna uma escolha excelente para construir aplicativos web rápidos e eficientes com .NET.
