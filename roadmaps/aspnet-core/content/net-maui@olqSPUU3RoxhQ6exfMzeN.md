# .NET MAUI

.NET MAUI (Multi-platform App UI) é o framework de interface do usuário cruz-plataforma para .NET. Ele permite que você crie aplicativos nativos para Android, iOS, macOS e Windows a partir de um único código-fonte em C# e XAML, compartilhando a lógica de negócios enquanto ainda permite personalizações específicas por plataforma quando necessário.
