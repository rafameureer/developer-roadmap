# .NET Framework

.NET (pronunciado "dot net") é um framework de software desenvolvido pela Microsoft que pode ser usado para criar uma ampla gama de aplicativos, incluindo aplicativos de desktop do Windows e da web, aplicativos móveis e jogos. O .NET Framework fornece uma grande biblioteca de funcionalidades pré-construídas, como coleções, entrada/saída de arquivo e rede, que podem ser usadas por aplicativos .NET. Ele também inclui um Common Language Runtime (CLR) que gerencia a execução do código, fornecendo recursos como gerenciamento de memória, segurança e tratamento de exceções.
