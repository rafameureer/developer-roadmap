# OData

OData (Protocolo de Dados Aberto) é um protocolo da web para consulta e atualização de dados. É um padrão aberto para criar e consumir serviços web RESTful. OData é construído sobre o protocolo HTTP e usa as convenções do REST para expor dados através de uma interface padrão.

No [ASP.NET](http://ASP.NET), OData pode ser usado para criar serviços web RESTful que expõem dados de maneira padronizada. OData fornece um conjunto de convenções para definir a estrutura dos dados e também fornece um conjunto de convenções para consultar e atualizar os dados.
