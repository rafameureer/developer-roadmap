# Puppeteer

Puppeteer é uma biblioteca de código aberto para automatizar navegadores web, semelhante ao Selenium e Playwright. Ele é construído sobre o protocolo Chrome DevTools e fornece um conjunto de APIs que permitem aos desenvolvedores interagir com navegadores web e simular interações do usuário, como clicar em botões, preencher formulários e navegar entre páginas. É comumente usado para testar aplicativos web, coleta de dados da web e geração de capturas de tela e PDFs de páginas web. O Puppeteer para .NET é construído sobre o runtime .NET Core e fornece vinculações para C#, permitindo que os desenvolvedores escrevam testes para aplicativos web em C# ou outras linguagens .NET.
