# Razor Pages

Razor Pages é uma funcionalidade do framework [ASP.NET](http://ASP.NET) Core que permite aos desenvolvedores construir aplicativos web usando uma combinação de marcação Razor (uma sintaxe de marcação para definir HTML dinâmico) e código C#. Razor Pages é baseado no framework [ASP.NET](http://ASP.NET) Core MVC (Model-View-Controller), e fornece uma maneira mais simples e intuitiva de construir páginas web e lidar com a entrada do usuário.

Razor Pages são úteis para construir páginas web simples, autônomas que não requerem uma estrutura complexa de navegação ou layout, e são frequentemente usados para construir aplicativos web pequenos a médios.
