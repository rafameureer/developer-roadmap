# RepoDB

RepoDB é uma biblioteca de ORM (Object-Relational Mapping) open-source para .NET que simplifica o processo de trabalhar com bancos de dados. É uma biblioteca leve, rápida e fácil de usar que fornece uma API simples e consistente para realizar operações comuns no banco de dados, como consulta, inserção, atualização e exclusão de dados.

RepoDB é construído sobre [ADO.NET](http://ADO.NET), que é a tecnologia de acesso a dados nativa em .NET, e fornece uma abstração de nível superior sobre ela. Isso permite que RepoDB aproveite o desempenho e escalabilidade do [ADO.NET](http://ADO.NET) enquanto oferece uma API mais simples e conveniente para os desenvolvedores.
