# Scriban

Scriban é um motor de modelo de código-fonte aberto e leve para .NET que se baseia no idioma de programação Lua. Ele está projetado para ser simples e fácil de usar, enquanto ainda fornece um conjunto poderoso de recursos para criar e manipular modelos. Ele oferece uma API simples e fácil de usar para análise e renderização de modelos e suporta uma ampla gama de recursos como variáveis, loops, condições e funções. Ele também oferece uma ampla gama de funções internas para trabalhar com strings, números, datas e outros tipos de dados, além de suporte a recursos avançados como scripting e metaprogramação.
