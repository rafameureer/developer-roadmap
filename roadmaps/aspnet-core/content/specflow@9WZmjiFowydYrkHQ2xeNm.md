# SpecFlow

SpecFlow é uma ferramenta de código aberto que permite aos desenvolvedores criar testes de aceitação automatizados em um formato de linguagem natural, como Gherkin. O SpecFlow é comumente usado no contexto do [ASP.NET](http://ASP.NET) e outras tecnologias .NET para escrever testes de aceitação para aplicativos web. Com o SpecFlow, os desenvolvedores podem escrever cenários de teste usando texto simples na sintaxe Gherkin, que usa um formato Given-When-Then para descrever as etapas de um teste. Esses cenários podem ser escritos por não profissionais técnicos, como analistas de negócios ou proprietários de produtos, e podem ser facilmente compreendidos por qualquer pessoa que os leia. O SpecFlow então converte esses cenários Gherkin em testes executáveis, que podem ser executados usando uma variedade de executadores de teste, como NUnit, xUnit ou MSTest. A ferramenta também fornece um conjunto de vinculações que permitem aos desenvolvedores mapear as etapas dos cenários Gherkin para o código em sua aplicação, tornando fácil testar funcionalidades específicas. Além disso, o SpecFlow oferece um conjunto de recursos avançados, como suporte a testes parametrizados, etapas de fundo e hooks, que permitem aos desenvolvedores criar testes mais complexos e poderosos.
