# Stored Procedures

Um procedimento armazenado é uma coleção pré-compilada de instruções SQL que pode ser executada em um servidor de banco de dados. Procedimentos armazenados são normalmente usados para realizar tarefas específicas, como recuperar dados de um banco de dados, inserir ou atualizar dados, ou realizar cálculos complexos. Eles são armazenados no servidor de banco de dados e podem ser chamados ou executados a partir de uma aplicação cliente ou outros procedimentos armazenados. Procedimentos armazenados podem melhorar o desempenho do banco de dados reduzindo a quantidade de código SQL necessário para ser executado e permitindo que os desenvolvedores reutilizem partes comuns de código. Eles também podem fornecer segurança, permitindo que administradores de banco de dados controluem quais usuários têm acesso a determinados procedimentos armazenados.
