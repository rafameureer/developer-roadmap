# Testes

Testes em [ASP.NET](http://ASP.NET) é o processo de avaliar o desempenho, funcionalidade e corretude geral de uma aplicação desenvolvida usando o framework [ASP.NET](http://ASP.NET). Existem vários tipos de testes que podem ser realizados em uma aplicação [ASP.NET], incluindo testes unitários, testes de integração, testes de aceitação e testes E2E. Cada tipo de teste tem um foco diferente e é usado em diferentes estágios do processo de desenvolvimento. Os frameworks de teste comuns para [ASP.NET] incluem MSTest, XUnit, NUnit, Selenium, Playwright, Puppeteer, Cypress, Specflow, Cucumber e LightBDD.
