# Gatilhos

Gatilhos são um tipo especial de procedimentos armazenados que são executados automaticamente em resposta a eventos específicos que ocorrem dentro de um banco de dados. Esses eventos podem incluir:

*   Eventos de modificação de dados (INSERT, UPDATE, DELETE) em uma tabela ou exibição específica.
*   Eventos de definição de dados (CREATE, ALTER, DROP) em objetos de banco de dados específicos como tabelas ou exibições.
*   Eventos de logon (CONNECT, DISCONNECT) que ocorrem quando um usuário se conecta ou desconecta do banco de dados.
