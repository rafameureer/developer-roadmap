# Web Sockets

WebSockets é um protocolo que permite comunicação em tempo real, bidirecional entre um cliente e um servidor. Ele se baseia no mesmo princípio do HTTP, mas usa um protocolo diferente para estabelecer e manter uma conexão entre o cliente e o servidor. Uma vez que a conexão é estabelecida, os WebSockets permitem que o cliente e o servidor enviem mensagens uns aos outros em tempo real.

No [ASP.NET](http://ASP.NET), os WebSockets podem ser usados para criar aplicativos web em tempo real e de alta interatividade. O framework [ASP.NET](http://ASP.NET) Core fornece suporte integrado para WebSockets através do pacote Microsoft.AspNetCore.WebSockets. Este pacote fornece um conjunto de classes e métodos que facilitam a criação e gerenciamento das conexões WebSockets.
