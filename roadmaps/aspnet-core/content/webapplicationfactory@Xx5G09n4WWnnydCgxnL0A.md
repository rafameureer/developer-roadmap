# WebApplicationFactory

Web Application Factory (WAF) é uma funcionalidade integrada do framework [ASP.NET](http://ASP.NET) Core que permite aos desenvolvedores criar e configurar um aplicativo web de forma programática. Ele fornece uma maneira simples e flexível de configurar um aplicativo web para testes, sem a necessidade de um servidor web ou navegador. O WAF pode ser usado para criar um servidor de teste que possa ser usado para executar testes de integração ou testes ponta a ponta para um aplicativo web [ASP.NET](http://ASP.NET) Core, isso permite aos desenvolvedores testar o aplicativo web em um ambiente realista, sem a necessidade de um servidor web físico ou navegador. O WAF pode ser configurado para usar diferentes serviços, middleware e configurações, dependendo das necessidades do aplicativo, isso permite aos desenvolvedores facilmente configurar um aplicativo web especificamente para testes. O WAF também permite que os desenvolvedores testem o aplicativo web contra diferentes configurações, como diferentes bancos de dados, diferentes provedores de autenticação e diferentes ambientes de hospedagem.
