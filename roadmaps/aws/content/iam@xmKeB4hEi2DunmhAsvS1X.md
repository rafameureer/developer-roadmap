# IAM

IAM, ou Gerenciamento de Identidade e Acesso, no AWS é um serviço que permite gerenciar o acesso aos serviços e recursos do AWS de forma segura. Ele permite criar e gerenciar usuários e grupos do AWS e usar permissões para permitir ou negar seu acesso a recursos do AWS. O serviço inclui funcionalidades como compartilhamento de acesso ao seu conta do AWS, permissões granulares, federação de identidade (incluindo integração com Active Directory), autenticação multifator (MFA) e fornecimento de acesso temporário para usuários, entre outros. IAM é um sistema universal, o que significa que ele é acessível globalmente e não depende de regiões específicas.
