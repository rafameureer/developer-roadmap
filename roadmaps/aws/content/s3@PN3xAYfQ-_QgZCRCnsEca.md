# S3

O Amazon S3 (Simple Storage Service) é um serviço de armazenamento de objetos oferecido pela Amazon Web Services (AWS). Ele fornece armazenamento escalável, seguro e duradouro na internet. Projetado para armazenar e recuperar qualquer quantidade de dados de qualquer lugar na web, ele é uma ferramenta chave para muitas empresas no campo do armazenamento de dados, incluindo aplicativos móveis, sites, backup e restauração, arquivamento, aplicativos empresariais, dispositivos IoT e análise de big data.
