# Tipos de Armazenamento

O AWS RDS oferece três tipos de armazenamento: General Purpose (SSD), Provisioned IOPS (SSD) e Magnetic. O armazenamento General Purpose (SSD) oferece uma linha base consistente de 3 IOPS/GB e pode atingir até 3.000 IOPS. É adequado para um amplo range de cargas de trabalho de banco de dados que têm requisitos moderados de I/O. O armazenamento Provisioned IOPS (SSD) é projetado para atender às necessidades de cargas de trabalho intensivas em I/O, especialmente cargas de trabalho de banco de dados sensíveis à performance e consistência do armazenamento. O armazenamento Magnetic, o tipo mais econômico, é perfeito para aplicações onde a menor custo de armazenamento é importante e é melhor para dados que são acessados infrequentemente.
