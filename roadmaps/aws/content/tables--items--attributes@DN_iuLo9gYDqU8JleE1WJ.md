# Tabelas / Itens / Atributos

No Amazon DynamoDB, as tabelas são uma coleção de itens. Um item é um grupo de atributos que é identificado por uma chave primária. Os itens são semelhantes a linhas ou registros em outros sistemas de banco de dados. Cada item em uma tabela é exclusivamente identificável por uma chave primária. Essa chave pode ser simples (apenas a chave de partição) ou composta (chave de partição e chave de classificação). Cada atributo em um item é um par nome-valor. O nome do atributo é uma string e o valor de um atributo pode ser dos seguintes tipos: String, Number, Binary, Boolean, Null, List, Map, String Set, Number Set e Binary Set.
