# Grupos de Usuários

No AWS Identity and Access Management (IAM), um **Grupo de Usuários** é uma coleção de usuários IAM. Os grupos permitem especificar permissões para múltiplos usuários, tornando mais fácil gerenciar as permissões desses usuários. Por exemplo, você poderia ter um grupo chamado "Desenvolvedores" e dar a esse grupo as permissões necessárias para desenvolver em seu ambiente. Se um novo desenvolvedor se juntar à sua organização, em vez de definir permissões específicas para esse usuário, você pode adicionar o usuário ao grupo "Desenvolvedores" para atribuir essas permissões. Lembre-se, cada usuário IAM do AWS em um grupo herda as políticas de permissão anexadas ao grupo.
