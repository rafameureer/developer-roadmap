# Testes Funcionais

Os testes funcionais verificam se o software atende aos requisitos de negócio esperados através de testes de caixa-preta (*black box testing*). O testador fornece entradas e compara as saídas geradas com os resultados esperados, sem precisar analisar o código-fonte interno. Eles validam funcionalidades completas do ponto de vista do usuário ou cliente da API, contrastando com testes não-funcionais (desempenho, estresse, segurança e escalabilidade).
