# Git

O Git é um sistema de controle de versão distribuído que rastreia todo o histórico de alterações feitas no código-fonte ao longo do tempo. Ele permite que desenvolvedores criem branches para trabalhar em novas funcionalidades de forma isolada, façam commits atômicos e mesclem seu trabalho de forma segura e colaborativa.
