# Bancos de Dados

Um banco de dados é uma coleção organizada e estruturada de dados armazenados eletronicamente em um sistema computacional. Um Sistema de Gerenciamento de Banco de Dados (SGBD ou DBMS) é o software responsável por armazenar, consultar, atualizar e proteger esses dados de forma eficiente, confiável e segura.
