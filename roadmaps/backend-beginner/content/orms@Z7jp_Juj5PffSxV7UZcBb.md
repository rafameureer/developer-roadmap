# ORMs (Object-Relational Mapping)

ORM (*Object-Relational Mapping* ou Mapeamento Objeto-Relacional) é uma técnica que permite aos desenvolvedores consultar e manipular bancos de dados relacionais utilizando o paradigma de orientação a objetos de sua linguagem favorita. O ORM mapeia tabelas para classes e linhas para objetos, abstraindo a necessidade de escrever comandos SQL manuais. Exemplos populares incluem Prisma e TypeORM (Node.js), SQLAlchemy e Django ORM (Python), Hibernate (Java) e Entity Framework (.NET).
