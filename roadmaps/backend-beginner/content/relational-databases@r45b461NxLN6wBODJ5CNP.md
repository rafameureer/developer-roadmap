# Bancos de Dados Relacionais

Bancos de dados relacionais organizam e armazenam informações em tabelas estruturadas compostas por linhas e colunas, utilizando a linguagem SQL (*Structured Query Language*) para consultas e manipulação. Eles garantem a integridade dos dados através de chaves primárias, estrangeiras e restrições, processando consultas complexas e transações com consistência forte. Exemplos líderes de mercado incluem PostgreSQL, MySQL, MariaDB e Oracle.
