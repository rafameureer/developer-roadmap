# Testes de Software

O teste de software avalia sistematicamente a funcionalidade, confiabilidade, desempenho e segurança de uma aplicação em relação aos requisitos esperados. Ele se divide em múltiplos níveis: testes unitários, testes de integração, testes de sistema e testes de aceitação (E2E). Os testes automatizados previnem regressões, aumentam a confiança no deploy e garantem alta qualidade contínua na entrega de código.
