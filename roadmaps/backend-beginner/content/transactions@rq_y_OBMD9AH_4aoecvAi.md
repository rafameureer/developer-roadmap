# Transações em Bancos de Dados

Uma transação de banco de dados é uma sequência de uma ou mais operações executadas como uma única unidade lógica e atômica de trabalho. Se todas as operações forem bem-sucedidas, a transação é confirmada (*commit*); se qualquer etapa falhar, o sistema desfaz todas as alterações anteriores (*rollback*). As transações seguem as propriedades ACID para garantir que o banco nunca fique em um estado corrompido ou inconsistente.
