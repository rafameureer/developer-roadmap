# Autenticação

A autenticação de API verifica a identidade do cliente para garantir acesso autorizado aos recursos. Métodos comuns incluem chaves de API, OAuth 2.0, JWT e autenticação básica. Ela protege os dados, impede o acesso não autorizado, habilita o rastreamento de uso e fornece controle granular sobre os recursos da API.
