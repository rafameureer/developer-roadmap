# AWS Neptune

AWS Neptune é um banco de dados de gráficos totalmente gerenciado que suporta modelos de propriedade-gráfico e RDF. Usa os idiomas de consulta Gremlin e SPARQL para relacionamentos complexos em redes sociais, recomendações e detecção de fraude. Oferece alta disponibilidade, replicação multi-AZ e até 15 réplicas de leitura.
