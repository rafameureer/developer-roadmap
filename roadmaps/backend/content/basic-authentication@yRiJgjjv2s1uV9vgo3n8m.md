# Autenticação Básica

A autenticação básica envia o nome de usuário e a senha codificados em base64 nos cabeçalhos HTTP. É simples de implementar, mas inseguro porque o base64 pode ser facilmente decodificado. Deve ser usada apenas sobre HTTPS para proteger as credenciais. Melhor para cenários de baixo risco ou mecanismos de fallback.
