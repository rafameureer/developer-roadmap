# Navegadores

Os navegadores web interpretam HTML, CSS e JavaScript para renderizar páginas da web. Os navegadores modernos usam motores de renderização (Blink, Gecko, WebKit) e motores de JavaScript, oferecendo recursos como abas, marcadores, extensões e segurança através do isolamento em sandbox e aplicação de HTTPS.
