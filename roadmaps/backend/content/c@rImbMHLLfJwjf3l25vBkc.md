# C#

C# é um idioma moderno e orientado a objetos da Microsoft, combinando a potência do C++ com a simplicidade do Visual Basic. Usado para aplicativos Windows, desenvolvimento web com [ASP.NET](http://ASP.NET), jogos Unity e aplicativos móveis Xamarin. Características incluem coleta de lixo, segurança de tipos e integração forte ao ecossistema .NET.
