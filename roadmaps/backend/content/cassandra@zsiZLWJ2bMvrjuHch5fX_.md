# Cassandra

Cassandra é um banco de dados NoSQL projetado para lidar com grandes quantidades de dados em muitos servidores comerciais, fornecendo alta disponibilidade sem um único ponto de falha. Ele usa uma arquitetura distribuída para alcançar escalabilidade e tolerância a falhas, tornando-o adequado para aplicativos que requerem continuidade do serviço e podem tolerar consistência eventual. Os dados são organizados em tabelas com linhas e colunas, semelhantes aos bancos de dados relacionais, mas com um esquema mais flexível.
