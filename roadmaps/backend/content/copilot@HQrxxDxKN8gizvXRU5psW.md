# Copilot

O Copilot é um assistente de codificação baseado em IA desenvolvido pela GitHub e a OpenAI. Ele sugere linhas de código e funções inteiras em tempo real à medida que você digita, com base no contexto do seu código e comentários. Ele aprende de um grande conjunto de dados de código público, permitindo-lhe oferecer sugestões relevantes e precisas.
