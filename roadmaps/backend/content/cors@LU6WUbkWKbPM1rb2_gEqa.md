# CORS

CORS (Compartilhamento de Recursos entre Origens) é um mecanismo de segurança do navegador que controla o acesso a recursos entre domínios. Usa cabeçalhos HTTP e solicitações pré-voo para determinar as origens permitidas. Extende a Política de Mesma Origem enquanto previne o acesso não autorizado a dados sensíveis.
