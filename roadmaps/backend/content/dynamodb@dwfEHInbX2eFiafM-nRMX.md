# DynamoDB

O AWS DynamoDB é um banco de dados NoSQL gerenciado e sem servidor que suporta modelos de chave-valor e documentos. Oferece latência em dígitos únicos de milissegundos, escalabilidade automática, tabelas globais e escalabilidade sincronizada. Ideal para aplicativos web de alta taxa de tráfego, jogos, móveis e soluções IoT.
