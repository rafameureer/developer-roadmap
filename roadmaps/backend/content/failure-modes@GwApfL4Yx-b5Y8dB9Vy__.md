# Modos de Falha

Os modos de falha dos bancos de dados incluem falhas de hardware, bugs de software, corrupção de dados, degradação de desempenho e inconsistências em sistemas distribuídos. Problemas comuns: perda de dados, indisponibilidade, atraso na replicação, deadlocks. São mitigados através de redundância, backups, log de transações e mecanismos de failover.
