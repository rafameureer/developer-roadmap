# Instrumentação, Monitoramento e Telemetria

A instrumentação incorpora código para capturar métricas, logs e rastreamentos. O monitoramento observa métricas em tempo real para anomalias e problemas de desempenho usando dashboards e alertas. A telemetria automatiza a coleta de dados de sistemas distribuídos. Juntas, elas fornecem insights sobre a saúde do sistema e resolução proativa de problemas.
