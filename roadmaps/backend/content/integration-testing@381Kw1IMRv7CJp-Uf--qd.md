# Testes de Integração

Os testes de integração verificam as interações entre componentes de software para garantir que eles funcionem corretamente. Testam a comunicação entre módulos por meio de APIs, bancos de dados e serviços terceiros. Capturam problemas de integração como desvios de dados e erros de protocolo que os testes unitários podem não detectar.
