# Memcached

Memcached é um sistema de cache em memória distribuído que acelera sites dinâmicos ao armazenar dados e objetos na RAM. Fornece uma grande tabela hash distribuída entre várias máquinas com a remoção de itens menos recentemente usados (LRU). As camadas de aplicativos solicitam dados na RAM antes de recorrer a armazenamentos de backup mais lentos.
