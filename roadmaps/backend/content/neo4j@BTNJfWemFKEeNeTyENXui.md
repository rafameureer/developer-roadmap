# NEO4J

O Neo4j é um banco de dados de gráficos de código aberto que armazena dados como nós e relações interconectados em vez de tabelas. Usa o idioma de consulta Cypher para uma navegação eficiente em grafos e correspondência de padrões. Ideal para aplicativos complexos de relacionamento, como redes sociais, recomendações e detecção de fraude.
