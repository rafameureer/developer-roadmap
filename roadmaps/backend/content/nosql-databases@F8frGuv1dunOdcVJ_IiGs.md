# Bancos de Dados NoSQL

Os bancos de dados NoSQL lidam com dados não estruturados, semi-estruturados ou que mudam rapidamente com esquemas flexíveis. Quatro tipos: armazenamento de documentos (MongoDB, CouchDB), armazenamento chave-valor (Redis, Riak), família de colunas (Cassandra, HBase) e bancos de dados de gráficos (Neo4j, Neptune). Usados para aplicações de alta escalabilidade, flexibilidade e desempenho.
