# OAuth

OAuth é um padrão de autorização aberto que permite que aplicativos terceiros acessem recursos do usuário sem expor credenciais. Utiliza tokens de acesso emitidos após o consentimento do usuário, envolvendo o proprietário do recurso, o servidor de recursos e o servidor de autorização. Habilita o gerenciamento seguro de acesso baseado em token para serviços.
