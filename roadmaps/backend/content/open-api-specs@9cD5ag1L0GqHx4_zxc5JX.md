# Especificações Open API

Especificação de API Aberta (OAS), anteriormente conhecida como Swagger, é um padrão para definir e documentar APIs RESTful em formato YAML/JSON. Descreve endpoints, formatos, autenticação e metadados. Permite a geração automática de clientes, documentação automatizada, testes e promove a consistência na design de API.
