# Rust

Rust é um idioma de programação de sistemas focado em segurança, desempenho e concorrência. Fornece segurança de memória sem coleta de lixo através do modelo de propriedade, previnindo ponteiros nulos e corridas de dados. Sistema de tipos forte com recursos modernos adequados para programação de sistemas a servidores web.
