# Família SHA

SHA (Secure Hash Algorithm) é uma família de funções de hash criptográficas que geram valores de hash de tamanho fixo para garantir a integridade e segurança dos dados. Inclui SHA-1 (fraco, 160 bits), SHA-2 (mais forte, 224-512 bits) e SHA-3 (mais recente com recursos adicionais de segurança). Usado para armazenamento de senhas e assinaturas digitais.
