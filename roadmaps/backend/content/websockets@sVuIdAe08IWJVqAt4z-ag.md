# Web sockets

Os WebSockets permitem comunicação em dupla direção, em tempo real, sobre uma única conexão persistente entre cliente e servidor. Diferentemente dos ciclos de solicitação-resposta do HTTP, permite o troca contínuo de dados bidirecionais. Ótimo para chat em tempo real, jogos e atualizações em tempo real com comunicação de baixa latência.
