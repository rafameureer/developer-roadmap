# Airflow

Airflow é uma plataforma para autorizar, agendar e monitorar workflows de forma programática. Use o Airflow para autorizar workflows como grafos direcionados acíclicos (DAGs) de tarefas. O scheduler do Airflow executa suas tarefas em um array de trabalhadores seguindo as dependências especificadas. Ferramentas de linha de comando ricas tornam a realização de cirurgias complexas em DAGs uma brincadeira. A interface de usuário rica facilita a visualização dos pipelines em produção, monitoramento do progresso e solução de problemas quando necessário. Quando os workflows são definidos como código, eles se tornam mais manteríveis, versáteis, testáveis e colaborativos.
