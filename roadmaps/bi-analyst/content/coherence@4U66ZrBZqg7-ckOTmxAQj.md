# Coerência na Qualidade dos Dados

Na qualidade dos dados, a coerência refere-se à consistência lógica e entendibilidade dos dados em diferentes conjuntos de dados ou dentro de um único conjunto de dados. Ela garante que os elementos de dados estejam relacionados uns com os outros de uma maneira significativa e esperada, evitando contradições e ambiguidades. Coerência alta significa que os dados contam uma história clara e consistente, tornando-os confiáveis para análise e tomada de decisão.
