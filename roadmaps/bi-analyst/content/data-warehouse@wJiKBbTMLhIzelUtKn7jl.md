# Data Warehouse

**Data Warehouses** são sistemas de armazenamento de dados projetados para análise, relatórios e integração com sistemas transacionais. Os dados em um data warehouse são limpos, consistentes e muitas vezes transformados para atender a uma ampla gama de requisitos de negócios. Portanto, os data warehouses fornecem dados estruturados, mas exigem mais processamento e gerenciamento em comparação com os data lakes.
