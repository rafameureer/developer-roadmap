# dplyr para Análise Exploratória de Dados

dplyr é um pacote R que torna a manipulação e exploração de dados mais fáceis. Ele fornece um conjunto consistente de verbos, como `filter`, `select`, `mutate`, `summarize` e `arrange`, que permitem que você execute rapidamente tarefas comuns de análise de dados. Essas funções são projetadas para serem intuitivas e funcionar juntas sem problemas, permitindo que você encadeie operações para limpar, transformar e obter insights dos seus dados. Esse abordagem simplificada ajuda você a entender a estrutura dos seus dados, identificar padrões e prepará-los para análise ou visualização adicionais.

- [@oficial@dplyr](https://dplyr.tidyverse.org/)
