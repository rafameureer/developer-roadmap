# ETL Básico

ETL, que significa Extrair, Transformar e Carregar, é um processo usado para mover dados de vários sistemas de origem para uma data warehouse ou outro repositório de dados. Involvem extrair dados de diferentes fontes, transformá-los em um formato consistente e utilizável, e depois carregá-los no sistema-alvo para análise e relatórios. Esse processo garante a qualidade e a consistência dos dados, tornando mais fácil obter insights significativos.
