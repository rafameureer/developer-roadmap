# Gráficos de Linha

Gráficos de linha são um tipo de visualização de dados que exibe pontos de dados conectados por linhas retas. Eles são usados para mostrar tendências e mudanças nos dados em um intervalo contínuo, como o tempo. Cada ponto na linha representa um valor específico de dados, e as linhas que conectam os pontos ilustram a relação entre valores consecutivos.
