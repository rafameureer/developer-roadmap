# Fontes de Dados Web

As fontes de dados web se referem a informações coletadas na internet. Isso inclui dados raspados de sites, dados de APIs (Interfaces de Programação de Aplicativos) que os sites expõem e dados coletados por meio de ferramentas de análise web. Essa informação pode variar desde o tráfego do site e o comportamento dos usuários até preços de produtos e tendências em mídias sociais.
