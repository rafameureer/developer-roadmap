# Brownie

Brownie é um quadro de desenvolvimento e teste baseado em Python para contratos inteligentes direcionados à Máquina Virtual Ethereum (EVM). Ele simplifica o processo de escrita, implantação, teste e interação com contratos inteligentes fornecendo uma suíte de ferramentas e bibliotecas adaptadas para desenvolvedores Python. O Brownie visa tornar a desenvolvimento de contratos inteligentes mais acessível e eficiente, especialmente para aqueles já familiarizados com o Python.
