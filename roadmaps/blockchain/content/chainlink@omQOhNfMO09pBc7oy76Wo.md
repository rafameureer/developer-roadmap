# Chainlink

Chainlink é uma rede de oráculos descentralizados que fornece dados do mundo real para contratos inteligentes em uma blockchain. Ele atua como um ponte, conectando segurançamente as blockchains a fontes de dados externas, APIs e sistemas de pagamento. Isso permite que os contratos inteligentes acessem informações como feeds de preços, dados climáticos e resultados de eventos, permitindo que eles sejam executados com base em condições do mundo real.
