# Tokens ERC

Tokens ERC são um conjunto de padrões para criar tokens na blockchain Ethereum. Esses padrões definem um conjunto comum de regras que os tokens devem seguir, garantindo que possam interagir facilmente com outras aplicações e carteiras dentro do ecossistema Ethereum. Esta padronização simplifica o processo de criação, implantação e uso de tokens para diversos propósitos, como representar ativos digitais, utilidade em uma plataforma ou direitos de governança.
