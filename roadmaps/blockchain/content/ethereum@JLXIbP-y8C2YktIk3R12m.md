# Ethereum

Ethereum é uma plataforma de blockchain descentralizada e de código aberto que estabelece uma rede peer-to-peer para executar e verificar códigos de aplicativos de forma segura, referidos como contratos inteligentes. Ele permite que participantes transitem com um recipiente sem a necessidade de uma autoridade central confiável. As transações no Ethereum são agrupadas em blocos, que são então vinculados criptograficamente uns aos outros para formar uma cadeia, garantindo a integridade e imutabilidade dos dados.
