# Git

Git é um sistema de controle de versão distribuído que rastreia as alterações em arquivos em um projeto ao longo do tempo. Ele permite que múltiplos desenvolvedores trabalhem no mesmo código-fonte simultaneamente, gerenciando diferentes versões e mesclando alterações eficientemente. Git habilita aos desenvolvedores revertê-los para estados anteriores, comparar modificações e manter uma história detalhada de todas as atualizações do projeto.
