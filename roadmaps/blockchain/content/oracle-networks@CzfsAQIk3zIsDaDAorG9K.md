# Redes de Oráculos

Redes de oráculos são grupos de oráculos independentes que trabalham juntos para fornecer dados a uma blockchain. Em vez de depender de uma única fonte de informações, essas redes agregam dados de múltiplos oráculos, aumentando a confiabilidade e segurança. Esta redundância ajuda a mitigar o risco de dados imprecisos ou manipulados serem fornecidos aos contratos inteligentes, tornando o sistema como um todo mais robusto.
