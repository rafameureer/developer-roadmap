# Rust

Rust é um idioma de programação multi-paradigma e de alto nível focado em segurança, velocidade e concorrência. Ele atinge a segurança da memória sem coleta de lixo, tornando-o adequado para o desenvolvimento de sistemas e ambientes com restrições de recursos. O sistema de propriedade e verificador de empréstimos do Rust previnem erros comuns de programação como corridas de dados e ponteiros pendentes no tempo de compilação.
