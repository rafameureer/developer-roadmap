# Truffle

Truffle é um ambiente de desenvolvimento, quadro de testes e pipeline de ativos para blockchains usando a Máquina Virtual Ethereum (EVM). Ele fornece ferramentas para compilar, testar e implantar contratos inteligentes, tornando mais fácil para os desenvolvedores construir aplicativos descentralizados (dApps). Truffle simplifica o processo de desenvolvimento oferecendo recursos como gerenciamento de contrato, teste automatizado e configuração de rede.
