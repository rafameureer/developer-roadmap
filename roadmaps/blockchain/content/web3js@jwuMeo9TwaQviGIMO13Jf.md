# web3.js

web3.js é uma coleção de bibliotecas JavaScript que permite interagir com um nó Ethereum local ou remoto usando HTTP, WebSocket ou IPC. Ele fornece um conjunto de funções para interagir com contratos inteligentes na blockchain Ethereum, enviar transações, ler dados da blockchain e gerenciar contas Ethereum. Em essência, ele atua como uma ponte entre sua aplicação JavaScript e a rede Ethereum.
