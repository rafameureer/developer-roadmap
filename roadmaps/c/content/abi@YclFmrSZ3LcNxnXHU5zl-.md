# ABI

Um ABI (Interface Binária de Aplicação) define as convenções de nível baixo que o código compilado deve seguir para ser compatível com outros códigos compilados, incluindo como os argumentos das funções são passados, como os dados são dispostos na memória e como a pilha é organizada. Diferentemente de uma API de nível de linguagem, que se preocupa com a compatibilidade do código-fonte, um ABI se preocupa com a compatibilidade binária entre peças de código já compiladas. Duas bibliotecas compiladas com ABIs incompatíveis, por exemplo usando diferentes compiladores ou configurações, podem não funcionar corretamente juntas mesmo se suas interfaces de nível de código-fonte coincidirem.
