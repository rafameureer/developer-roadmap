# C vs Assembly

O código em linguagem de montagem se mapeia quase diretamente para o conjunto de instruções de um CPU específico, então o código escrito para uma arquitetura de processador não funcionará em outra sem uma reescrita. O C está um nível acima do assembly: ele compila para código máquina, mas usa uma sintaxe portátil que funciona em arquiteturas com pouca ou nenhuma alteração. Os programadores obtêm a maioria dos benefícios de desempenho do assembly com muito menos código e uma melhor legibilidade. O C às vezes é chamado de "assembly portável" por essa razão.
