# calloc

A função `calloc` é usada para alocar um número especificado de blocos de memória, cada um com um tamanho definido, e inicializa todos os bytes nessa memória para zero. Ela aceita dois argumentos: o número de elementos a serem alocados e o tamanho de cada elemento em bytes. Se a alocação for bem-sucedida, ela retorna um ponteiro para o primeiro byte do espaço alocado, ou um ponteiro nulo se o sistema não tiver memória suficiente.
