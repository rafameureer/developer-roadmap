# Conan

Conan é um gerenciador de pacotes para C e C++ que lida com tanto pacotes-fonte quanto binários pré-compilados, com foco em lidar com diferentes configurações de build, como depuração versus release ou diferentes compiladores. Ele integra-se a sistemas de build como CMake e Meson, e mantém um repositório central de receitas de pacote que descrevem como construir e consumir cada biblioteca. É comumente usado em projetos C++ maiores e multi-plataforma, embora também suporte C.
