# GCC / Clang

GCC (GNU Compiler Collection) e Clang são dois compiladores C amplamente utilizados e de código aberto, cada um suportando múltiplas plataformas e interfaces de linha de comando quase compatíveis. GCC tem uma história mais longa e suporte a uma maior variedade de plataformas, enquanto Clang é conhecido por compilação rápida, mensagens de erro mais legíveis e ser construído na infraestrutura do compilador LLVM. Ambos suportam flags de otimização semelhantes e modos de conformidade com padrões, tornando comum que projetos testem tanto GCC quanto Clang.
