# if else / switch

A declaração `if`/`else` ramifica a execução com base na avaliação de uma condição como verdadeira ou falsa, e pode ser encadeada com `else if` para múltiplas condições. A declaração `switch` compara um único valor contra várias possíveis opções e é geralmente mais clara que uma cadeia longa de `if`/`else if` ao verificar uma única variável contra muitos valores fixos. Esquecer um `break` no final de um caso `switch` causa a execução de cair para o próximo caso, o que é uma fonte comum de bugs.
