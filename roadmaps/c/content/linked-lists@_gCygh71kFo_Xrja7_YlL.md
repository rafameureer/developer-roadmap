# Listas Encadeadas

Uma lista encadeada armazena uma sequência de elementos como nós separados, onde cada nó contém um valor e um ponteiro para o próximo nó, em vez de armazenar os elementos continuamente como um array. Isso torna a inserção ou remoção de elementos no meio da lista eficiente, pois requer apenas atualizar alguns ponteiros, mas acessar um elemento arbitrário exige percorrer a lista do início. Variantes incluem listas encadeadas simplesmente encadeadas, listas duplamente encadeadas com ponteiros em ambas as direções e listas encadeadas circulares.
