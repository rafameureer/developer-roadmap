# Função main

A função `main` atua como o ponto de entrada designado onde a execução de cada programa em C começa. Quando um programa é executado, o sistema operacional chama essa função específica para iniciar a sequência de instruções definidas no código. Geralmente retorna um valor inteiro ao sistema operacional ao completar, onde um valor de retorno zero indica que o programa foi concluído com sucesso.
