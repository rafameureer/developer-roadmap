# Meson

Meson é um sistema de construção que enfatiza a velocidade e uma linguagem de configuração simples e legível, gerando arquivos de construção de back-end para ferramentas como Ninja em vez de compilar diretamente. Ele visa tornar tarefas de construção comuns fáceis com padrões sensíveis, reduzindo o boilerplate geralmente necessário com ferramentas como CMake. Ele ganhou adoção em vários projetos open-source em C buscando uma experiência de configuração de construção mais moderna.
