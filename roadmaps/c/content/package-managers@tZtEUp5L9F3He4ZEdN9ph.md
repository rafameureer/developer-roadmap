# Gerenciadores de Pacotes

Gerenciadores de pacotes para C, como vcpkg e Conan, automatizam o processo de encontrar, baixar e construir bibliotecas de terceiros, permitindo que sejam vinculadas a um projeto sem a necessidade de gerenciar manualmente o código-fonte ou binários pré-compilados. Isso resolve um problema persistente na desenvolvimento em C, já que o próprio idioma não possui uma gestão de pacotes embutida ou método padrão para distribuição da biblioteca padrão. Eles geralmente se integram a sistemas de construção como CMake para simplificar a adição de dependências a um projeto.
