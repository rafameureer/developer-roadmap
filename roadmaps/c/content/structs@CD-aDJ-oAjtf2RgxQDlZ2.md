# Estruturas (Structs)

A `struct` agrupa várias variáveis, possivelmente de diferentes tipos, sob um único nome, para que dados relacionados possam ser tratados como uma unidade. Cada campo, ou membro, é acessado usando o operador de ponto, ou o operador de seta se acessado através de um ponteiro para a estrutura. As estruturas são a maneira principal em que o C modela dados compostos, desde pares simples de valores até registros complexos usados em estruturas de dados maiores.
