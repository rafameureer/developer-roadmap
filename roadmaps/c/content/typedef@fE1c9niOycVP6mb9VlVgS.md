# Typedef

`typedef` cria um alias para um tipo existente, o que pode encurtar declarações de tipos complexos ou tornar o código mais portável e legível, por exemplo `typedef unsigned long size_t;`. Ele é comumente usado com structs para evitar repetir a palavra-chave `struct` toda vez que o tipo é usado. `typedef` não cria um novo tipo distinto, ele é puramente uma conveniência de nomeação para o compilador.
