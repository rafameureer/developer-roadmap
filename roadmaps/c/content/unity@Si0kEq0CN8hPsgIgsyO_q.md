# Unity

Unity é um framework de teste unitário leve para C, projetado com sistemas embarcados em mente, exigindo dependências mínimas e funcionando até mesmo em plataformas sem uma biblioteca padrão completa. Ele fornece um conjunto de macros de declaração de afirmações para verificar valores esperados e organizar testes em conjuntos executáveis. Sua pequena footprint o torna uma escolha comum para testar firmware e outros ambientes com restrições de recursos.
