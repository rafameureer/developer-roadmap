# vim / nvim

O vim e seu ramo moderno neovim são editores de texto baseados em terminal conhecidos por uma edição modal guiada pelo teclado, em vez de uma interface tradicional com mouse e menu. Eles são leves e funcionam via SSH, o que os torna populares para editar código C em servidores remotos ou sistemas embarcados. Configurar um para desenvolvimento em C, como adicionar destacamento de sintaxe ou um servidor de linguagem, requer algum setup inicial, mas recompensa a utilização frequente com velocidade.
