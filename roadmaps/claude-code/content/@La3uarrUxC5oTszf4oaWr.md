# Menções de Caminho do Arquivo (@)

Menções de caminho do arquivo, acionadas ao digitar o símbolo `@` seguido por um nome de arquivo ou pasta, permitem que você aponte manualmente a IA para partes específicas do seu código-fonte. Isso cria uma referência direta que prioriza esses arquivos na conversa atual, garantindo que o assistente analise exatamente o código que você está interessado em, sem precisar pesquisar todo o projeto primeiro. Ele suporta a conclusão de autocompletado, então à medida que você digita após o símbolo `@`, uma lista de arquivos correspondentes aparece, permitindo que você selecione rapidamente o caminho correto e adicione-o ao contexto da conversa.
