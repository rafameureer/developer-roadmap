# claude --add-dir

O comando `claude --add-dir` é uma bandeira de inicialização que permite incluir pastas extras em sua sessão de trabalho antes mesmo da interface ser aberta. Ao fornecer um ou mais caminhos de diretório ao iniciar a ferramenta (por exemplo, `claude --add-dir ../biblioteca --add-dir ./docs`), você concede permissão ao assistente para ler e modificar arquivos nessas localizações externas junto com o seu projeto atual. Isso é particularmente útil para tarefas de repositórios cruzados, como atualizar uma biblioteca compartilhada e sua aplicação dependente simultaneamente, garantindo que a IA tenha uma visão unificada de todos os códigos relevantes desde o primeiro prompt.
