# Equipe de Agentes

Equipes de Agentes são uma funcionalidade experimental de orquestração multi-agente em Claude Code que permite coordenar múltiplas instâncias de IA trabalhando em paralelo em um único projeto. As Equipes de Agentes funcionam como uma rede colaborativa onde um líder da equipe designado gerencia uma lista compartilhada de tarefas e delega trabalho a colegas que podem se comunicar diretamente para compartilhar descobertas ou debater soluções.
