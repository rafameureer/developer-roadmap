# claude --add-dir

O comando `claude --add-dir` é uma bandeira de inicialização que permite incluir pastas extras em sua sessão de trabalho antes mesmo da interface ser aberta. Ao iniciar a ferramenta e fornecer um ou mais caminhos de diretório (por exemplo, `claude --add-dir ../biblioteca --add-dir ./docs`), você concede ao assistente permissão para ler e modificar arquivos nessas localizações externas juntamente com o seu projeto atual. Isso é especialmente útil para tarefas cruz-repositórios, como atualizar uma biblioteca compartilhada e sua aplicação dependente simultaneamente, garantindo que a IA tenha uma visão unificada de todos os códigos relevantes desde o primeiro prompt.
