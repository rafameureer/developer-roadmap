# Claude Code Security

Claude Code Security é uma nova funcionalidade incorporada ao Claude Code que escaneia seu código em busca de vulnerabilidades de segurança e sugere correções para sua equipe revisar. Cada descoberta passa por um processo de verificação antes de chegar a você, com classificações de severidade para você saber o que corrigir primeiro. Nada muda automaticamente; o Claude sugere a correção, mas uma pessoa sempre aprova-a. Atualmente está disponível como uma prévia limitada de pesquisa para clientes Enterprise e Equipes, com acesso gratuito para mantenedores de código aberto.
