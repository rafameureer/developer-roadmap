# claude "query"

O comando `claude "query"` permite iniciar o REPL interativo do Claude Code com uma instrução inicial já fornecida. Ao passar uma string como argumento diretamente após o comando `claude`, o assistente iniciará imediatamente o processamento da solicitação—como "explicar este projeto" ou "corrigir os erros de lint"—assim que a interface carregar. Este método é mais eficiente do que abrir a ferramenta primeiro e digitar sua solicitação manualmente, pois combina a inicialização e a tarefa inicial em um único passo, mantendo a sessão aberta para conversas adicionais e ações de follow-up.
