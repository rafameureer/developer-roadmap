# CLAUDE.md

[CLAUDE.md](http://CLAUDE.md) é um arquivo markdown específico do projeto que atua como a "memória persistente" e manual de orientação para o Claude Code, garantindo que o AI siga seus padrões de desenvolvimento únicos em cada sessão. Como o Claude começa cada nova interação com um contexto em branco, este arquivo é lido automaticamente ao iniciar para fornecer informações essenciais sobre o projeto "POR QUE", "O QUE" e "COMO".
