# Context

A janela de contexto é a quantidade total de informações que um modelo pode armazenar em sua memória ativa ao mesmo tempo, incluindo seu histórico de conversas, os arquivos que ele leu e os resultados de quaisquer comandos terminais que ele executou. Ela funciona como um espaço de trabalho temporário onde cada palavra e símbolo (contado como tokens) preenchem uma capacidade limitada. À medida que essa janela se preenche, o Claude Code pode começar a "esquecer" detalhes mais antigos ou se tornar menos preciso, por isso gerenciar o contexto através de comandos como `/compact` é essencial para manter as respostas afiadas e custos sob controle.
