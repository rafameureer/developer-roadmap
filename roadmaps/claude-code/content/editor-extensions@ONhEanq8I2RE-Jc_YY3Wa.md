# CLaude Code no Editor de Código

As extensões do IDE permitem que você use o Claude Code diretamente em ambientes de desenvolvimento populares como Visual Studio Code e a família JetBrains (incluindo IntelliJ IDEA, PyCharm e WebStorm). Essas extensões fornecem uma barra lateral gráfica e visualizadores de diferenças em linha, permitindo que você revise as alterações de código propostas lado a lado com seus arquivos existentes. Ao integrar-se com o IDE, o Claude ganha uma consciência automática do seu espaço de trabalho ativo, seleção de arquivo atual e até mesmo mensagens de erro do terminal, eliminando a necessidade de copiar e colar contexto manualmente.
