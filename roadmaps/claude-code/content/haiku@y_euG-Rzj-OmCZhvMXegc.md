# Haiku

Claude Haiku é o modelo mais rápido e econômico da família Claude, especificamente projetado para tarefas de alta velocidade e volume que exigem uma resposta instantânea. Ele oferece uma solução compacta mas poderosa para aplicativos em tempo real como chatbots de suporte ao cliente, extração rápida de dados e moderação de fluxos de conteúdo grandes onde baixa latência é crítica.
