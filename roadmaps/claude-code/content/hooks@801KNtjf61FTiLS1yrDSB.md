# Hooks

Hooks são gatilhos automatizados que executam scripts ou comandos específicos em pontos-chave no fluxo de trabalho da IA, como antes ou depois do assistente realizar uma tarefa. Esses hooks permitem aos desenvolvedores impor padrões de projeto e garantir a confiabilidade do sistema sem intervenção manual, muito como os gatilhos Git, mas projetados para um ciclo de desenvolvimento guiado pela IA.
