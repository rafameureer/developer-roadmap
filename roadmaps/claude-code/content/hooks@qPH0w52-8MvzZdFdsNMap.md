# Ganchos (Hooks)

Ganchos são gatilhos automatizados que executam scripts ou comandos específicos em pontos-chave no fluxo de trabalho da IA, como antes ou depois do assistente realizar uma tarefa. Esses ganchos permitem que os desenvolvedores impensem padrões de projeto e garantam a confiabilidade do sistema sem intervenção manual, muito como os ganchos do Git, mas projetados para um ciclo de desenvolvimento guiado pela IA.
