# /memória

O comando `/memória` é uma ferramenta de gerenciamento de conhecimento usada para criar e gerenciar informações persistentes que sobrevivem a diferentes sessões do Claude Code. Diferentemente do comando `/compact`, que apenas otimiza a janela temporária da conversa atual, o `/memória` interage com o armazenamento permanente—principalmente o arquivo [CLAUDE.md](http://CLAUDE.md) do seu projeto e um diretório oculto de memória automática. Quando você executa esse comando, ele geralmente abre o editor de texto padrão do sistema, permitindo que você refine manualmente as convenções de codificação, decisões arquitetônicas e padrões específicos do projeto que Claude deve "lembrar" toda vez que iniciar a ferramenta nesse diretório.
