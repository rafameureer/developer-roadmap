# Canais

Para usar o Claude Code com aplicativos móveis através de canais, você instala um plug-in de canal pré-construído para sua plataforma de mensagens, como Telegram, Discord ou iMessage. O plug-in roda localmente em seu computador e consulta a API da plataforma por novas mensagens. Quando alguém envia uma mensagem para o aplicativo móvel, o plug-in recebe e encaminha para o Claude Code, que pode então ler e responder. Você configura o plug-in no arquivo de configuração MCP e o Claude Code o inicia automaticamente. O plug-in atua como um ponte entre o aplicativo móvel e o Claude Code, permitindo que você converse com o Claude através do seu telefone sem expor quaisquer URLs à internet.
