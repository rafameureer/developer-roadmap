# /model

O comando `/model` é uma utilidade de interruptor que permite alterar qual modelo de linguagem de grande escala (LLM) está fornecendo a sua sessão atual sem reiniciar o aplicativo. Isso é particularmente útil para otimização de custo desempenho; você pode usar um modelo de alta inteligência como Claude Sonnet para planejamento arquitetônico complexo e depois trocar por um modelo mais rápido e econômico como Claude Haiku para tarefas repetitivas como escrever código em branco ou testes unitários.
