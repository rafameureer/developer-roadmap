# Modelos do Claude Code

O Claude Code é alimentado por três modelos distintos - Opus, Sonnet e Haiku - cada um otimizado para um papel específico na ciclo de vida de desenvolvimento. **Claude Opus** é o "pensador profundo" e arquiteto primário, usado para raciocínio complexo, design de sistemas de alto nível e correções de bugs cirúrgicas em grandes bases de código. **Claude Sonnet** atua como o "construtor versátil", fornecendo um meio-termo de alta velocidade para tarefas diárias como implementar lógica de recursos, escrever código em branco e gerenciar estado em vários arquivos. **Claude Haiku** é o "especialista em resposta rápida", projetado para execução instantânea de tarefas leves, como a geração de protótipos UI rápidos, redação de mensagens de commit ou atuar como sub-agentes paralelos para escanear logs e executar verificações rápidas.
