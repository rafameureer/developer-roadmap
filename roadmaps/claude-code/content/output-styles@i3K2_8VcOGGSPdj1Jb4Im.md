# Estilos de Saída

O Claude Code permite que você troque entre diferentes estilos de saída para adaptar a personalidade e a verbosidade do agente às suas necessidades específicas, modificando efetivamente seu prompt de sistema central. Além do modo padrão de codificação, você pode usar estilos integrados como Explicativo, que fornece insights educacionais sobre as escolhas de implementação, ou Aprendizagem, um modo colaborativo onde o Claude marca `TODO(human)` para encorajar a contribuição prática.
