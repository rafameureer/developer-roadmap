# Modos de Permissão

Claude Code oferece vários modos de permissão que definem o equilíbrio entre autonomia e segurança durante sua sessão, variando desde o modo Plan, que restringe Claude a um estado somente leitura para exploração e estratégia sem nenhuma execução de ferramenta, até o modo BypassPermissions (geralmente chamado de "modo YOLO"), que concede ao AI toda autonomia para executar qualquer comando ou editar qualquer arquivo sem interrupção.
