# PostToolUse

O `PostToolUse` é um evento de ciclo de vida reativo que dispara imediatamente após uma ferramenta (como Bash, Write, Edit ou uma ferramenta MCP personalizada) concluir sua execução. Enquanto o `PreToolUse` atua como um guarda para bloquear ações, o `PostToolUse` é projetado para automação, limpeza e controle de qualidade—garantindo que cada ação que Claude tome esteja em conformidade com os padrões do seu projeto.
