# Caching de Prompt

O caching de prompt no Claude Code é uma funcionalidade que otimiza o desempenho armazenando os "prefixos" frequentemente usados em suas conversas—como seu estado completo do código, instruções do sistema e definições de ferramenta—para que não precisem ser reprocessados a partir do zero com cada novo mensagem. Em um ambiente agente onde Claude frequentemente lê seus arquivos várias vezes para manter o contexto, o caching atua como um "sistema de ponto de verificação": enquanto a inicialização no cache carrega uma pequena taxa adicional, todas as interações subsequentes que reutilizam esse prefixo recebem um desconto de 90% nos tokens de entrada e até 85% na latência. O Claude Code lida com isso automaticamente colocando "pontos de interrupção de cache" em pontos estratégicos no prompt (como após o [CLAUDE.md](http://CLAUDE.md) e a estrutura do projeto), garantindo que mesmo à medida que sua conversa cresce, a "base estática" do seu projeto permaneça imediatamente acessível e econômica.
