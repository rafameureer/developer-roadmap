# Cacheamento de Prompt

O cacheamento de prompt no Claude Code é uma função de otimização de desempenho que armazena os "prefixos" frequentemente usados em suas conversas—como seu estado completo do código, instruções do sistema e definições de ferramentas—para que não precisem ser reprocessados do zero com cada nova mensagem. Em um ambiente agente onde o Claude lê frequentemente seus arquivos várias vezes para manter o contexto, o cacheamento atua como um "sistema de ponto de verificação": enquanto a primeira gravação no cache carrega uma pequena taxa adicional, toda interação subsequente que reutiliza esse prefixo recebe um desconto de 90% nos tokens de entrada e até uma redução de 85% na latência. O Claude Code lida com isso automaticamente colocando "pontos de interrupção de cache" em pontos estratégicos no prompt (como após o seu CLAUDE.md e estrutura do projeto), garantindo que, mesmo à medida que sua conversa cresce, a "base estática" do seu projeto permaneça imediatamente acessível e econômica.
