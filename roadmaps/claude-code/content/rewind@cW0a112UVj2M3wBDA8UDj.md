# Desfazendo Conversas

Para desfazer uma conversa no Claude Code, você pode usar o comando de barra `/rewind` ou a combinação de teclas `Esc + Esc` para abrir o menu interativo de pontos de verificação. Esta funcionalidade aproveita a ferramenta de captura automática de snapshots, que cria um ponto de restauração para cada prompt do usuário e modificação de arquivo durante sua sessão.
