# SessionEnd

O evento de ciclo de vida `SessionEnd` é um evento de desmontagem que é acionado quando você sai do Claude Code ou termina uma sessão. Enquanto `SessionStart` é para preparação, `SessionEnd` é sua janela dedicada para limpeza, arquivamento e relatório final. Ele garante que seu ambiente esteja em um estado limpo e que qualquer métrica de sessão importante seja capturada antes do processo ser fechado completamente.
