# SessionStart

O evento de ciclo de vida `SessionStart` é um evento de inicialização que é acionado no início muito cedo de uma interação do Claude Code. Diferentemente de outros hooks que reagem a prompts ou edições de arquivos específicos do usuário, `SessionStart` está projetado para iniciar seu ambiente e injetar contexto de alta prioridade antes mesmo do primeiro prompt ser processado.
