# Melhores Práticas para Habilidades

Ao configurar habilidades de Claude Code, a prática principal é otimizar para a descoberta e eficiência do contexto usando frontmatter YAML preciso e "carregamento perezoso". A descrição da sua habilidade deve atuar como um gatilho semântico claro, usando palavras-chave específicas que ajudem Claude a identificar exatamente quando ativar as instruções de especialista, sem distorcer o contexto de cada conversa. Estruture o `SKILL.md` com uma abordagem modular e focada em um escopo estreito, em vez de criar uma "Kit de ferramentas Swiss Army". Se um fluxo de trabalho tiver efeitos secundários não negociáveis, use `disable-model-invocation: true` para garantir que ele só seja executado quando acionado manualmente por meio de um comando de barra. Além disso, aproveite os espaços reservados de argumentos (como `$ARGUMENTS`) para tornar suas habilidades reutilizáveis em diferentes arquivos e armazene-as no diretório `.claude/skills/` do seu projeto para que sejam controladas pela versão e compartilhadas com sua equipe. Finalmente, mantenha as instruções das habilidades determinísticas fornecendo sequências de ferramentas passo a passo, o que garante que Claude siga o "caminho dourado" do seu projeto para tarefas complexas como implantações ou auditorias de segurança.
