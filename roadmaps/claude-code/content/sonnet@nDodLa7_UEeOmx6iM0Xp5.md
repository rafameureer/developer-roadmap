# Sonnet

O Claude Sonnet é um modelo de linguagem de alto desempenho que equilibra perfeitamente a inteligência de raciocínio avançado e a velocidade rápida de processamento. Ele atua como o "cavalheiro de trabalho" da família Claude, capaz de lidar com tarefas de programação complexas, como refatoração multi-arquivo e depuração autônoma, enquanto opera significativamente mais rápido e de forma mais econômica do que o modelo Opus de nível superior.
