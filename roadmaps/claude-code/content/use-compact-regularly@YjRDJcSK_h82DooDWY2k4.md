# Use /compact e /clear

Usar regularmente `/compact` e `/clear` é a maneira mais eficaz de prevenir "rot do contexto" e gerenciar custos crescentes da API enquanto trabalha com Claude Code. Porque Claude reprocessa toda a sua história de conversação com cada novo mensagem, uma sessão que acumulou milhares de linhas de saída de terminal e diffs de arquivos eventualmente se tornará cara, lenta e propensa a "esquecer" instruções iniciais. Usar `/compact` permite resumir longas discussões de pesquisa ou depuração em um conjunto conciso de principais descobertas, efetivamente "zipando" a conversa para que você possa continuar sem perder o progresso essencial. Por outro lado, `/clear` é vital quando se passa para uma tarefa não relacionada; ele limpa o histórico atual para fornecer um tablado limpo.
