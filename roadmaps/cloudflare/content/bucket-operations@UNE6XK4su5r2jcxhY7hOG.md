# Operações de Bucket

No Cloudflare R2, os buckets são contêineres para armazenar objetos. Você pode realizar várias operações de bucket, incluindo:

- **Criando Buckets:** Criar novos buckets para organizar seus dados.
- **Listando Buckets:** Listar todos os buckets em sua conta.
- **Excluindo Buckets:** Excluir buckets que não forem mais necessários (deve estar vazio).
- **Configurando Políticas de Bucket:** Definir políticas de controle de acesso para buckets.

Essas operações são geralmente realizadas usando a API R2, o painel do Cloudflare ou ferramentas de linha de comando como `wrangler`.

Acesse os seguintes recursos para saber mais:

- [@oficial@Buckets · Cloudflare R2](https://developers.cloudflare.com/r2/buckets/)
- [@oficial@Criar Novos Buckets · Cloudflare R2](https://developers.cloudflare.com/r2/buckets/create-buckets/)
