# Fundamentos do JavaScript

JavaScript é um linguagem de programação versátil e de alto nível, principalmente usada para adicionar interatividade e recursos dinâmicos a sites. Ele roda no navegador, permitindo scripting do lado do cliente que pode manipular HTML e CSS, responder a eventos do usuário e interagir com APIs da web.

JavaScript é uma linguagem fundamental para os Workers do Cloudflare, permitindo que você escreva funções de servidor sem estado que rodem na rede de borda do Cloudflare. Você usará o JavaScript para interceptar e modificar solicitações e respostas HTTP, personalizar o comportamento do site e construir aplicações dinâmicas. Entender os fundamentos do JavaScript como variáveis, funções, programação assíncrona (Promises, async/await) e manipulação do DOM é crucial para o desenvolvimento eficaz dos Workers do Cloudflare. Você também pode usar TypeScript, que se compila em JavaScript, oferecendo benefícios de tipagem estática.
