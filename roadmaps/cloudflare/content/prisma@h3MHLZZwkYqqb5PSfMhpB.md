# Prisma

Prisma é um ORM popular de código aberto que fornece um cliente de banco de dados tipado e ferramentas de migração. Embora não seja diretamente compatível com o Cloudflare D1 devido à sua dependência em adaptadores específicos de banco de dados, o Prisma pode ser usado em conjunto com um adaptador D1 ou uma camada de acesso a dados personalizada dentro dos seus Trabalhos do Cloudflare. Esse abordagem permite que você aproveite as funcionalidades de segurança tipada, construtor de consultas e migrações do Prisma enquanto ainda usa o D1 como seu banco de dados.
