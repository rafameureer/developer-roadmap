# Cabeçalhos de Segurança Web

Os cabeçalhos de segurança web são cabeçalhos HTTP de resposta que aumentam a segurança do site. O Cloudflare permite configurar esses cabeçalhos facilmente para proteger contra ataques comuns. Os cabeçalhos-chave incluem:

- **Política de Segurança de Conteúdo (CSP):** Controla os recursos que o navegador pode carregar.
- **Strict-Transport-Security (HSTS):** Força conexões HTTPS.
- **X-Frame-Options:** Previne ataques de clickjacking.
- **X-XSS-Protection:** Habilita a filtragem XSS nos navegadores.
- **Referrer-Policy:** Controla as informações do referente enviadas com solicitações.

O Cloudflare simplifica a configuração desses cabeçalhos, melhorando a segurança do site com esforço mínimo.
