# Algoritmo A*

O algoritmo A* é um algoritmo de navegação em grafos usado para encontrar o caminho mais curto entre dois nós em um grafo. É uma versão modificada do algoritmo de Dijkstra que usa heurísticas para encontrar o caminho mais curto. Ele é usado em busca por caminhos e navegação em grafos.
