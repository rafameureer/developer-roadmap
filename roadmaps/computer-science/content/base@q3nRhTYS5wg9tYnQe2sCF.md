# Modelo BASE

O aumento na popularidade dos bancos de dados NoSQL forneceu flexibilidade e fluidez na manipulação de dados, e como resultado, um novo modelo de banco de dados foi projetado que reflete essas propriedades. O acrônimo BASE é ligeiramente mais confuso do que ACID; no entanto, as palavras por trás dele destacam como o modelo BASE difere. BASE significa:

*   **B**asicamente **A**vailable
*   **S**tado suave
*   **E**ventualmente consistente
