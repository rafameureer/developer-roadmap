# Árvore de Busca Binária

Uma árvore de busca binária, também chamada de árvore ordenada ou balanceada, é uma estrutura de dados em forma de árvore binária com a chave de cada nó interno sendo maior que todas as chaves na subárvore esquerda respectiva e menor que as chaves na subárvore direita.
