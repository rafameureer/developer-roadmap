# Ordenação por Bolha

Ordenação por bolha é um algoritmo de ordenação simples que percorre repetidamente a lista, compara elementos adjacentes e os troca se estiverem na ordem errada. O percurso pela lista é repetido até que a lista esteja ordenada.
