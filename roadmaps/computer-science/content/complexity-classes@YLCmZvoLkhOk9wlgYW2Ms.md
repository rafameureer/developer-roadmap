# Classes de Complexidade

Na ciência da computação, existem alguns problemas cujas soluções ainda não foram encontradas. Esses problemas são divididos em classes conhecidas como Classes de Complexidade. Na teoria da complexidade, uma Classe de Complexidade é um conjunto de problemas com complexidades relacionadas. Essas classes ajudam os cientistas a agrupar problemas com base no tempo e espaço que eles requerem para resolver problemas e verificar as soluções. É a ramificação da teoria da computação que lida com os recursos necessários para resolver um problema.
