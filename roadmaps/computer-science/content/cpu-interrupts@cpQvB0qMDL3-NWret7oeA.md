# Interrupções da CPU

As Interrupções da CPU são uma maneira pela qual a CPU se comunica com o resto do computador. Elas são uma forma pela qual a CPU informa ao resto do computador que ele precisa fazer algo. Por exemplo, se a CPU estiver executando um programa e precisar ler do teclado, ela enviará uma interrupção para o teclado para pedir que ele envie os dados para a CPU. A CPU então aguardará até que o teclado envie os dados e depois continuará executando o programa.
