# Bancos de Dados

Um banco de dados é uma coleção de dados úteis de uma ou mais organizações relacionadas estruturados de forma a tornar os dados um ativo para a organização. Um sistema de gerenciamento de banco de dados é um software projetado para auxiliar na manutenção e extração de grandes conjuntos de dados de maneira eficiente.
