# Índices de Banco de Dados

Um índice é uma estrutura de dados que você constrói e atribui sobre uma tabela existente, basicamente procurando em sua tabela para analisar e resumir, para que possa criar atalhos.

Acesse os seguintes recursos para saber mais:
