# Instruções e Programas

As instruções são os comandos mais básicos que um CPU pode entender, direcionando-o a realizar ações específicas como adicionar números ou mover dados. Por outro lado, um programa é uma coleção dessas instruções, organizadas em sequência para atingir uma tarefa específica. Imagine as instruções como palavras individuais e o programa como uma frase completa ou história; o CPU executa essas instruções uma por uma, seguindo a lógica do programa, para alcançar o resultado desejado.
