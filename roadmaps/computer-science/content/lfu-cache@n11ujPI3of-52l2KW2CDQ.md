# Cache LFU

O Cache LFU é uma estrutura de dados que armazena pares chave-valor. Ele tem um tamanho fixo e quando está cheio, remove o par chave-valor menos frequentemente usado. É uma variação do Cache LRU e é usada em muitas aplicações como cache de páginas web, cache de consultas de banco de dados e cache de imagens.
