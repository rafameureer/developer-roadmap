# Listas Encadeadas

Arrays armazenam elementos em locais de memória contíguos, resultando em endereços de elementos facilmente calculáveis e permitindo um acesso mais rápido a um elemento em um índice específico. As listas encadeadas têm uma estrutura de armazenamento menos rígida e os elementos geralmente não são armazenados em locais contíguos, portanto, precisam ser armazenados com tags adicionais fornecendo uma referência ao próximo elemento. Esta diferença na esquema de armazenamento de dados determina qual estrutura de dados será mais adequada para uma situação específica.
