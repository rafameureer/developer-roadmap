# OSI e Modelo TCP/IP

O modelo OSI e o modelo TCP/IP são usados para ajudar o desenvolvedor a projetar seu sistema para interoperabilidade. O modelo OSI tem 7 camadas, enquanto o modelo TCP/IP tem uma forma resumida do modelo OSI, composta apenas por 4 camadas. Isso é importante se você estiver tentando projetar um sistema para comunicar-se com outros sistemas.
