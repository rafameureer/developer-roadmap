# Escolha uma Linguagem

Você precisa escolher um idioma de programação para aprender os conceitos da Ciência da Computação. Minha recomendação pessoal é escolher C++ ou C, e o motivo para isso é:

*   Eles permitem lidar com ponteiros e alocação/desalocação de memória, então você se sente as estruturas de dados e algoritmos na pele. Em linguagens de nível superior como Python ou Java, essas coisas são ocultas para você. No trabalho diário, isso é ótimo, mas quando você está aprendendo como essas estruturas de dados de baixo nível são construídas, é incrível sentir-se perto do metal.
*   Você poderá encontrar muitos recursos para os tópicos listados nesta rota usando C ou C++. Você pode encontrar muitos recursos para Python e Java, mas eles não são tão abundantes quanto C++ e C.
