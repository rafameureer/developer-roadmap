# REST

REST, ou Transferência de Estado Representacional (Representational State Transfer), é um estilo arquitetônico que fornece padrões entre sistemas computacionais na web, tornando mais fácil para os sistemas se comunicarem entre si.

- [@artigo@Aprenda REST: Um Tutorial RESTful](https://restapitutorial.com/)
