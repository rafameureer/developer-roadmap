# Algoritmo de Rabin-Karp

O algoritmo de Rabin-Karp é um algoritmo de busca em cadeias que usa hashing para encontrar qualquer uma das strings de padrão em um texto. Para strings de comprimento médio `n`, ele funciona em `O(n+m)` tempo com `O(m)` espaço, onde `m` é o comprimento do padrão. Ele é frequentemente usado na bioinformática para buscar padrões de DNA.
