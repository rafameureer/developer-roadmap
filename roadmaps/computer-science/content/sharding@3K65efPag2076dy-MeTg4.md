# Particionamento de Banco de Dados

O particionamento de banco de dados é um método de distribuir dados em várias máquinas. É uma técnica de escala horizontal, em oposição à escala vertical, que envolve adicionar mais potência a uma única máquina. O particionamento é uma maneira comum de dimensionar um banco de dados.
