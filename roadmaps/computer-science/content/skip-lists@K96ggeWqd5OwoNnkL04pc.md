# Listas de Pular

As listas de pular são uma estrutura de dados que permite realizar operações em uma lista ordenada em O(log n) tempo. As listas de pular são uma estrutura de dados probabilística, o que significa que a probabilidade de uma certa operação levar um certo período de tempo é um valor determinado. No caso das listas de pular, a probabilidade de uma operação levar O(log n) tempo é 1.
