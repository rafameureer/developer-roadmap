# SQL vs Bancos de Dados NoSQL

SQL significa Linguagem de Consulta Estruturada. É usada para bancos de dados relacionais. Um banco de dados SQL é uma coleção de tabelas que armazena um conjunto específico de dados estruturados. Alguns exemplos são PostgreSQL, MySQL, MariaDB etc.

NoSQL significa Não-SQL. É usada para bancos de dados não-relacionais. Um banco de dados NoSQL é uma coleção de coleções que armazena um conjunto específico de dados não-estruturados. Alguns exemplos são MongoDB, CouchDB, Redis etc.
