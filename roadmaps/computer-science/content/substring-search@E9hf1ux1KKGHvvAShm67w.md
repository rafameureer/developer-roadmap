# Busca de Substring

A busca de substring é o problema de encontrar uma substring em uma string. É um problema muito comum na ciência da computação, e há muitos algoritmos para resolver isso.

Acesse os seguintes recursos para saber mais:

- [@curso@Introdução à Busca de Substring](https://www.coursera.org/lecture/algorithms-part2/introduction-to-substring-search-n3ZpG)
- [@artigo@Qual é o algoritmo de busca de substring mais rápido?](https://stackoverflow.com/questions/3183582/what-is-the-fastest-substring-search-algorithm)
- [@artigo@Exercícios de Busca de Substring](https://algs4.cs.princeton.edu/53substring/)
