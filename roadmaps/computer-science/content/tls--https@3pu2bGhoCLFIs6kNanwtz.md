# TLS / HTTPS

TLS (Transport Layer Security) é um protocolo criptográfico que fornece privacidade e integridade de dados entre duas aplicações em comunicação. É amplamente usado para segurar o HTTP, embora possa ser usado com qualquer protocolo. TLS geralmente é usado em combinação com HTTPS, que é o HTTP sobre TLS.
