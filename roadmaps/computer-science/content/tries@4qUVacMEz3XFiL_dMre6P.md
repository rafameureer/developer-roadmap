# Estruturas de Dados Trie

As estruturas de dados Trie são usadas para armazenar strings. A ideia é armazenar os caracteres da string em uma estrutura de árvore, onde cada nó da árvore representa um único caractere. Podemos usar essa estrutura para armazenar strings de maneira que possamos pesquisar rapidamente strings com um prefixo comum.
