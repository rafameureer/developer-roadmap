# Fases do Compilador

O processo de compilação em C++ transforma o código-fonte legível por humanos em um programa executável através de quatro fases distintas. Essas fases incluem: Pré-processamento, que lida com diretivas como `#include` e substituições de macros; Compilação, onde o código pré-processado é traduzido para linguagem de montador; Montagem, que converte o código de montador em código objeto; e Ligação, onde o código objeto é combinado com bibliotecas para criar o programa executável final. Cada fase executa um conjunto específico de tarefas para garantir que o código seja transformado corretamente para a execução na plataforma-alvo.
