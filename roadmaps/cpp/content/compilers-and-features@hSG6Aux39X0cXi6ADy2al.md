# Compiladores e Funcionalidades

Os compiladores C++ traduzem o código-fonte legível em C++ para código executável por máquina. Eles oferecem várias funcionalidades, incluindo técnicas de otimização para melhorar a performance do programa eliminando redundâncias e reestruturando o código, geração de informações de depuração para auxiliar no troubleshooting, e sistemas de advertência para sinalizar potencialmente código problemático. Compiladores populares incluem GCC, uma opção aberta e versátil; Clang, conhecido por sua compatibilidade e diagnósticos; Microsoft Visual C++, integrado ao IDE Visual Studio; e o Intel C++ Compiler, parte da suite Intel Parallel Studio XE. Familiarize-se com a documentação do compilador escolhido é essencial para aproveitar plenamente suas capacidades.
