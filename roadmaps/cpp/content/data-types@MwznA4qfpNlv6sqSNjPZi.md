# Tipos de Dados

Os tipos de dados em C++ categorizam o tipo de valores que uma variável pode conter, influenciando a utilização de memória e as operações permitidas. O C++ oferece tipos fundamentais como `int` para inteiros, `float` e `double` para números de ponto flutuante, `char` para caracteres individuais e `bool` para valores lógicos. Além desses básicos, os tipos derivados como arrays, ponteiros e referências fornecem capacidades mais complexas de manipulação de dados. Finalmente, os usuários podem definir seus próprios tipos usando estruturas, classes e uniões para criar organizações de dados personalizadas.
