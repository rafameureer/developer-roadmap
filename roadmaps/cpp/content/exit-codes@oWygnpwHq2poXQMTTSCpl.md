# Códigos de Saída

Os códigos de saída são valores numéricos retornados por um programa ao sistema operacional ao concluir, sinalizando se a execução foi bem-sucedida ou se ocorreram erros. Um valor de retorno de 0 geralmente indica sucesso, enquanto valores não-zero denotam falha, com o significado específico de cada código não-zero sendo dependente da aplicação. Em C++, você pode especificar o código de saída usando a declaração `return` dentro da função `main` ou chamando a função `exit()` do cabeçalho `<cstdlib>`.
