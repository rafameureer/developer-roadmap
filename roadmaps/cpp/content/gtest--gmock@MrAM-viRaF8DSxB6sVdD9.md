# Google Test e Google Mock

Google Test e Google Mock são frameworks de teste unitário em C++ de código aberto desenvolvidos pela Google. O Google Test é um framework independente para escrever e executar testes unitários, enquanto o Google Mock estende-o com capacidades de mock poderosas. GMock é especialmente útil para testar componentes que interagem com utilitários externos ou de terceiros.
