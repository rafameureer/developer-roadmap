# Introdução à Linguagem

O C++ é um idioma de programação de propósito geral conhecido por sua performance, eficiência e controle sobre o hardware. Ele suporta tanto paradigmas de programação procedural quanto orientados a objetos, tornando-o versátil para uma ampla gama de aplicações, desde programação de sistemas até desenvolvimento de jogos. O C++ se baseia no idioma C, adicionando recursos como classes, templates e tratamento de exceções.
