# Idioma Pimpl

O idioma Pimpl (Pointer to Implementation) é uma técnica em C++ usada para ocultar os detalhes de implementação de uma classe. Isso é feito declarando uma classe de implementação privada e mantendo um ponteiro dela dentro da classe principal. A interface pública permanece limpa, e as dependências de tempo de compilação são significativamente reduzidas. Isso promove uma melhor organização do código, reduz o tempo de recompilação e melhora a compatibilidade binária.
