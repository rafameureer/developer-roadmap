# spdlog

spdlog é uma biblioteca de registro em tempo real e multiplataforma para C++. Ela oferece uma interface simples para escrever mensagens de log em diferentes destinos, como o console, arquivos ou sumidouros personalizados. Ele suporta vários níveis de log, opções de formatação e registro assíncrono, tornando-o adequado para projetos que exigem capacidades eficientes e flexíveis de registro.
