# Padrões em C++

Os padrões em C++ são conjuntos de regras e diretrizes que definem o idioma de programação C++. Esses padrões garantem consistência e portabilidade entre diferentes compiladores e plataformas. Cada padrão apresenta novos recursos, melhorias e às vezes descontinua funcionalidades mais antigas. O padrão atual é o C++23.
