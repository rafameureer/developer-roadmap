# TensorFlow

O TensorFlow é uma biblioteca de software de código aberto desenvolvida pela Google, principalmente usada para cálculos numéricos e aprendizado em escala. Ele permite aos desenvolvedores criar e treinar modelos de aprendizado de máquina usando uma variedade de ferramentas, bibliotecas e recursos da comunidade. O TensorFlow se concentra em tarefas de aprendizado profundo como reconhecimento de imagens, processamento de linguagem natural e análise de séries temporais.
