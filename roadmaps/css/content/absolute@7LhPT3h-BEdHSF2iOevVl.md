# Posicionamento Absoluto em CSS

O posicionamento absoluto em CSS permite que você coloque um elemento com precisão em relação ao seu antepassado mais próximo que tenha um valor de posição diferente de `static`. Se não houver tal antepassado, o elemento será posicionado em relação à bloco contêiner inicial, que geralmente é o elemento `<html>`. Os elementos com `position: absolute` são removidos do fluxo normal do documento, o que significa que eles não afetam a posição de outros elementos ao seu redor.
