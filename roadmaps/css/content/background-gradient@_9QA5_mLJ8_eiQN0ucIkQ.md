# Gradiente de Fundo

Os gradientes de fundo em CSS permitem criar transições suaves entre duas ou mais cores para o fundo de um elemento. Em vez de uma cor sólida, você pode definir um gradiente que mistura as cores juntas, adicionando profundidade visual e interesse aos seus designs. Esses gradientes podem ser lineares (flutuando em linha reta), radiais (emanação a partir de um ponto central) ou cônicas (rotacionando em torno de um ponto central).
