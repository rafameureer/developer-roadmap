# Posição do Fundo

A posição de fundo em CSS controla onde uma imagem de fundo é colocada dentro de seu elemento. Ele permite especificar a colocação horizontal e vertical da imagem, usando palavras-chave como `top`, `bottom`, `left`, `right` e `center`, ou com valores numéricos (pixels, porcentagens, etc.) para ajustar exatamente a localização. Esta propriedade é útil para alinhar imagens de fundo de maneiras específicas, criar efeitos visuais ou garantir que partes importantes da imagem sempre estejam visíveis.
