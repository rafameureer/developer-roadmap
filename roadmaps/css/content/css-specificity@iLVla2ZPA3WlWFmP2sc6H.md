# Especificidade CSS

Especificidade CSS é o conjunto de regras que os navegadores usam para determinar quais declarações de CSS se aplicam a um elemento quando múltiplas regras conflitantes existem. É essencialmente um sistema de pontuação que prioriza certos seletores CSS sobre outros, garantindo que o estilo mais relevante seja aplicado. Entender especificidade é crucial para controlar como seus estilos CSS são aplicados e resolver problemas de estilização inesperados.
