# CSS

CSS (Cascading Style Sheets) é uma linguagem usada para descrever a apresentação de um documento escrito em HTML ou XML. Ela controla o layout, cores, fontes e outros aspectos visuais das páginas da web, garantindo uma experiência de usuário consistente e visualmente agradável em diferentes dispositivos e tamanhos de tela. Essencialmente, CSS separa o conteúdo de uma página da web de seu design, tornando os sites mais fáceis de manter e atualizar.
