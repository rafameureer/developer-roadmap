# Exibição

A propriedade `display` no CSS controla como um elemento é renderizado em uma página da web, especificamente definindo seu tipo de caixa e como ele interage com outros elementos. Ela determina se um elemento é tratado como um elemento de nível de bloco (ocupando toda a largura disponível), um elemento em linha (flutuando dentro do texto) ou algo completamente diferente, como uma tabela ou um contêiner de grade. Esta propriedade é fundamental para controlar o layout e a estrutura das páginas da web.
