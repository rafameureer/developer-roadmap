# CSS Externo

O CSS externo envolve escrever regras de CSS em um arquivo separado (com a extensão `.css`) e, em seguida, vincular esse arquivo ao seu documento HTML. Este método promove código limpo, manutenção mais fácil e reutilização de estilos em várias páginas da web. Ao separar o estilo do conteúdo, você pode modificar o visual e o layout do seu site sem alterar a estrutura HTML.
