# Abreviação de Fonte

A propriedade abreviada `font` em CSS oferece uma maneira de definir várias propriedades relacionadas a fontes em uma única declaração. Em vez de especificar individualmente `font-style`, `font-variant`, `font-weight`, `font-size`, `line-height` e `font-family`, você pode usar a propriedade `font` para definir todas elas de uma só vez, tornando seus folhos mais concisos e legíveis.

Acesse os seguintes recursos para saber mais:

- [@artigo@Abreviação de fonte](https://developer.mozilla.org/pt-BR/docs/Web/CSS/font)
