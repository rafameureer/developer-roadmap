# Tamanho da Fonte

O tamanho da fonte em CSS determina o tamanho do texto em uma página web. É uma propriedade fundamental que controla a prominência visual e a legibilidade dos elementos de texto. Você pode especificar tamanhos de fonte usando várias unidades como pixels (px), ems (em), rems (rem), porcentagens (%) e unidades de viewport (vw, vh). Escolher o tamanho da fonte certo é crucial para criar um design visualmente atraente e acessível.
