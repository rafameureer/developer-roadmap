# Cores HSL

O HSL (Hue, Saturation, Lightness) é uma maneira de definir cores em CSS usando três componentes: Hue, que representa o tipo de cor em um círculo de cores (0-360 graus); Saturation, que indica a intensidade da cor (0-100%); e Lightness, que determina como brilhante ou escuro é a cor (0-100%). Este modelo oferece uma maneira mais intuitiva de ajustar cores em comparação com o RGB, permitindo aos desenvolvedores criar facilmente variações de uma cor modificando seus valores de Hue, Saturation ou Lightness.
