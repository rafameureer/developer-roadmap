# HTML

HTML (HyperText Markup Language) é o padrão de linguagem de marcação para criar páginas web. Ele fornece a estrutura e conteúdo de um site, usando elementos para definir cabeçalhos, parágrafos, imagens, links e outros componentes que são exibidos em um navegador da web. O HTML forma a base sobre a qual o CSS e JavaScript se construem para criar experiências web visualmente atraentes e interativas.
