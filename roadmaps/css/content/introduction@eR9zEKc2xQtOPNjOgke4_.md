# CSS

CSS (Cascading Style Sheets) é uma linguagem usada para descrever a apresentação de um documento escrito em HTML ou XML, incluindo cores, layout e fontes. Ele permite separar o conteúdo do seu site (HTML) da sua design visual, tornando os sites mais manteráveis e adaptáveis. O CSS usa regras para definir como os elementos devem ser exibidos, alvo de elementos HTML específicos ou grupos de elementos.
