# Layout em Colunas Múltiplas

O layout em colunas múltiplas no CSS permite dividir um bloco de conteúdo em várias colunas, semelhante a layouts de jornais. Esta funcionalidade habilita o texto e outros conteúdos a fluirem automaticamente de uma coluna para a próxima, melhorando a legibilidade e eficiência do espaço na tela, especialmente para artigos ou listas mais longos. Você pode controlar o número de colunas, o espaço entre elas e uma linha (regra) entre as colunas para separação visual.
