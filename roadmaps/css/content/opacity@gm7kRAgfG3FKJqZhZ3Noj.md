# Opacidade

A opacidade em CSS controla a transparência de um elemento. Determina quão visível é o fundo atrás do elemento. Um valor de `1` significa que o elemento é completamente opaco (não transparente), enquanto um valor de `0` significa que ele é completamente transparente (invisível). Valores entre `0` e `1` criam diferentes graus de transparência.
