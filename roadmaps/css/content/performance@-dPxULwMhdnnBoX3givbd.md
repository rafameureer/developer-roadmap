# Desempenho

O desempenho do CSS refere-se à eficiência com que o código CSS é processado e renderizado pelo navegador, afetando a velocidade e a resposta de um site. Otimizar o CSS para o desempenho envolve técnicas como minimizar o tamanho dos arquivos, reduzir a complexidade dos seletores e aproveitar o cache do navegador para garantir uma experiência de usuário suave.
