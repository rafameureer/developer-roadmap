# Pseudo-classe

As pseudo-classe no CSS são palavras-chave adicionadas a seletores que especificam um estado especial do elemento(s) selecionado. Eles permitem estilizar um elemento com base em coisas como interação do usuário (por exemplo, passar o mouse), sua posição na estrutura do documento (por exemplo, o primeiro filho) ou outras características de elementos (por exemplo, estar marcado). Eles permitem aplicar estilos a elementos dinamicamente sem precisar modificar o HTML ou usar JavaScript.
