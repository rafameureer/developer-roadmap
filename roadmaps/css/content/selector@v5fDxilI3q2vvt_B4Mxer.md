# Seletor

Um seletor é uma parte fundamental de uma regra CSS. É essencialmente um padrão que identifica quais elementos HTML a regra deve ser aplicada. Os seletores podem alvo de elementos com base em seu nome de tag, classe, ID, atributos ou sua relação com outros elementos no documento.

Acesse os seguintes recursos para saber mais:

- [@article@CSS selectors](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_selectors)
