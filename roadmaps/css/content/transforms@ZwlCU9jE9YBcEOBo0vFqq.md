# Transformações

As transformações no CSS permitem alterar a forma e posição dos elementos em um espaço bidimensional ou tridimensional. Isso inclui operações como rotação, escala, inclinação e translação de elementos, fornecendo uma maneira de criar efeitos visuais envolventes e manipular o layout sem afetar a fluxo do documento subjacente.
