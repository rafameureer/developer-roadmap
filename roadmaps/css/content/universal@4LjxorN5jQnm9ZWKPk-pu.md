# Seletor Universal

O seletor universal em CSS é um seletor simples que corresponde a qualquer elemento em uma página web. Representado por um asterisco (\*), ele aplica um estilo específico a todos os elementos, independente de seu tipo ou posição na árvore do documento. Ele é frequentemente usado para resetar ou normalizar estilos em diferentes navegadores, garantindo uma aparência base consistente.
