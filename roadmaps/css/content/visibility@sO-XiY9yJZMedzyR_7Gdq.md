# Visibilidade

A propriedade `visibility` em CSS controla se um elemento é visível ou oculto. Quando a visibilidade de um elemento é definida como `hidden`, ele desaparece da página, mas o espaço que ocuparia permanece. Isso é diferente de `display: none`, que remove o elemento completamente do fluxo do documento, causando que os elementos circundantes se reorganizem.
