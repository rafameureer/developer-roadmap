# ARP

Protocolo de Resolução de Endereços (ARP) é um protocolo de comunicação usado para descobrir o endereço de camada de ligação, como um endereço MAC, associado a uma determinada camada de internet, geralmente um endereço IPv4. Em termos mais simples, quando um dispositivo deseja enviar dados para outro dispositivo na mesma rede, ele usa ARP para encontrar o endereço físico do dispositivo de destino (MAC address), para que os dados possam ser entregues corretamente. Ele funciona enviando uma solicitação de ARP de broadcast perguntando "Quem tem esse endereço IP?" e o dispositivo com esse endereço IP responde com seu endereço MAC.
