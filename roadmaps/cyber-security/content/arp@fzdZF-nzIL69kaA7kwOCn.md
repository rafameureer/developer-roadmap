# ARP

ARP, ou Protocolo de Resolução de Endereços, é um protocolo de comunicação usado para descobrir o endereço da camada de ligação (geralmente um endereço MAC) associado a uma determinada camada de internet (geralmente um endereço IPv4). Ele opera enviando uma solicitação ARP para todos os dispositivos em uma rede, pedindo ao dispositivo com o endereço IP específico responder com seu endereço MAC. Isso permite que dispositivos comuniquem-se na rede local sem precisar saber os endereços físicos uns dos outros antes.
