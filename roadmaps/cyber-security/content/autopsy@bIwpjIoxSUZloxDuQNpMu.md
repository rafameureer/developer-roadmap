# Autópsia

Autópsia é uma plataforma de forenses digitais aberta e poderosa que é principalmente usada para resposta a incidentes, investigações em segurança cibernética e recuperação de dados. Como um investigador, você pode usar o Autópsia para analisar rapidamente e eficientemente um sistema comprometido, extrair artefatos cruciais e gerar relatórios abrangentes. Integrado com o The Sleuth Kit e outros plug-ins, o Autópsia permite que os examinadores automatizem tarefas e mergulhem profundamente na estrutura de um sistema para descobrir a causa raiz de um incidente.
