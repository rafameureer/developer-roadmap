# Bash

Bash (Bourne Again Shell) é um shell e linguagem de script amplamente utilizado no Unix que atua como uma interface de linha de comando para executar comandos e organizar arquivos em seu computador. Ele permite aos usuários interagir com o sistema operacional do sistema digitando comandos de texto, servindo como alternativa à interface gráfica do usuário (GUI). O Bash, criado como uma versão gratuita e melhorada da original Bourne Shell (`sh`), é o shell padrão em muitos sistemas baseados no Unix, incluindo Linux, macOS e o Subsistema do Windows para Linux (WSL).
