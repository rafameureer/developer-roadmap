# dd para Incident Response e Descoberta

`dd` (data duplicator) é uma utilidade de linha de comando usada principalmente para copiar e converter dados. Ele opera em nível baixo, lendo e escrevendo dados bloco a bloco. Isso o torna extremamente útil para criar cópias exatas bit-a-bit de dispositivos de armazenamento, como discos rígidos ou pendrives, e imagens forenses em formatos brutos ou outros.
