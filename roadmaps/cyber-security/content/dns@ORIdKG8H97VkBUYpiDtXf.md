# Sistema de Nomes de Domínio (DNS)

O Sistema de Nomes de Domínio (DNS) é um protocolo fundamental da internet que traduz nomes de domínio legíveis por humanos, como `www.example.com`, em endereços IP, como `192.0.2.1`, que são usados pelos computadores para localizar e se comunicar entre si. Em essência, o DNS atua como o caderno telefônico da internet, permitindo que os usuários acessem sites e serviços sem precisar lembrar endereços IP numéricos. Quando um usuário digita um nome de domínio em um navegador, uma consulta DNS é enviada a um servidor DNS, que resolve o domínio em seu endereço IP correspondente, permitindo que o navegador se conecte ao servidor apropriado. O DNS é crucial para a funcionalidade da internet, pois suporta praticamente todas as atividades online garantindo que solicitações sejam direcionadas para os destinos corretos.
