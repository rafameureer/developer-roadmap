# O que é o ataque Evil Twin

Um Evil Twin é um tipo de ataque à rede sem fio onde um invasor configura um ponto de acesso Wi-Fi falso que simula uma rede Wi-Fi legítima. O ponto de acesso falso tem o mesmo SSID (nome da rede) que a rede legítima, tornando difícil para os usuários distinguir entre as duas. O objetivo do invasor é enganar os usuários para se conectar ao ponto de acesso falso, permitindo-lhes interceptar informações sensíveis, injetar malware ou lançar outros tipos de ataques.
