# GTFOBINS

GTFOBins (GTFOBINS) é uma lista curada de binários Unix que podem ser explorados por atacantes para pular as restrições de segurança locais em um sistema mal configurado. Ele fornece um índice detalhado de comandos e scripts, demonstrando como determinados binários, quando usados de forma inadequada, podem habilitar a escalada de privilégios, manipulação de arquivos e outras atividades não autorizadas, servindo como uma fonte para profissionais de segurança entenderem vulnerabilidades potenciais e para atacantes identificar e explorar fraquezas.
