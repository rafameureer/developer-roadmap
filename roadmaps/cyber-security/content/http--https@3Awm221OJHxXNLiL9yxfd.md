# HTTP / HTTPS

HTTP (Protocolo de Transferência de Hipertexto) é a base da comunicação de dados na web. Ele define como as mensagens são formatadas e transmitidas entre um servidor web e um navegador. HTTPS (HTTP Seguro) é a versão segura do HTTP, onde a comunicação é criptografada usando o Protocolo de Camada de Transporte (TLS) ou a Camada de Sockets Seguros (SSL). Esta criptografia protege os dados sendo transferidos da interceptação e manipulação.
