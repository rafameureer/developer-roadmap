# Modelo de Nuvem Híbrida

O modelo híbrido de nuvem combina a infraestrutura local (uma nuvem privada) com os serviços públicos da nuvem de terceiros. Esta configuração permite que as organizações explorem os benefícios de ambos os ambientes. Por exemplo, dados sensíveis podem permanecer em uma nuvem privada por razões de segurança e conformidade, enquanto tarefas intensivas em computação podem ser offloaded para a nuvem pública para escalabilidade e economia de custos. A chave é a interoperabilidade entre esses ambientes de nuvem, permitindo que dados e aplicativos sejam compartilhados.
