# LDAPS

LDAPS (Protocolo de Acesso a Diretórios Leve Seguro) é um método de segurança para comunicações LDAP usando SSL (Camada de Sockets Seguros) ou TLS (Camada de Transporte Segura) para criptografar os dados transmitidos entre um cliente e um servidor de diretório. Esta criptografia previne a interceptação e manipulação de informações sensíveis como nomes de usuários, senhas e outros atributos do diretório durante o transporte, garantindo um ambiente mais seguro de serviço de diretório.
