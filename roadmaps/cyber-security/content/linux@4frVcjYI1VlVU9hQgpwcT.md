# Linux

O Linux é um sistema operacional de código aberto, semelhante ao Unix, que foi lançado pela primeira vez por Linus Torvalds em 1991. Ele forma a base de vários sistemas operacionais conhecidos como distribuições Linux. O Linux é famoso por sua estabilidade, segurança e flexibilidade, tornando-o popular para servidores, sistemas embarcados e cada vez mais para uso na área de trabalho. Ele suporta uma ampla gama de hardware e oferece interfaces de linha de comando potentes juntamente com interfaces gráficas de usuário. O Linux adere aos princípios do Unix, enfatizando a modularidade e o filosofia "faça apenas uma coisa e faça bem". Sua natureza de código aberto permite o desenvolvimento e personalização comunitários. O Linux é amplamente usado em computação em nuvem, supercomputadores e dispositivos Android, e é um componente fundamental da pilha web LAMP (Linux, Apache, MySQL, PHP).
