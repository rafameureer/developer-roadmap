# LOLBAS

Living Off The Land Binários e Scripts (LOLBAS) refere-se ao uso de ferramentas e programas legítimos, pré-instalados no sistema operacional, para fins maliciosos. Em vez de introduzir novos malware, os atacantes aproveitam esses binários existentes e confiáveis para realizar ações como download de arquivos, execução de código ou coleta de informações, frequentemente evadindo defesas tradicionais de segurança que se concentram em detectar software malicioso.
