# Loopback

O loopback é um mecanismo onde o tráfego de rede é roteado de volta ao dispositivo de origem. É essencialmente um atalho para que um dispositivo se comunique consigo mesmo em uma rede. Isso é alcançado usando um endereço IP especial (geralmente 127.0.0.1 para IPv4 ou ::1 para IPv6) e uma interface de rede designada (a interface de loopback). Os dados nunca saem realmente da máquina, em vez disso, são redirecionados internamente.
