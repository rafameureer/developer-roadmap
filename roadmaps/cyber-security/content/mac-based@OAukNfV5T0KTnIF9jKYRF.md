# Controle de Acesso Forçado (MAC)

Controle de Acesso Forçado (MAC) é um modelo de segurança onde o sistema operacional impõe regras rigorosas sobre o acesso a recursos. Diferentemente do controle de acesso discrecional (DAC), onde os usuários controlam o acesso aos próprios arquivos, MAC usa uma autoridade centralizada para definir políticas de acesso. Essas políticas são baseadas em rótulos ou classificações atribuídas tanto a usuários quanto a dados. Acesso é concedido apenas se o rótulo do usuário corresponder ou dominar o rótulo dos dados, garantindo uma postura de segurança rígida e consistente.
