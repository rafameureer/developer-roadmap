# Rede Metropolitana (MAN)

A Rede Metropolitana (MAN) é uma rede de computadores que conecta computadores e outros dispositivos em uma área geográfica maior do que uma rede local (LAN), mas menor do que uma rede de largura de banda (WAN). É essencialmente uma versão escalada de uma LAN, projetada para atender a uma cidade ou área metropolitana. As MANs são frequentemente usadas para conectar várias LANs juntas, permitindo que dispositivos em diferentes locais se comuniquem entre si.
