# Phishing

O phishing é um tipo de ataque de engenharia social onde os atores maliciosos tentam enganar indivíduos para revelar informações sensíveis, como nomes de usuários, senhas, detalhes de cartões de crédito ou outros dados pessoais. Isso geralmente é feito se escondendo-se como uma entidade confiável em uma comunicação eletrônica, como um e-mail, mensagem ou site, para enganar o destinatário a clicar em um link malicioso ou fornecer as informações solicitadas. O objetivo é roubar dados ou instalar malware no dispositivo do vítima.
