# PowerShell

PowerShell é um shell de linha de comando e linguagem de script desenvolvida pela Microsoft. Ele está projetado para administradores de sistemas automatizar tarefas e gerenciar sistemas operacionais. Baseado no framework .NET, o PowerShell usa cmdlets (pronunciados "command-lets") para realizar ações específicas e pode interagir com diversos componentes do sistema e aplicativos.
