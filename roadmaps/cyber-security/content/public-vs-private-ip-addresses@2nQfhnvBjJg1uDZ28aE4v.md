# Endereços IP Público e Privado

Os endereços IP públicos são atribuídos a dispositivos diretamente acessíveis na internet, permitindo que eles comuniquem-se com redes e serviços externos. Por outro lado, os endereços IP privados são usados em redes locais e não são roteáveis na internet, fornecendo uma maneira para dispositivos dentro de uma rede privada se comunicarem entre si enquanto conservam o espaço de endereços IP público. Os endereços IP públicos são únicos na internet, enquanto os endereços IP privados são reutilizados em diferentes redes locais e geralmente são gerenciados por tradução de endereço de rede (NAT) para se comunicar com redes públicas.
