# Rota

O comando `route` é uma ferramenta de rede usada para exibir e manipular a tabela de encaminhamento IP em sistemas Unix-like e Windows. Ele permite que os usuários mostrem as rotas atuais pelas quais os pacotes de dados viajam, bem como adicionar, modificar ou deletar rotas para o tráfego de rede. Esse comando é frequentemente usado na solução de problemas de rede e configuração para controlar como os dados fluem entre diferentes redes e sub-redes. Ao especificar rotas manualmente, administradores podem definir caminhos específicos para o tráfego de rede, evitando rotas padrão e otimizando desempenho ou segurança.
