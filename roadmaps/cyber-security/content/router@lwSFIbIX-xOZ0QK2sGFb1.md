# Roteador

Um roteador é um dispositivo de rede que direciona pacotes de dados entre diferentes redes, garantindo que eles cheguem ao seu destino. Ele opera na camada de rede (Camada 3) do modelo OSI e encaminha dados com base em endereços IP da fonte e do destino. Roteadores são essenciais para conectar dispositivos à internet ou vincular várias redes juntas. Eles mantêm uma tabela de roteamento para decidir o melhor caminho para os dados e podem atualizar dinamicamente rotas usando protocolos como RIP, OSPF ou BGP. Roteadores também lidam com a Tradução de Endereços de Rede (NAT), permitindo que vários dispositivos compartilhem um único endereço IP público. Muitos roteadores modernos oferecem Wi-Fi para conectividade sem fio e incluem uma segurança básica de firewall para proteger a rede contra ameaças.
