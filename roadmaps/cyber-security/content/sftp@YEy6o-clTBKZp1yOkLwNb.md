# SFTP

SFTP (SSH File Transfer Protocol) é um protocolo de transferência de arquivos seguro que fornece acesso, transferência e gerenciamento de arquivos sobre uma stream de dados confiável. Ele opera sobre o protocolo SSH, geralmente na porta 22, garantindo a transferência de arquivos criptografados. O SFTP oferece segurança mais forte do que o FTP tradicional ao criptografar tanto os comandos quanto os dados em transito, previnindo interceptações não autorizadas. Ele suporta recursos como retomada de transferências interrompidas, listagens de diretórios e operações no sistema de arquivos remoto. O SFTP é amplamente usado para transferências de arquivos seguras em diversos ambientes, desde hospedagem web até gerenciamento de dados corporativos, oferecendo uma alternativa mais segura ao FTP enquanto mantém funcionalidades similares. Sua integração com o SSH o torna a escolha preferida para transferências de arquivos seguros e autenticados em muitas configurações de rede.
