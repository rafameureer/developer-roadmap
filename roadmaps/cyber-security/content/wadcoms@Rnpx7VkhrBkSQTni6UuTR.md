# WADCOMS

WADcoms (Windows/Active Directory Commands) é um guia interativo, contendo uma lista curada de ferramentas ofensivas em segurança cibernética e seus respectivos comandos, para serem usados contra ambientes Windows/AD. Basta selecionar a informação que você possui atualmente relacionada à máquina Windows (senhas, nomes de usuários, serviços, etc.), e ele exibirá uma lista de ferramentas que você pode tentar usar na máquina, junto com um modelo de comando para facilitar a cópia e cola

Acesse os seguintes recursos para saber mais:
