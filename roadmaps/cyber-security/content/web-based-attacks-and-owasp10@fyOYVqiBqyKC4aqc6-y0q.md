# OWASP Top 10 e Ataques Baseados em Web

A OWASP Top 10 é uma lista atualizada regularmente que destaca os principais riscos de segurança enfrentando as aplicações web. Essas vulnerabilidades são classificadas com base na facilidade de exploração, prevalência, detectabilidade e impacto técnico e comercial. Os ataques baseados em web explorem essas fraquezas para comprometer aplicativos, roubar dados ou interromper serviços, frequentemente aproveitando vulnerabilidades no código, configuração ou design.
