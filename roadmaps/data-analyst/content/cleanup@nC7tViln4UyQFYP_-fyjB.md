# Limpeza de Dados

A limpeza de dados (ou limpeza de dados) é o processo de identificar e corrigir erros, incongruências e valores ausentes em um conjunto de dados. Tarefas comuns incluem lidar com valores nulos, remover duplicatas, corrigir problemas de formatação e padronizar categorias. Dados limpos são uma pré-requisito para análise precisa.
