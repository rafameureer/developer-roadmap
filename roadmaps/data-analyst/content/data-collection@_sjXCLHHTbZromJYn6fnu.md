# Coleta de Dados

A coleta de dados em análise envolve a extração de dados das fontes relevantes para o ambiente analítico. As fontes incluem bancos de dados consultados com SQL, arquivos CSV carregados do disco, APIs chamadas programaticamente e raspagem da web para dados publicamente disponíveis. Cada fonte tem diferentes métodos de acesso, formatos e características de confiabilidade.
