# Árvores de Decisão

Uma árvore de decisão é um algoritmo de aprendizado supervisionado que divide os dados em ramos com base nos valores das características para chegar a uma previsão. É interpretável porque a lógica da decisão pode ser visualizada e explicada. Árvores de decisão são a base para métodos enxame como Random Forests e Boosting Gradual.
