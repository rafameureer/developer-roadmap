# Hadoop

O Apache Hadoop é um framework de código aberto para armazenamento distribuído e processamento de grandes conjuntos de dados em clusters. Ele consiste em HDFS (Hadoop Distributed File System) para armazenamento e MapReduce para computação. Embora largamente superado pelo Spark para o processamento, o ecossistema do Hadoop, incluindo HDFS e YARN, continua sendo fundamental em muitos ambientes de big data.
