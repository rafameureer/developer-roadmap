# Introdução

O análise de dados é a prática de examinar dados brutos para tirar conclusões e apoiar tomadas de decisão. Combina métodos estatísticos, ferramentas de programação e conhecimento do domínio para extrair significado de dados estruturados e não estruturados. Analistas de dados trabalham em várias indústrias para ajudar as organizações a entender o que aconteceu, por que aconteceu e o que pode acontecer next.
