# Aprenda Funções Comuns

As funções do Excel são fórmulas incorporadas que realizam cálculos em dados. Dominar as funções comuns para manipulação de texto, aritmética de datas, pesquisa, agregação e lógica é o núcleo da análise de dados baseada no Excel. As funções podem ser combinadas e aninhadas para lidar com tarefas analíticas complexas sem programação.

Acesse os seguintes recursos para saber mais:

- [@artigo@Funções do Excel (por categoria)](https://support.microsoft.com/en-US/Excel/excel-functions-by-category)
- [@artigo@Essenciais do Microsoft Excel](https://uniskills.library.curtin.edu.au/digital/ms-excel/formulas-and-common-functions/)
