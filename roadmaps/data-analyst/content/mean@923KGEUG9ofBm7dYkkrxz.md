# Média

A média é a média aritmética de um conjunto de valores, calculada somando todos os valores e dividindo pelo número total. É o medida mais comumente usada de tendência central, mas é sensível a outliers. Quando os dados estão assimétricos, a mediana geralmente é uma representação melhor do valor típico.
