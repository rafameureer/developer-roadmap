# Tabelas Dinâmicas

As tabelas dinâmicas são uma das funcionalidades mais poderosas do Excel para resumir e analisar grandes conjuntos de dados. Elas permitem que os dados sejam agrupados, filtrados e agregados em várias dimensões sem escrever fórmulas. As tabelas dinâmicas são usadas para explorar rapidamente os dados e construir relatórios de resumo arrastando e soltando campos.
