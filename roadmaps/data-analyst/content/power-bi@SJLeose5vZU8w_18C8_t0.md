# Power BI

Power BI é a plataforma de inteligência empresarial da Microsoft para criar relatórios e painéis interativos. Ele integra-se estreitamente com o ecossistema Microsoft, incluindo Excel, Azure e SQL Server. O Power BI é amplamente adotado em organizações já usando ferramentas da Microsoft para relatórios e compartilhamento de dados entre equipes.
