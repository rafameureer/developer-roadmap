# SUBSTITUIR / SUBSTITUIR

`SUBSTITUIR` substitui uma parte de uma string de texto com base na posição e no comprimento. `SUBSTITUIR TUDO` substitui todas as ocorrências de um subconjunto específico de caracteres por outra string. Ambos são usados para limpeza e padronização de texto no Excel.
