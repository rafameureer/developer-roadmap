# Seaborn

Seaborn é uma biblioteca de visualização em Python construída sobre o Matplotlib que fornece uma interface de nível superior para gráficos estatísticos. Ele simplifica a criação de gráficos complexos como mapas de calor, gráficos de dispersão parcial e comparações de distribuição. O Seaborn é adequado para explorar relações em conjuntos de dados com um mínimo de código boilerplate.
