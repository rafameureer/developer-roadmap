# UPPER / LOWER / PROPER

`UPPER` converte texto para maiúsculas, `LOWER` para minúsculas e `PROPER` capitaliza a primeira letra de cada palavra. Essas funções são usadas para padronizar o formato do texto em conjuntos de dados, especialmente quando combinando dados de várias fontes com casing inconsistente.
