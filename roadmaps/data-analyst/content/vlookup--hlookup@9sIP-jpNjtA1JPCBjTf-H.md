# VLOOKUP / HLOOKUP

`VLOOKUP` procura um valor na primeira coluna de uma tabela e retorna um valor de uma coluna especificada na mesma linha. `HLOOKUP` faz o mesmo horizontalmente, procurando pela primeira linha. Ambos são usados para mesclar dados de diferentes tabelas, embora tenham sido largamente substituídos por `XLOOKUP` no Excel moderno.
