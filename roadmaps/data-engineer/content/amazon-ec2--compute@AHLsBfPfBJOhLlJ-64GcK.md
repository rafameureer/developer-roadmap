# Amazon EC2 (Computação)

O Amazon EC2 (Elastic Compute Cloud) oferece servidores virtuais na nuvem AWS. Os usuários podem escolher tipos de instâncias otimizados para computação, memória ou armazenamento e pagar apenas pelo que executam. O EC2 é usado para executar trabalhos de processamento de dados, hospedar bancos de dados e construir infraestrutura de dados personalizada na AWS.
