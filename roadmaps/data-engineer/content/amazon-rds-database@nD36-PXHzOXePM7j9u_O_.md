# Amazon RDS (Banco de Dados)

Amazon RDS (Relational Database Service) é um serviço da Web da Amazon Web Services. Ele foi projetado para simplificar a configuração, operação e escalabilidade de bancos de dados relacionais na nuvem. Este serviço fornece capacidade reconfigurável e eficiente em custo para um banco de dados relacional padrão do setor e gerencia comuns tarefas administrativas de banco de dados. O RDS suporta seis motores de banco de dados: Amazon Aurora, PostgreSQL, MySQL, MariaDB, Oracle Database e SQL Server. Esses motores lhe permitem executar instâncias que variam em memória de 5GB a 6TB, adaptando-se ao seu caso de uso específico. Ele também garante que o banco de dados esteja atualizado com as últimas patches, faz backup automático dos seus dados e oferece criptografia em repouso e em transito.
