# Apache Kafka

Apache Kafka é uma plataforma de processamento em fluxo de software开源 desenvolvida pela LinkedIn e doada à Fundação Apache Software. Ele está escrito em Scala e Java e opera com base em uma fila de mensagens, projetado para lidar com feeds de dados em tempo real. O Kafka funciona como um tipo de serviço de provedor de mensagem entre os produtores de dados e os consumidores, facilitando a transmissão eficiente de dados. Ele pode ser visto como um provedor de mensagem duradouro onde as aplicações podem processar e reprocessar dados em fluxo. O Kafka é um sistema altamente escalável e tolerante a falhas que garante a entrega de dados sem perdas.
