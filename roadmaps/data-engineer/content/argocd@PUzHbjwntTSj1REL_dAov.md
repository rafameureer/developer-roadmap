# ArgoCD

Argo CD é uma ferramenta de entrega contínua declarativa do GitOps para Kubernetes. Ele monitora continuamente um repositório Git e garante que o estado do cluster Kubernetes corresponda ao estado desejado definido no código. O Argo CD é usado em engenharia de dados para gerenciar implantações de pipelines baseados em Kubernetes e alterações na infraestrutura através do Git.
