# Assíncrono vs Síncrono

Comunicação síncrona significa que o remetente espera uma resposta antes de continuar. Comunicação assíncrona significa que o remetente envia uma mensagem e continua sem esperar. Os sistemas de mensagens permitem comunicação assíncrona, o que é mais adequado para pipelines de alta taxa de throughput onde a bloqueio criaria bottlenecks.
