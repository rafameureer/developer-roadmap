# Ferramentas de Big Data

As ferramentas de big data são projetadas para processar e analisar conjuntos de dados muito grandes que não podem ser lidados com ferramentas tradicionais de computação em um único nó. Eles distribuem o cálculo em clusters e estão otimizados para throughput a escala. O framework de processamento de big data mais amplamente utilizado é o Apache Spark, com as ferramentas baseadas em Hadoop ainda sendo comuns em ambientes legados.
