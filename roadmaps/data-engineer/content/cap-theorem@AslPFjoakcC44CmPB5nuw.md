# Teorema CAP

O Teorema CAP afirma que um sistema distribuído pode fornecer no máximo duas das três garantias: Consistência, Disponibilidade e Tolerância a Partições. Na prática, partições de rede são inevitáveis, então os sistemas devem escolher entre consistência e disponibilidade quando uma partição ocorre. Esse equívoco molda o design de bancos de dados distribuídos como Cassandra, DynamoDB e HBase.
