# Engenharia de Dados vs Ciência de Dados

A engenharia de dados e a ciência de dados são papéis distintos, mas complementares, dentro do campo dos dados. A engenharia de dados se concentra na construção e manutenção da infraestrutura para coleta, armazenamento e processamento de dados, essencialmente criando os sistemas que tornam os dados disponíveis para usuários downstream. Por outro lado, profissionais de ciência de dados, como analistas de dados e cientistas de dados, usam esses dados para extrair insights, construir modelos preditivos e, finalmente, informar tomada de decisão.
