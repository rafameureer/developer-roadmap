# Data Lake

Um data lake é um repositório de armazenamento centralizado que mantém grandes quantidades de dados brutos em seu formato nativo, incluindo dados estruturados, semi-estruturados e não estruturados. Diferentemente de um data warehouse, um data lake não impõe esquemas na ingestão. Os dados são armazenados economicamente a escala e processados conforme necessário, o que permite flexibilidade para análises futuras.
