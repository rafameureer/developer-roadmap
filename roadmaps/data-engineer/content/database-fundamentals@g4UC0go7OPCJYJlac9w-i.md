# Fundamentos de Banco de Dados

Os fundamentos do banco de dados cobrem os conceitos centrais que se aplicam a maioria dos sistemas de banco de dados relacionais: como os dados são organizados em tabelas, como as consultas são executadas e como o banco de dados garante consistência e durabilidade. Os tópicos incluem normalização, indexação, transações e otimização de consultas. Esses conceitos se aplicam independentemente do uso de PostgreSQL, MySQL ou qualquer outro sistema relacional.
