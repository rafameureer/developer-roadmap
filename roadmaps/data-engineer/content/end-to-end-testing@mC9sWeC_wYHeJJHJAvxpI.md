# Teste de ponta a ponta

O teste de ponta a ponta (ou E2E) é um tipo de teste usado para afirmar que toda sua aplicação funciona conforme o esperado, desde o início até o fim ou "de ponta a ponta". O teste E2E difere do teste unitário em que ele está completamente decolocado dos detalhes de implementação subjacentes do seu código. Geralmente é usado para validar uma aplicação de maneira que simule como um usuário interagiria com ela.
