# Google BigQuery

O Google BigQuery é um produto de armazenamento em nuvem gerenciado e sem servidor oferecido pelo Google, que permite análises escaláveis sobre grandes quantidades de dados. É um Serviço como uma Plataforma (PaaS) que suporta consultas usando um dialeto do SQL. O BigQuery é NoOps, o que significa que não há infraestrutura para gerenciar e você não precisa de um administrador de banco de dados. Com o BigQuery, você pode se concentrar em analisar os dados para encontrar insights significativos enquanto usa familiarmente SQL e aprende com a máquina por meio da melhor desempenho/valor.
