# Google Cloud Storage

O Google Cloud Storage (GCS) é um serviço de armazenamento em nuvem escalável, seguro e duradouro para objetos dentro do Plataforma do Google Cloud (GCP), projetado para armazenar e recuperar dados não estruturados de qualquer tipo ou tamanho. Ele permite que os usuários armazenem dados em "bucktes" e acessem através de APIs, interfaces web ou ferramentas de linha de comando para aplicações, backups, hospedagem de mídia e análises de big data. O GCS oferece diferentes classes de armazenamento para otimizar os custos com base na frequência de acesso aos dados, segurança forte com criptografia e alta disponibilidade através do armazenamento redundante em várias localizações.
