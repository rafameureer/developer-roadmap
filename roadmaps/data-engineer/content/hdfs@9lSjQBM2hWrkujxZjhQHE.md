# HDFS

O HDFS (Hadoop Distributed File System) é o sistema de armazenamento primário do Hadoop. Ele está projetado para armazenar dados de forma confiável em um cluster de máquinas. Sua arquitetura está configurada para este tipo de acesso a grandes conjuntos de dados e otimizada para tolerância a falhas, escalabilidade e localidade dos dados.
