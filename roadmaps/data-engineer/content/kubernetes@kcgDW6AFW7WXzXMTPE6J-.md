# Kubernetes

O Kubernetes é um sistema de código aberto para automatizar a implantação, escala e operação de aplicativos contêinerizados. Ele gerencia clusters de contêineres em vários nós e lida com balanceamento de carga, auto-reparo e atualizações em rotação. Engenheiros de dados usam o Kubernetes para executar trabalhos de processamento distribuído, agendar trabalhadores de pipeline e gerenciar infraestrutura em escala.
