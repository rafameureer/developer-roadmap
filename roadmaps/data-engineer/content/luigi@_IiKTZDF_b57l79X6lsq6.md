# Luigi

Luigi é um poderoso e fácil de usar framework open-source para construir pipelines de dados com Python. Ele lida com a resolução de dependências, gerenciamento de fluxos de trabalho, visualização etc. Luigi ajuda a construir o pipeline de dados, típicamente associado a processos em lote de longa duração.
