# MS SQL

O Microsoft SQL Server (MS SQL) é um banco de dados relacional desenvolvido pela Microsoft, comumente usado em ambientes empresariais e baseados em Windows. Ele integra-se estreitamente ao ecossistema da Microsoft, incluindo Azure, Power BI e .NET. O MS SQL suporta T-SQL, a extensão do SQL da Microsoft com capacidades adicionais de procedimento.
