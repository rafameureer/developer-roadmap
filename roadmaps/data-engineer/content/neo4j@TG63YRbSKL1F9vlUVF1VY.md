# Neo4j

O Neo4j é o banco de dados de gráficos mais amplamente usado. Ele armazena dados intrinsecamente como nós e relações e usa Cypher, uma linguagem de consulta declarativa projetada para navegação em grafos. O Neo4j é usado em aplicações onde consultas centrais envolvem muitas relações, como sistemas de recomendação e análise de rede.
