# Prefect

Prefect é um motor de orquestração open-source que transforma suas funções Python em pipelines de dados de produção com minimal friction. Você pode construir e agendar workflows em Python puro—sem DSLs ou arquivos de configuração complexos—and executá-los em qualquer lugar onde você possa executar Python. O Prefect lida automaticamente com as tarefas pesadas por você: rastreamento automático do estado, tratamento de falhas, monitoramento em tempo real e muito mais.
