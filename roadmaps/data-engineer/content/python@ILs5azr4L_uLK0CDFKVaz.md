# Python

As características intrínsecas do Python e a rica quantidade de recursos que se desenvolveram ao seu redor o tornaram a linguagem de escolha para engenheiros de dados. Python é um idioma de alto nível, interpretado e de propósito geral. Sua filosofia de design enfatiza a legibilidade do código com o uso de indentação significativa. Python é tipicamente dinamicamente-tipo e coletor de lixo.
