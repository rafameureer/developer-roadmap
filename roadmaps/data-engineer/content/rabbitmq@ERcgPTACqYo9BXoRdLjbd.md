# RabbitMQ

RabbitMQ é um intermediário de mensagens de código aberto que implementa o protocolo AMQP. Ele roteia mensagens entre produtores e consumidores usando trocas e filas, suportando padrões como publicar/assinar, filas de trabalho e encaminhamento. RabbitMQ é usado para filas de tarefas, comunicação serviço-a-serviço e sistemas de notificação de eventos.
