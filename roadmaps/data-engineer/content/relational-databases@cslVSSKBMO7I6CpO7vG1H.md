# Bancos de Dados Relacionais

Os bancos de dados relacionais armazenam dados em tabelas com linhas e colunas, e usam SQL para consultas. As relações entre as tabelas são definidas através de chaves estrangeiras. São o tipo mais amplamente utilizado de banco de dados para aplicativos transacionais e formam a base dos sistemas operacionais maioria.
