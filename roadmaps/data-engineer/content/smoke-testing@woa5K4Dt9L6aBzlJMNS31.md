# Teste de Fumaça

O Teste de Fumaça é um processo de teste de software que determina se a versão implantada do software está estável ou não. O teste de fumaça é uma confirmação para o time de QA para prosseguir com os testes adicionais de software. Ele consiste em um conjunto mínimo de testes executados em cada build para testar as funcionalidades do software.
