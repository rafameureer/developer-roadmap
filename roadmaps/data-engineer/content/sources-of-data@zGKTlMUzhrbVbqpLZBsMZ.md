# Fontes de Dados

As fontes de dados são origens ou locais a partir dos quais os dados são coletados, categorizadas como primárias (informações diretas, primeira mão) ou secundárias (coletadas por outras pessoas). Exemplos comuns de fontes primárias incluem pesquisas, entrevistas, experimentos e dados de sensores. As fontes secundárias englobam bancos de dados, relatórios publicados, dados governamentais, livros, artigos e dados da web como posts em redes sociais. As fontes de dados também podem ser classificadas como internas (dentro de uma organização) ou externas (de origens externas).
