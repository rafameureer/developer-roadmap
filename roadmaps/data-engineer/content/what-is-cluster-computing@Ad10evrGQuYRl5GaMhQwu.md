# O que é Computação em Cluster

A computação em cluster é um modelo onde múltiplos computadores são conectados em rede para funcionar como um sistema de processamento unificado. Tarefas são divididas entre os nós do cluster e executadas em paralelo. Esse método é usado no processamento de grandes volumes de dados, na ciência da computação e em qualquer carga de trabalho que ultrapasse a capacidade de uma única máquina.
