# Busca em Largura

Busca em Largura (BFS) é um algoritmo de busca usado para navegar ou pesquisar em estruturas de dados como árvores ou grafos. O algoritmo começa com um nó raiz e visita os nós nível por nível (ou seja, visitando primeiro os mais próximos à raiz). Ele usa uma estrutura de dados fila para armazenar nós que ainda não foram visitados. É feita uma verificação antes de os nós serem colocados na fila. Isso é para garantir que o mesmo nó não seja visitado duas vezes. BFS pode ser usado em várias áreas como encontrar caminhos mais curtos, árvores serializadas ou em cenários de casos de teste onde todos os vértices são igualmente importantes.
