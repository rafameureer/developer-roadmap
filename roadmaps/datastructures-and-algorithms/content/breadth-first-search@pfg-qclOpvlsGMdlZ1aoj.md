# Busca em Largura

Busca em Largura (BFS) é um algoritmo de busca usado em estruturas de dados como árvores ou grafos. Ele começa no nó raiz (o nó mais alto na árvore) e expande todos os nós vizinhos na profundidade atual antes de passar para nós na próxima nível de profundidade. Esta técnica usa uma estrutura de dados fila para lembrar de explorar o próximo vértice ou nó, e cada aresta que leva a um vértice será explorada, garantindo a descoberta de todos os vértices alcançáveis a partir da fonte. BFS é completo em natureza, o que significa que se o nó pesquisado estiver na árvore, BFS garante encontrá-lo.
