# Bubble Sort

O Bubble Sort é um algoritmo de ordenação simples que funciona trocando repetidamente os elementos adjacentes se estiverem na ordem errada. Ele recebeu esse nome porque, com cada iteração, o maior elemento "subir" até sua posição correta. Esse processo de troca continua até que toda a lista esteja ordenada em ordem crescente. As principais etapas do algoritmo são: começar pelo início da lista, comparar cada par de elementos adjacentes e trocá-los se estiverem na ordem errada, e então passar pela lista até que mais nenhuma troca seja necessária. Embora simples, o Bubble Sort não é adequado para grandes conjuntos de dados, pois tem uma complexidade de tempo pior e média de O(n²), onde n é o número de itens sendo ordenados.
