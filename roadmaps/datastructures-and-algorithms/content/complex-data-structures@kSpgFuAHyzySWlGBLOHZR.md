# Estruturas de Dados Complexas

As estruturas de dados complexas são estruturas avançadas usadas para armazenar e organizar dados de uma maneira mais especializada, para gerenciar maior quantidades de dados de forma mais eficaz. Isso inclui Árvores, Grafos, Tabelas Hash e Montículos. As Árvores permitem estruturas hierárquicas de dados e podem ser utilizadas de várias maneiras, como Árvores Binárias, Árvores AVL etc. Os Grafos são redes composta por nós ou vértices, conectados por arestas. As Tabelas Hash usam uma função hash para calcular um índice em um array de baldes ou slots, a partir do qual o valor desejado pode ser encontrado. Montículos são um caso especial de uma árvore binária onde os nós pais são comparados com seus filhos com regras específicas.
