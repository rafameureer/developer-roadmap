# Árvores de Fenwick

As árvores de Fenwick, também conhecidas como Árvores Indexadas Binárias, são estruturas de dados que podem suportar eficientemente as operações de atualização de elementos e cálculo de somas prefixadas em uma tabela de números. Isso o torna especialmente útil em situações onde a tabela é atualizada frequentemente e diferentes tipos de consultas (como a soma dos elementos) precisam ser respondidas rapidamente. Uma árvore de Fenwick geralmente leva O(log n) tempo para ambas as operações de atualização e consulta, o que é mais eficiente do que um array ou uma árvore de segmentos. Ela alcança essa eficiência armazenando informações parciais de soma no array. Isso permite cálculos eficientes de intervalos de soma, com a operação de adicionar um elemento e obter a soma de um intervalo ambos alcançando em O(log n) tempo.
