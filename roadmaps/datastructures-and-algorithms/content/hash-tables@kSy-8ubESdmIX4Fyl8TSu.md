# Tabelas de Hash

As `Tabelas de Hash` são estruturas de dados especializadas que permitem acesso rápido a dados com base em uma chave. Basicamente, uma tabela de hash funciona tomando uma entrada de chave e calculando um índice em um array onde o valor desejado pode ser encontrado. Ela usa uma função de hash para calcular esse índice. Suponha que os elementos sejam inteiros e a função de hash retorne o valor na unidade de lugar. Se a chave fornecida for 22, ela verificará o valor no índice 2. Colisões ocorrem quando a função de hash retorna a mesma saída para duas entradas diferentes. Existem vários métodos para lidar com essas colisões como encadeamento e endereçamento aberto.
