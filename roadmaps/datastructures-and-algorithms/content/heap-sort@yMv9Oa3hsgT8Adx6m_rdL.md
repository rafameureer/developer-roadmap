# Heap Sort

Heap Sort é um algoritmo de classificação eficiente e baseado em comparação. Ele utiliza uma estrutura de dados conhecida como 'binary heap', e funciona dividindo seu entrada em uma região ordenada e uma região não ordenada, e iterativamente diminuindo a região não ordenada removendo o maior elemento e movendo-o para a região ordenada. É um algoritmo in-place, mas não estável. Involves construir uma Max-Heap, que é uma estrutura de dados baseada em árvore especializada, e depois trocando o nó raiz (maior elemento) com o último nó, reduzindo o tamanho da heap por um e reorganizando a raiz da heap. O maior elemento agora está no final da lista e este passo é repetido até que todos os nós sejam ordenados. Heap Sort oferece uma boa taxa de execução pior caso de O(n log n), independentemente dos dados de entrada.
