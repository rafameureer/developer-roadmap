# Indexação

A indexação é uma técnica de estrutura de dados para recuperar eficientemente dados de um banco de dados. Ela cria essencialmente uma tabela de pesquisa que pode ser usada para encontrar rapidamente a localização dos registros de dados em disco. Índices são criados usando algumas colunas do banco de dados e são capazes de localizar rapidamente os dados sem precisar examinar cada linha da tabela do banco de dados toda vez que o banco de dados é acessado. Índices podem ser criados usando qualquer combinação de colunas em uma tabela do banco de dados, reduzindo o tempo necessário para encontrar dados.

Índices podem ser estruturados de várias maneiras: Árvore Binária, Árvore B, Mapa Hash, etc., cada um com suas próprias particularidades fortes e fracos. Quando criando um índice, é crucial entender qual tipo de índice aplicar para obter a maior eficiência. Índices, como qualquer outra característica do banco de dados, devem ser usados com sabedoria porque eles exigem espaço em disco e precisam ser mantidos, o que pode lentificar as operações de inserção e atualização.
