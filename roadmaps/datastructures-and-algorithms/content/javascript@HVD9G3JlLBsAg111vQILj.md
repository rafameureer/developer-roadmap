# JavaScript

JavaScript permite adicionar interatividade às suas páginas. Exemplos comuns que você pode ter visto em sites são sliders, interações de clique, popups e muito mais. Além de ser usado no frontend nos navegadores, há o Node.js, um ambiente de tempo de execução de JavaScript de back-end aberto-fonte e multiplataforma que roda no motor V8 e executa código JavaScript fora do navegador.
