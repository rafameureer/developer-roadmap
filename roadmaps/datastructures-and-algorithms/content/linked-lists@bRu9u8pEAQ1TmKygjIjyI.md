# Listas Encadeadas

As listas encadeadas são um tipo de estrutura de dados usada para armazenar coleções de dados. Os dados são armazenados em nós, cada um dos quais contém um campo de dados e uma referência (link) ao próximo nó na sequência. Estruturalmente, uma lista encadeada é organizada em uma sequência ou cadeia de nós, por isso o nome. Dois tipos de listas encadeadas são comumente usados: listas encadeadas simples, onde cada nó aponta para o próximo nó e o último nó aponta para null, e listas duplamente encadeadas, onde cada nó tem duas ligações, uma para o nó anterior e outra para o próximo. As listas encadeadas são usadas em outros tipos de estruturas de dados como pilhas e filas.
