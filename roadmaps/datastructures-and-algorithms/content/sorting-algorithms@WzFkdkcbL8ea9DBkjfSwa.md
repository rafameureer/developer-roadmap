# Algoritmos de Ordenação

Algoritmos de ordenação são usados para rearranjar os elementos de um dado array ou lista em ordem, com base em um operador de comparação nos elementos. O operador de comparação é usado para decidir a nova ordem dos elementos na estrutura de dados respectiva. Por exemplo, a ordem numérica é uma sequência comumente usada, mas uma ordem lexicográfica também é um tipo de sequência comum. Existem vários tipos de algoritmos de ordenação: quick sort, bubble sort, merge sort, insertion sort, selection sort, heap sort, radix sort e bucket sort entre outros. Cada um tem suas próprias propriedades e são adequados para tarefas específicas e dados.
