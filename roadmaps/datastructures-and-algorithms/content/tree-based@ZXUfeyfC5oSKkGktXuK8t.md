# Indexação Baseada em Árvores

A indexação baseada em árvores envolve o uso de estruturas de dados que seguem um modelo de árvore, com nós pais, filhos e folhas em uma ordem hierárquica. Dois métodos populares de indexação baseada em árvores são B-tree e B+ tree. Em um índice B-tree, cada registro de dados está associado a uma folha, enquanto os nós internos podem ser vinculados a um número de nós inferiores dentro de um determinado intervalo. Por outro lado, a estrutura de índice B+ tree coloca todos os registros na camada de folhas, com os nós internos contendo apenas valores-chave. O caminho da raiz até cada nó folha em ambas as árvores B-tree e B+ tree tem o mesmo comprimento, permitindo uma recuperação eficiente e consistente.
