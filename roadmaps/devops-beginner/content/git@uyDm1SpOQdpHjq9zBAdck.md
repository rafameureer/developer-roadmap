# Git

O Git é um sistema de controle de versão distribuído projetado para rastrear qualquer alteração no código-fonte ao longo do ciclo de vida de desenvolvimento de software. Cada desenvolvedor possui uma cópia completa do histórico localmente em sua máquina, permitindo operações ultra-rápidas e trabalho offline. O Git viabiliza desenvolvimento não-linear através de ramificações (*branches*) leves e mesclagens (*merges*) robustas, tornando-se o padrão absoluto da indústria para versionamento de código e colaboração técnica.
