# GitHub Actions

O GitHub Actions é a plataforma nativa de automação e integração/entrega contínua (CI/CD) do GitHub. Ele permite executar fluxos de trabalho (*workflows*) automatizados diretamente do seu repositório, acionados por eventos como envios de código (*push*), criação de *Pull Requests*, agendamentos (*cron*) ou chamadas manuais. Com ele, você pode compilar, testar, validar qualidade e realizar o deploy de suas aplicações de forma contínua e integrada ao ecossistema GitHub.
