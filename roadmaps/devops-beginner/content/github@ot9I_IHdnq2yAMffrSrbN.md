# GitHub

O GitHub é uma plataforma na nuvem construída sobre o Git que fornece hospedagem de repositórios, ferramentas avançadas de colaboração, controle de versões e gestão de projetos de software. Ele possibilita a revisão colaborativa de código via *Pull Requests*, rastreamento de tarefas com *Issues* e quadros *Projects*, automação de CI/CD com *GitHub Actions*, além de documentação e páginas estáticas via *GitHub Pages*. É a maior comunidade de código aberto do mundo e o hub central para equipes de engenharia de software modernas.
