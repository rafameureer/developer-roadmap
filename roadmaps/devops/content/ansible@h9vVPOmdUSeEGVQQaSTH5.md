# Ansible

Ansible é uma ferramenta de automação open-source usada para gerenciamento de configuração, implantação de aplicativos e orquestração de tarefas. Ele opera como um sistema sem agentes, conectando-se a servidores remotos via SSH ou WinRM para executar tarefas definidas em arquivos YAML humanamente legíveis chamados playbooks. Ele permite que os usuários descrevam o estado desejado de um sistema e a ferramenta garante que a infraestrutura corresponda automaticamente àquela configuração.
