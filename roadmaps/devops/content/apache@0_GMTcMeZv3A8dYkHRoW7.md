# Apache

Apache HTTP Server é um software de servidor web open-source que impulsiona uma grande porção dos sites na internet. Ele funciona processando solicitações de entrada dos clientes e entregando o conteúdo web solicitado, como arquivos HTML ou imagens, através do protocolo HTTP. Para configurá-lo, você geralmente instala o pacote via gerenciador de pacotes do seu sistema operacional, configura o arquivo principal de configuração para definir o diretório raiz do servidor e os hosts virtuais, e então inicia o serviço para começar a hospedar seus aplicativos.
