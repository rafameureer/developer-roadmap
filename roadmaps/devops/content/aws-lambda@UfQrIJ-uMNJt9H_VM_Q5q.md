# AWS Lambda

AWS Lambda é um serviço de computação sem servidor que permite executar código sem provisionar ou gerenciar servidores. Ele escala automaticamente, executa código em resposta a gatilhos e cobrança apenas pelo tempo de computação consumido. O Lambda suporta múltiplos idiomas de programação e integra-se perfeitamente com outros serviços da AWS, tornando-o ideal para construir microservices, automatizar tarefas e processar fluxos de dados com pouco overhead operacional.
