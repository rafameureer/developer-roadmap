# Cloud Smith

Cloudsmith é um serviço de gerenciamento de artefatos nativo da nuvem que suporta uma ampla gama de formatos de pacote, incluindo imagens Docker, npm, PyPI, Maven e mais. Ele fornece um repositório centralizado e hospedado para armazenar e distribuir artefatos com controles de acesso granulares e integração com pipelines CI/CD populares.
