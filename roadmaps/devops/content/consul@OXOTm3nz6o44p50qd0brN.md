# Consul

Consul é uma solução de malha de serviço que fornece um painel de controle completo com funcionalidades de descoberta de serviços, configuração e segmentação. Cada uma dessas funcionalidades pode ser usada individualmente conforme necessário, ou podem ser usadas juntas para construir uma malha de serviço completa. Consul requer um plano de dados e suporta tanto um proxy quanto um modelo de integração nativa. Consul vem com um proxy interno simples para que tudo funcione de saída do caixão, mas também suporta integrações de proxy de terceiros como o Envoy.
