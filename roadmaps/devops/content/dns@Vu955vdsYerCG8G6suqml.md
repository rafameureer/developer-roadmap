# DNS

DNS, ou Sistema de Nomenclatura de Domínio, é um sistema de nomeação hierárquico que funciona como um caderno telefônico para a internet traduzindo nomes de domínios humanamente legíveis, como [www.example.com](http://www.example.com), em endereços IP numéricos que os computadores usam para se identificar em uma rede. Quando você insere um endereço web em um navegador, o sistema consulta vários servidores para localizar o endereço IP específico associado a esse domínio, permitindo que seu dispositivo estabeleça uma conexão com o servidor correto. Esse processo elimina a necessidade de usuários memorizarem cadeias complexas de números, garantindo que a comunicação na rede permaneça amigável e eficiente.
