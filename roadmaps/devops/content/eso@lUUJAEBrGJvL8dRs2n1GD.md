# ESO

External Secrets Operator (ESO) é um operador do Kubernetes que puxa segredos de sistemas de gerenciamento de segredos externos, como AWS Secrets Manager, Vault ou GCP Secret Manager, e cria automaticamente objetos de segredo do Kubernetes a partir deles. Isso permite que equipes gerenciem segredos em um repositório central enquanto ainda os tornam disponíveis nativamente dentro do Kubernetes.
