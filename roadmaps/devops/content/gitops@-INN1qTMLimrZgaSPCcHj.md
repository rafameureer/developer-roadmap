# GitOps

GitOps é uma maneira de gerenciar a infraestrutura e implantações de aplicativos armazenando o estado desejado em um repositório do Git e usando automação para aplicar alterações. Ele trata o Git como a única fonte de verdade, então as atualizações são feitas com a commit das alterações no repositório, e ferramentas automatizadas reconciliam o estado real do sistema com o que está no Git.
