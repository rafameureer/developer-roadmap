# Nexus

O Nexus Repository Manager é um software de gerenciador de repositórios amplamente utilizado desenvolvido pela Sonatype. Ele foi projetado para gerenciar componentes binários como bibliotecas Java, imagens Docker, pacotes npm, pacotes NuGet e mais. O Nexus Repository Manager permite que organizações armazenem, gerenciem e distribuam componentes de software de forma segura e eficiente.

Acesse os seguintes recursos para saber mais:

- [@artigo@Usando o Nexus Repository](https://help.sonatype.com/en/using-nexus-repository.html)
- [@artigo@Melhores práticas do Nexus](https://help.sonatype.com/repomanager3/nexus-repository-best-practices)
