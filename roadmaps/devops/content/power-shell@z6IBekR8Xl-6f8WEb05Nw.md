# PowerShell

PowerShell é uma solução de automação de tarefas cross-platform composta por um shell de linha de comando, um idioma de script e um quadro de gerenciamento de configuração. Ele permite que os usuários execute comandos e scripts para gerenciar sistemas, automatizar tarefas administrativas repetitivas e interagir com diversos serviços de nuvem ou componentes da infraestrutura local. Ao utilizar objetos em vez de texto para entrada e saída, ele oferece uma maneira poderosa de manipular dados e simplificar fluxos de trabalho em ambientes Windows, Linux e macOS.
