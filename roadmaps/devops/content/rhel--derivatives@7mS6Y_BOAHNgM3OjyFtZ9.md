# RHEL e Derivativos

RHEL (Red Hat Enterprise Linux) é um sistema operacional de código aberto comercial projetado para ambientes empresariais, fornecendo uma base estável e segura para executar aplicativos em escala. Seus derivados, como AlmaLinux, Rocky Linux e CentOS Stream, são projetos orientados pela comunidade que mantêm alta compatibilidade binária com o RHEL. Esses sistemas são amplamente utilizados na infraestrutura de servidores para gerenciar recursos, lidar com a rede e executar implantações de software através de ferramentas de gerenciamento de pacotes como DNF e RPM.
