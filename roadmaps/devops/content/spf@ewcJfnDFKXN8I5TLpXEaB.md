# SPF

Sender Policy Framework (SPF) é usado para autenticar o remetente de um email. Com um registro SPF em vigor, provedores de serviços de internet podem verificar se um servidor de email está autorizado a enviar emails para um domínio específico. Um registro SPF é um registro TXT DNS contendo uma lista de endereços IP que são permitidos enviar emails em nome do seu domínio.
