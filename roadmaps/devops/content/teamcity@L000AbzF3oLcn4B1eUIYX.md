# TeamCity

TeamCity é um servidor de CI/CD desenvolvido pela JetBrains que automatiza a construção, teste e implantação de software. Oferece uma interface web, integração profunda com sistemas de controle de versão e suporte forte para uma ampla gama de ferramentas de build e linguagens, tornando-se popular em ambientes corporativos.

- [@official@Tutoriais do TeamCity](https://www.jetbrains.com/teamcity/tutorials/)
