# Twitch
 
O Twitch é uma plataforma de transmissão ao vivo, principalmente conhecida por jogos, mas com uma comunidade crescente de desenvolvedores e codificação. É usada por alguns profissionais DevRel para sessões de codificação ao vivo, pair programming e interações sociais casuais da comunidade. As funcionalidades de chat e clipe do Twitch tornam fácil para os espectadores se envolverem e compartilharem momentos de uma transmissão.
