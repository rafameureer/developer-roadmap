# Casos de Uso

Projetos de exemplo baseados em casos de uso são organizados em torno do que um desenvolvedor deseja construir, em vez de em torno de recursos individuais da API. Exemplos incluem uma aplicação de chat, um pipeline de processamento de imagens ou uma integração de pagamento. Essa abordagem é mais intuitiva para os desenvolvedores que chegam com um objetivo em mente em vez de desejar explorar a API sistematicamente.
