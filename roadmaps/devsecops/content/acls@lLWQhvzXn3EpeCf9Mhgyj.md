# Listas de Controle de Acesso (ACLs)

As Listas de Controle de Acesso (ACLs) são conjuntos de regras que determinam se o tráfego de rede é permitido ou negado para passar por uma interface de rede. Eles atuam como um filtro de segurança, examinando pacotes com base em endereços IP de origem e destino, portas e protocolos. ACLs são configurados em dispositivos de rede como roteadores e firewalls para controlar o acesso à rede e impor políticas de segurança.
