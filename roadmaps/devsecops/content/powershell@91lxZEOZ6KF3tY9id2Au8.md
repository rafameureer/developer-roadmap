# PowerShell

PowerShell é um quadro de automação e gerenciamento de configuração multiplataforma, composto por uma shell de linha de comando e um idioma de script associado. Ele permite que os usuários automatizem tarefas administrativas em sistemas Windows, Linux e macOS locais e remotos. PowerShell usa cmdlets (pronunciados como "command-lets") para realizar ações específicas, e esses cmdlets podem ser combinados em scripts para automatizar processos complexos.
