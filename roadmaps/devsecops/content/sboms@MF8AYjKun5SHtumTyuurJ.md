# SBOMs

A Software Bill of Materials (SBOM) é um inventário abrangente de todos os componentes, bibliotecas e dependências usados na construção de uma aplicação de software. É essencialmente uma lista que detalha os ingredientes do seu software, como uma etiqueta nutricional para alimentos. Isso permite aos desenvolvedores e equipes de segurança entender a composição do seu software e identificar potenciais vulnerabilidades ou problemas de licenciamento associados a esses componentes.
