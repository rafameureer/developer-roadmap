# SHA-256

SHA-256 (Secure Hash Algorithm 256-bit) é uma função de hash criptográfica que gera um hash quase único de 256 bits (32 bytes) a partir de qualquer dados de entrada. Esse hash atua como um digital fingerprint, o que significa que mesmo uma pequena alteração na entrada resultará em um valor de hash significativamente diferente. Ele é usado principalmente para verificar a integridade dos dados, assinaturas digitais e armazenamento de senhas devido à sua natureza unidirecional, tornando-se computacionalmente infeasível revertê-lo e derivar o entrada original do hash.
