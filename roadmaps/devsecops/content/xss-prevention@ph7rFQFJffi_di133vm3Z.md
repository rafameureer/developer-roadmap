# Prevenção de Cross-Site Scripting (XSS)

Cross-Site Scripting (XSS) é um tipo de vulnerabilidade de segurança que permite que atacantes injetem scripts maliciosos em sites vistos por outros usuários. Esses scripts podem então ser executados no navegador do usuário, potencialmente roubando informações sensíveis como cookies, redirecionando o usuário para sites maliciosos ou desfigurando o site. Prevenir XSS envolve sanitizar as entradas dos usuários, codificar as saídas e implementar políticas de segurança para garantir que dados não confiáveis não possam ser executados como código.
