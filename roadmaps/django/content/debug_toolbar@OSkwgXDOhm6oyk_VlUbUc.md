# Django Debug Toolbar

O Django Debug Toolbar é um conjunto poderoso de painéis que exibe várias informações de depuração sobre a solicitação e resposta atuais. Ele aparece como uma barra de ferramentas colapsável em seu navegador quando você está desenvolvendo uma aplicação Django. Esta barra de ferramentas fornece insights em consultas de banco de dados, renderização de templates, configurações, cabeçalhos, arquivos estáticos e muito mais, ajudando os desenvolvedores a identificar e resolver bottlenecks de desempenho e outros problemas rapidamente.
