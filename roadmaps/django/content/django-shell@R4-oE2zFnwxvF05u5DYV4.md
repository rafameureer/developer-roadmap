# Django Shell

O Django Shell é um interpretador Python interativo que fornece acesso direto aos modelos, banco de dados e configurações do seu projeto Django. Ele permite testar trechos de código, consultar dados e realizar tarefas administrativas sem a necessidade de executar toda a aplicação. É essencialmente um ambiente de linha de comando pré-configurado com as configurações e modelos do seu projeto Django.
