# Filtragem e Lookups no Django ORM

A filtragem e os lookups são mecanismos fundamentais dentro do Object-Relational Mapper (ORM) do Django que permitem você fazer consultas precisas em seu banco de dados. Eles habilitam a recuperação de dados específicos com base em critérios definidos, como encontrar todos os usuários com um nome específico ou todas as artigos publicados em um determinado intervalo de datas. Essas ferramentas fornecem uma maneira poderosa e flexível de interagir com seu banco de dados sem escrever consultas SQL brutas.
