# Filtros & Filtros Personalizados

Os filtros no Django Template Language (DTL) são usados para modificar a saída de variáveis. Eles são aplicados usando um pipe `|` e podem realizar várias transformações como alterar o caso, formatar datas ou truncar texto. Os filtros personalizados permitem aos desenvolvedores definir seus próprios tags de template reutilizáveis para realizar manipulações específicas de dados não cobertas pelos filtros embutidos.
