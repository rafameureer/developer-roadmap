# Como a Web Funciona

A web opera através de um modelo cliente-servidor, onde um cliente (como um navegador da web) envia uma solicitação para um servidor, e o servidor processa essa solicitação e devolve uma resposta. Essa interação envolve protocolos como HTTP para comunicação, URLs para identificar recursos e DNS para traduzir nomes de domínio em endereços IP, permitindo que usuários acessem e interajam com conteúdo hospedado em servidores na internet.
