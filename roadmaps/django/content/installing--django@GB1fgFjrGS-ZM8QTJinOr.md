# Instalando Django

Instalar Django envolve configurar o pacote Django em seu sistema para que você possa começar a desenvolver aplicativos web. Isso geralmente envolve usar um instalador de pacotes como pip para baixar e instalar os arquivos e dependências necessários. Uma vez instalado, você pode verificar a instalação e começar a criar o seu projeto Django.

Acesse os seguintes recursos para saber mais:

- [@oficial@Como instalar o Django](https://docs.djangoproject.com/en/6.0/topics/install/)
- [@oficial@Como obter o Django](https://www.djangoproject.com/download/)
- [@artigo@Introdução ao Django](https://www.w3schools.com/django/django_getstarted.php)
- [@vídeo@Como Instalar o Django para Python 3.11.3 | PIP e Django no Windows 10/11 | Tutoriais do Django](https://www.youtube.com/watch?v=Uq7TkegTXRU)
