# Introdução

Django é um framework web de alto nível em Python que incentiva o desenvolvimento rápido e a design pragmático. Ele cuida de muitos dos problemas do desenvolvimento web, permitindo que você se concentre em escrever seu aplicativo sem precisar reinventar a roda. Django segue o padrão arquitetônico modelo-template-views (MTV), fornecendo uma maneira estruturada de construir aplicativos web.
