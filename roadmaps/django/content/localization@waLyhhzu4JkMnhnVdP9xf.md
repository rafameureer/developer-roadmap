# Localização

A localização é o processo de adaptar um produto ou conteúdo a um mercado de destino específico. Isso envolve traduzir texto, mas também adaptar outros elementos como formatos de data, símbolos monetários e referências culturais para que o produto se sinta nativo ao usuário da região. Isso garante que a aplicação seja acessível e relevante para usuários de diferentes línguas e backgrounds culturais.
