# Migrações

As migrações no Django são uma maneira de propagar as alterações que você faz em seus modelos (como adicionar um campo, deletar um modelo, etc.) para o esquema do banco de dados. Elas são essencialmente arquivos Python que descrevem como alterar suas tabelas de banco de dados para corresponder ao estado atual dos seus modelos. O Django usa esses arquivos para manter seu esquema de banco de dados em sincronização com os modelos da sua aplicação ao longo do tempo.
