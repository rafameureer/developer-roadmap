# Modelos

Os modelos são classes Python que representam tabelas do banco de dados. Cada atributo do modelo representa um campo do banco de dados. O Django usa esses modelos para interagir com o banco de dados, permitindo que você crie, leia, atualize e exclua dados sem escrever consultas SQL brutas. Eles definem a estrutura dos seus dados e fornecem uma interface de alto nível para operações no banco de dados.
