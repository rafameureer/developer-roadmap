# Roteadores no Django REST Framework

Roteadores no Django REST Framework (DRF) fornecem uma maneira automatizada de gerar padrões de URL para suas views da API. Em vez de definir manualmente URLs para ações comuns da API como listar, criar, recuperar, atualizar e excluir recursos, os roteadores lidam com isso automaticamente com base nos viewsets que você define. Isso simplifica a configuração de URL e promove consistência em sua API.
