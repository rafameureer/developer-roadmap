# SQLite no Django

O SQLite é um motor de banco de dados SQL autônomo, sem servidor, sem configuração e transacional. Ele é incorporado diretamente na aplicação, o que significa que não requer um processo de servidor separado para operar. Isso o torna uma escolha leve e conveniente para desenvolvimento, teste e projetos Django pequenos.
