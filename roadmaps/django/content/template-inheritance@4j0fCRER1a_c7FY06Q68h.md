# Herança de Templates

A herança de templates no Django permite que você crie um "esqueleto" base template que contém todos os elementos comuns do seu site (como o cabeçalho, rodapé e navegação). Os templates filhos podem então estender este template base e substituir blocos específicos de conteúdo, preenchendo as partes únicas para cada página enquanto reutiliza a estrutura comum. Isso promove a reutilização de código e manutenibilidade ao evitar repetição em seus templates de site.
