# O Modelo MVC

O padrão arquitetônico de Model-View-Controller (MVC) separa uma aplicação em três partes interconectadas. O Model gerencia os dados e a lógica de negócios, o View exibe os dados ao usuário e o Controller lida com a entrada do usuário e atualiza o Model. O Django usa uma versão modificada chamada Model-Template-View (MTV), onde a Template é a camada de apresentação (como a View no MVC) e a View lida com a lógica de que dados exibir (como o Controller no MVC). A estrutura do framework do Django naturalmente encoraja essa separação de preocupações, tornando mais fácil desenvolver e manter aplicativos web complexos.
