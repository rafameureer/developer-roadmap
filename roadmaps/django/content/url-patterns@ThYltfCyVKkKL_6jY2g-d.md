# URL patterns

Os padrões de URL no Django definem como as URLs (endereços web) são mapeadas para exibições específicas (funções que lidam com solicitações). Eles atuam como um diretório, informando ao Django qual exibição executar quando um usuário visita uma URL específica. Cada padrão consiste em uma expressão regular que corresponde a uma URL e uma função de exibição correspondente. Quando uma URL corresponde a um padrão, o Django chama a exibição associada, passando o objeto de solicitação e quaisquer parâmetros capturados da URL.
