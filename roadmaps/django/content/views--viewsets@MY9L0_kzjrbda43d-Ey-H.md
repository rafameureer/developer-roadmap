# Visualizações & ViewSets

As visualizações no Django REST Framework lidam com a lógica para processar solicitações web entrantes e retornar respostas, semelhante às visualizações regulares do Django. Os ViewSets fornecem uma maneira de agrupar visualizações relacionadas em uma única classe, reduzindo a duplicação de código e simplificando a criação de APIs complexas oferecendo ações pré-construídas como list, create, retrieve, update e delete.
