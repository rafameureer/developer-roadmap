# Whitenoise

Whitenoise é uma biblioteca que permite que sua aplicação web sirva arquivos estáticos diretamente de seu próprio servidor WSGI. Isso significa que você não precisa depender de um servidor web separado como Nginx ou Apache para servir ativos estáticos como CSS, JavaScript e imagens. Ele simplifica a implantação, especialmente em ambientes onde configurar um servidor de arquivos estáticos separado é complexo ou indesejável.
