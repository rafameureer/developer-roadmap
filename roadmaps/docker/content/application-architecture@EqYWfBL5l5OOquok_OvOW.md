# Arquitetura de Aplicativos

A arquitetura de aplicativos em ambientes containerizados se concentra em projetar aplicativos para aproveitar os benefícios da contêinerização. Isso inclui padrões de microservices, decomposição de serviços, comunicação entre serviços, estratégias de persistência de dados e design para escalabilidade e tolerância a falhas em sistemas distribuídos.
