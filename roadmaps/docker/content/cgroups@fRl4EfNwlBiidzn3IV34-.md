# cgroups

cgroups (control groups) são recursos do kernel Linux que limitam e gerenciam os recursos do sistema como CPU, memória e I/O para grupos de processos. O Docker usa cgroups para impor restrições de recursos nos contêineres, garantindo um desempenho previsível e impedindo que os contêineres consumam recursos do sistema em excesso.
