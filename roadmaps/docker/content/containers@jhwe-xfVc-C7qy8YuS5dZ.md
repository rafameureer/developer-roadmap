# Contêineres

Contêineres são ambientes isolados e leves que executam aplicativos usando um kernel de sistema operacional compartilhado, garantindo consistência e portabilidade em diferentes ambientes computacionais. Eles encapsulam tudo o que é necessário para executar um aplicativo, como código, dependências e configurações, tornando fácil mover e executar a aplicação contêinerizada em qualquer lugar. Usando a CLI do Docker, você pode criar, iniciar, parar e gerenciar contêineres com comandos como `docker run`, `docker ps` para listar os contêineres em execução, `docker stop` para interromper e `docker exec` para interagir com eles em tempo real. A CLI fornece uma interface poderosa para desenvolvedores construir, controlar e depurar contêineres de forma eficiente, permitindo fluxos de trabalho de desenvolvimento e operacional otimizados.
