# Integração Contínua (CI)

A integração contínua é a ideia de executar algumas ações (por exemplo, build, testes, etc.) automaticamente ao empurrar o código para seu sistema de controle de versão.

Para contêineres, há várias coisas que podemos querer fazer:

*   Construir imagens de contêiner
*   Executar testes
*   Scannear imagens de contêiner em busca de vulnerabilidades
*   Marcar imagens com metadados úteis
*   Empurrar para um repositório de contêiner
