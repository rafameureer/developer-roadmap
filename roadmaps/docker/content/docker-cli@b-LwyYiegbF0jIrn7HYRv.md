# CLI do Docker

A Interface de Linha de Comando (CLI) do Docker é uma ferramenta poderosa usada para interagir com o motor do Docker, permitindo que desenvolvedores e operadores construam, gerenciem e solucionem problemas em contêineres e recursos relacionados. Com um amplo conjunto de comandos, a CLI do Docker fornece controle sobre todos os aspectos do Docker, incluindo a criação e gestão de contêineres (`docker run`, `docker stop`), construção de imagens (`docker build`), gestão de redes (`docker network`), manipulação de armazenamento (`docker volume`) e inspeção do status do sistema (`docker ps`, `docker info`). Sua sintaxe intuitiva e flexibilidade permitem aos usuários automatizar fluxos de trabalho complexos, streamlinhar processos de desenvolvimento e manter aplicativos contínuos com facilidade, tornando-se uma ferramenta fundamental para a gestão e orquestração do Docker.
