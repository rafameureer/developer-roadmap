# Alternativas ao DockerHub

Imagens de contêiner podem ser armazenadas em muitos diferentes registros, não apenas no Dockerhub. A maioria das grandes plataformas de nuvem agora oferece registros de contêiner como "Artifact Registry" na Plataforma do Google Cloud, Elastic Container Registry na AWS e Azure Container Registry na Microsoft Azure. O GitHub também fornece seu próprio registro que é útil quando as construções de contêiner estão incluídas em seu fluxo de trabalho do GitHub Actions.

Acesse os seguintes recursos para saber mais:

- [@oficial@DockerHub](https://hub.docker.com/)
- [@oficial@Artifact Registry](https://cloud.google.com/artifact-registry)
- [@oficial@Amazon ECR](https://aws.amazon.com/ecr/)
- [@oficial@Azure Container Registry](https://azure.microsoft.com/en-in/products/container-registry)
- [@oficial@GitHub Container Registry](https://docs.github.com/en/packages/guides/about-github-container-registry)
