# Linguagens de Programação

Ter proficiência em pelo menos uma linguagem de programação é essencial antes de trabalhar com Docker, pois os contêineres são usados finalmente para empacotar e executar aplicativos. Independentemente da linguagem que você use (Python, JavaScript, Go, Java ou outra), entender como o seu aplicativo é construído, suas dependências e seus requisitos de tempo de execução informa diretamente como você escreve Dockerfiles e estrutura imagens de contêiner. Conhecimento do gerenciamento de pacotes, ferramentas de construção e ambiente de tempo de execução da sua linguagem ajuda a criar imagens Docker eficientes e mínimas adaptadas às necessidades do seu aplicativo.
