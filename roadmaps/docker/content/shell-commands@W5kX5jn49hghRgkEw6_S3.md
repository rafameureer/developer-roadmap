# Comandos de Shell

Os comandos de shell são a maneira fundamental de interagir com sistemas baseados em Linux que os contêineres Docker geralmente executam. Entender comandos como `ls`, `cd`, `cp`, `mv`, `rm`, `chmod`, `chown`, `ps`, `top`, `grep`, `find` e `cat` é essencial para trabalhar dentro dos contêineres, escrever Dockerfiles e depurar contêineres em execução. Quando você usa `docker exec` para acessar um contêiner em execução ou escreve instruções `RUN` em um Dockerfile, depende desses comandos de shell para instalar dependências, configurar ambientes e gerenciar arquivos no sistema de arquivos do contêiner.
