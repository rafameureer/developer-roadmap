# Autenticação

A autenticação é o processo de verificar a identidade de um usuário ou sistema tentando acessar um recurso. Ele garante que apenas indivíduos ou aplicativos autorizados possam obter acesso, exigindo que eles provem quem são, geralmente através de credenciais como nomes de usuário e senhas, chaves de API ou certificados. Esse processo confirma que o usuário ou sistema é na verdade quem diz ser antes de conceder acesso.
