# Cluster (Sistema)

Um cluster é uma coleção de um ou mais nós do Elasticsearch que trabalham juntos para armazenar e processar dados. Ele fornece um sistema distribuído e escalável onde os dados são divididos em shards e distribuídos em vários nós para redundância e desempenho. O cluster gerencia operações de indexação, busca e análise em todos os nós, apresentando uma visão unificada dos dados ao usuário.
