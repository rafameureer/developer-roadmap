# Criar Índice

Criar um índice no Elasticsearch usando a API de Documentos envolve enviar uma solicitação PUT ao servidor Elasticsearch. Essa solicitação especifica o nome do índice que você deseja criar. Você também pode incluir configurações e mapeamentos no corpo da solicitação para configurar como o índice deve armazenar e analisar seus dados. Se o índice ainda não existir, o Elasticsearch criará ele com base na configuração fornecida. Se o índice já existir, você receberá um erro.
