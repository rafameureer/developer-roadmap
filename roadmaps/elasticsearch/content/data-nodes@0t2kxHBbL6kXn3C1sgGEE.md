# Nós de Dados

Nós de dados no Elasticsearch são os cavaleiros de trabalho da cluster, responsáveis por armazenar dados e realizar operações intensivas em CPU e I/O como busca, indexação e análise de dados. Esses nós mantêm fragmentos (shards) dos índices do Elasticsearch e gerenciam a armazenamento real dos dados no disco. Eles contribuem significativamente para o desempenho e escalabilidade globais da cluster.
