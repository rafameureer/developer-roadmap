# Elastic Cloud

Elastic Cloud é uma suite de serviços baseados em Elasticsearch oferecidos pela Elastic, a empresa por trás do Elasticsearch. Ele fornece uma plataforma gerenciada para implantar, gerenciar e escalar clusters Elasticsearch na nuvem, eliminando a necessidade de usuários lidarem com a infraestrutura subjacente. Isso inclui tarefas como fornecer servidores, configurar redes e gerenciar backups, permitindo que os usuários se concentrem em analisar e visualizar seus dados.
