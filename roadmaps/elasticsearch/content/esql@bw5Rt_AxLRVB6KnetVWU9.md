# ES|QL

ES|QL é um idioma de consulta projetado para o Elasticsearch que permite aos usuários pesquisar, transformar e analisar dados usando uma sintaxe semelhante ao SQL. Ele oferece uma maneira mais familiar e acessível de interagir com os dados do Elasticsearch em comparação com a DSL JSON tradicional, permitindo que os usuários realizem manipulações e agregações de dados complexas com facilidade.
