# Consulta Exists

Uma consulta exists no Elasticsearch é usada para encontrar documentos que contêm um campo específico, independentemente de seu valor. Ela verifica a presença do campo nos dados-fonte do documento. Isso é útil quando você precisa filtrar documentos com base em whether um determinado campo foi definido ou não.
