# Tipo de Dados Flattened

O tipo de dados flattened no Elasticsearch permite que você indexe um objeto JSON inteiro como um único campo. Isso é útil quando você tem objetos com muitos campos, mas precisa apenas pesquisar ou agrupar em um subconjunto pequeno deles. Em vez de mapear cada campo individualmente, o tipo flattened indexa todo o objeto como uma string, permitindo que você consulte valores específicos dentro do objeto usando consultas especializadas.
