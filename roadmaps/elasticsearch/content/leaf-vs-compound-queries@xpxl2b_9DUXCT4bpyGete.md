# Folhas vs. Consultas Compostas

As consultas folha no Elasticsearch direcionam campos específicos com critérios de pesquisa simples, como encontrar documentos onde um campo corresponde a um valor específico ou se encontra em um determinado intervalo. As consultas compostas, por outro lado, combinam várias consultas folhas ou outras consultas compostas para criar uma lógica de pesquisa mais complexa, permitindo especificar como essas consultas individuais devem interagir (por exemplo, todas devem corresponder, pelo menos uma deve corresponder ou nenhuma deve corresponder).
