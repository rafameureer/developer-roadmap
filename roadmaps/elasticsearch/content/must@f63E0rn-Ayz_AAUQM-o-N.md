# Consultas Must

A consulta "must" no Elasticsearch é um tipo de consulta composta que especifica condições que os documentos devem atender para serem incluídos nos resultados da pesquisa. Ela contribui para a pontuação de relevância de cada documento correspondente. Basicamente, ela funciona como um filtro obrigatório, garantindo que apenas os documentos que correspondam aos critérios especificados sejam retornados.
