# Nó (Instância)

Um nó é um único servidor em um cluster do Elasticsearch que armazena dados e participa das capacidades de indexação e busca do cluster. Cada nó é configurado com um nome e pode ser atribuído papéis específicos, como master, data ou ingest, para otimizar a alocação de recursos e o desempenho do cluster. Os nós se comunicam entre si para distribuir dados, gerenciar o estado do cluster e lidar com solicitações de busca.
