# Pesquisa de Vetor

A pesquisa de vetor é um método de busca de dados com base em seu significado ou contexto, em vez de correspondências exatas de palavras-chave. Envolve representar os dados como vetores de alta dimensão, onde cada vetor captura as propriedades semânticas dos dados. As consultas de pesquisa também são convertidas em vetores e o sistema encontra pontos de dados com vetores que estão "próximos" ao vetor de consulta, indicando similaridade semântica.
