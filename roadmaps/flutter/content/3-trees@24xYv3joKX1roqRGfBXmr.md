# Árvores

Uma árvore é uma estrutura de dados usada para representar a hierarquia de widgets em um aplicativo Flutter. A estrutura de árvore permite que o Flutter gerencie o layout, estilo e comportamento dos widgets no aplicativo.

Acesse os seguintes recursos para saber mais:

- [@official@Árvore em Flutter](https://docs.flutter.dev/resources/inside-flutter#tree-surgery)
- [@article@Começando com Flutter — Entendendo a Árvore de Widgets](https://medium.com/@JediPixels/beginning-flutter-understanding-the-widget-tree-3513c94dc356)
