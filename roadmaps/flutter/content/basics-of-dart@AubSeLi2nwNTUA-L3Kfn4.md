# Básicos do Dart

Dart é um idioma de programação de propósito geral, orientado a objetos com sintaxe semelhante ao C desenvolvido pela Google em 2011. O objetivo da programação em Dart é criar interfaces de usuário front-end para aplicativos web e móveis. Ele também pode ser usado para construir aplicativos de servidor e desktop.
