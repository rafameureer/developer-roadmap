# Desenvolvimento Guiado por Comportamento (BDD)

O desenvolvimento guiado por comportamento (Behavior-driven development, BDD) é um método de desenvolvimento de software que enfatiza a colaboração entre desenvolvedores, testadores e stakeholders para definir e verificar o comportamento de uma aplicação. O BDD usa linguagem natural para descrever o comportamento esperado da aplicação e fornece uma compreensão compartilhada dos requisitos para o time de desenvolvimento.
