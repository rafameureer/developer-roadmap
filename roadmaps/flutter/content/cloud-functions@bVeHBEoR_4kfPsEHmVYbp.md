# Funções do Firebase Cloud

O Firebase Cloud Functions é uma plataforma de computação sem servidor que simplifica o desenvolvimento de back-end permitindo aos desenvolvedores escrever código em JavaScript ou TypeScript, que é executado automaticamente em resposta a eventos dos serviços do Firebase ou solicitações HTTP entrantes. Este framework aproveita a infraestrutura da Google para fornecer um ambiente escalável e gerenciado, tornando mais fácil construir aplicativos de back-end sem a necessidade de manutenção de servidores.
