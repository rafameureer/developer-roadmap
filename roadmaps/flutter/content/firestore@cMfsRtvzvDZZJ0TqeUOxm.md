# Firestore

Firebase Firestore é um serviço de banco de dados NoSQL em nuvem fornecido pelo Firebase que facilita o armazenamento, gerenciamento e recuperação de dados em seu aplicativo Flutter. Firestore é um banco de dados flexível, escalável e fácil de usar que permite armazenar e recuperar dados no formato de documentos, coleções e campos.
