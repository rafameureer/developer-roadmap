# Mixpanel

Mixpanel é uma plataforma de análise de produtos que fornece insights sobre o comportamento do usuário para aplicativos móveis, incluindo aqueles construídos com Flutter.

Com o Mixpanel, os desenvolvedores de Flutter podem rastrear as interações dos usuários com seu aplicativo, incluindo visualizações de página, eventos e propriedades do usuário, e usar esses dados para obter insights sobre o comportamento do usuário. O Mixpanel oferece uma variedade de ferramentas e recursos para analisar esses dados, incluindo painéis em tempo real, segmentação e testes A/B.
