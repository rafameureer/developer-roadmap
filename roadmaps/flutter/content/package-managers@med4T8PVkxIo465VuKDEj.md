# Gerenciador de Pacotes

O gerenciador de pacotes para o Flutter é chamado pub. Ele é usado para gerenciar as dependências dos projetos do Flutter e publicar pacotes do Flutter. Ele está incluído com o SDK do Flutter e pode ser executado a partir da linha de comando usando o comando `pub`.

Acesse os seguintes recursos para saber mais:

- [@official@Pacotes e Plugins](https://docs.flutter.dev/development/packages-and-plugins)
- [@video@Gerenciador de Pacotes Dart (pub.dev) no Flutter](https://www.youtube.com/watch?v=F1VRO0_MKLs)
