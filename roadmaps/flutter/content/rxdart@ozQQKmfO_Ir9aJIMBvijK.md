# RxDart

RxDart é uma biblioteca para Dart que fornece funcionalidades adicionais para trabalhar com programação reativa, especificamente com as classes Streams e Observables. Ela estende a API padrão de Streams do Dart e fornece funcionalidades adicionais como a capacidade de transformar e combinar streams, e compor e encadear streams juntos. No Flutter, RxDart é comumente usado para lidar com fluxos de dados assíncronos e interações do usuário de uma maneira mais eficiente e elegante.
