# Shared Preferences

No Flutter, SharedPreferences é um plugin que permite armazenar dados em pares de chave-valor persistentemente. É semelhante a uma base de dados local ou cache, mas foi especificamente projetado para armazenar pequenas partes de dados, como preferências do usuário ou configurações. O plugin SharedPreferences é frequentemente usado para armazenar pedaços simples de dados que precisam ser acessados por várias telas ou widgets em um aplicativo. Por exemplo, você pode usar SharedPreferences para armazenar o status de login do usuário ou a cor do tema do aplicativo.
