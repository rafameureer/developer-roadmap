# Armazenamento

O Flutter oferece várias opções para armazenamento persistente, algumas das quais são:

*   SharedPreferences: Um repositório de chave-valor para dados pequenos.
*   Banco de Dados SQLite: Um banco de dados relacional para dados estruturados.
*   Sistema de Arquivos: Para armazenar arquivos e dados grandes.
*   Firebase: Uma base de dados em tempo real e backend como serviço.

Todas essas opções de armazenamento são suportadas por meio de pacotes terceiros, que podem ser facilmente integrados a um aplicativo Flutter.
