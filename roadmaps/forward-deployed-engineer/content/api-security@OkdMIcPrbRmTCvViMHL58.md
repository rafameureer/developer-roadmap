# Segurança de API

A segurança de API abrange as práticas e controles necessários para proteger APIs de acesso não autorizado e abuso. Isso inclui autenticação, autorização, limitação de taxa, validação de entrada e proteção contra ataques comuns. Ao construir APIs, é importante seguir os padrões de segurança do cliente e projetar endpoints que não sejam vulneráveis ao uso inadequado, especialmente quando essas APIs expõem capacidades de IA.
