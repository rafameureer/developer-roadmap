# AWS

O Amazon Web Services (AWS) é a maior plataforma de nuvem por participação do mercado, oferecendo serviços em computação (EC2, Lambda), armazenamento (S3), bancos de dados (RDS, DynamoDB), rede e ferramentas de IA/ML. Uma grande proporção dos ambientes de cliente rodam no AWS, tornando-o uma das plataformas de nuvem mais comuns que um FDE precisará trabalhar.
