# Claude Code

Claude Code é uma ferramenta de IA baseada em terminal construída pela Anthropic. Ele está projetado para resolver problemas complexos de código, explicar códigos desconhecidos e ajudar com a depuração. Funciona melhor quando você precisa entender o que um pedaço de código está fazendo antes de modificá-lo; forneça um problema específico e ele passará por ele passo a passo.
