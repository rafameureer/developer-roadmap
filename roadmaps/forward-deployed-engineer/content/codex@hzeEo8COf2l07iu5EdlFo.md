# Codex

Codex é o modelo de código focado da OpenAI, treinado em grandes quantidades de código público e que alimenta o GitHub Copilot. Ele pode gerar código a partir de descrições naturais, completar funções e auxiliar na documentação. É uma das ferramentas fundamentais no ecossistema de codificação assistida por IA que os FDEs podem usar ou encontrar em equipes de engenharia de clientes.
