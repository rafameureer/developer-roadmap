# Frontend

O desenvolvimento frontend refere-se à parte do desenvolvimento web que se ocupa de tudo o que os usuários veem e interagem em um navegador. Inclui HTML para estrutura, CSS para estilização e JavaScript para interatividade. Os FDEs que conseguem construir frontends funcionais são mais independentes nas negociações com clientes, capazes de entregar demonstrações e protótipos funcionais sem depender de uma equipe frontend separada.
