# Git & GitHub

O Git é um sistema de controle de versão distribuído que rastreia as alterações no código ao longo do tempo e permite que várias pessoas colaborem na mesma base de código. O GitHub adiciona recursos como solicitações de pull, revisão de código, acompanhamento de problemas e integrações de CI/CD sobre o Git. Os FDEs trabalham regularmente dentro dos repositórios dos clientes, contribuem para bases de código compartilhadas e precisam seguir as convenções existentes de ramificação e revisão desde o início.
