# JavaScript / TypeScript

JavaScript é o idioma de programação da web, rodando nativamente em navegadores e em servidores via Node.js. TypeScript é um superconjunto do JavaScript que adiciona anotações de tipo estático, ajudando a capturar erros cedo e melhorar a manutenção do código. Juntos cobrem uma grande parte dos códigos de clientes e trabalho frontend que um FDE provavelmente encontrará.
