# Linux

O Linux é um sistema operacional open-source amplamente utilizado em servidores, ambientes de nuvem e estação de trabalho do desenvolvedor. A maioria dos softwares em produção roda no Linux, então ser confortável navegando em um sistema Linux, gerenciando processos, lendo logs e configurando serviços é uma necessidade prática para qualquer pessoa que esteja construindo e implantando em ambientes reais de clientes.
