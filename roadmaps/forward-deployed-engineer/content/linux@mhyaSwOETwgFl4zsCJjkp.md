# Linux

Linux é um sistema operacional de código aberto amplamente utilizado em servidores, ambientes de nuvem e estação de trabalho para desenvolvedores. A maioria dos softwares de produção roda no Linux, então ser confortável navegando em um sistema Linux, gerenciando processos, lendo logs e configurando serviços é uma necessidade prática para qualquer pessoa que esteja construindo e implantando em ambientes reais de clientes.
