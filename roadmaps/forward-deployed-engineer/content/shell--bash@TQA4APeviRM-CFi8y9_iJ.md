# Shell / Bash

O Bash é um shell de linha de comando e linguagem de script disponível em maioria dos sistemas Unix-like. Os scripts de shell permitem automatizar tarefas repetitivas, gerenciar arquivos, configurar sistemas e encadear ferramentas de linha de comando. Ser fluente em Bash permite aos FDEs se mover rapidamente em ambientes de terminal, depurar problemas de implantação rapidamente e escrever automação leve sem recorrer a uma ferramenta mais pesada.
