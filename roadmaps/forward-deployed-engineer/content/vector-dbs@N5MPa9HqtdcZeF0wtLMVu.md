# Bancos de Dados Vetoriais

Os bancos de dados vetoriais armazenam embeddings vetoriais de alta dimensão e suportam buscas de similaridade eficientes. Eles são um componente central dos sistemas RAG e aplicativos de busca semântica, onde o objetivo é encontrar conteúdo semânticamente similar a uma consulta em vez de corresponder palavras-chave exatamente.
