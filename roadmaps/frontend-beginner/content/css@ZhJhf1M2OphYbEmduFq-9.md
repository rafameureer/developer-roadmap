# CSS

CSS (*Cascading Style Sheets* ou Folhas de Estilo em Cascata) é a linguagem utilizada para descrever a aparência e a formatação de um documento escrito em HTML. Ele controla aspectos visuais como cores, fontes, espaçamentos, layout e a apresentação gráfica geral de uma página web, garantindo que ela seja esteticamente agradável e intuitiva para os usuários. Pense no CSS como o estilista do seu site, transformando a estrutura básica fornecida pelo HTML em uma interface bonita e profissional.
