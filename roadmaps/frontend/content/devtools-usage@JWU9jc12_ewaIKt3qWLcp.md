# Uso de DevTools

DevTools são um conjunto de ferramentas de desenvolvedor web integradas diretamente nos navegadores da web. Eles permitem que você inspecione e depure HTML, CSS e JavaScript, monitore a atividade de rede, analise gargalos de desempenho e muito mais. Ao usar DevTools, os desenvolvedores frontend podem entender como seu código é executado no navegador e identificar áreas para otimização.
