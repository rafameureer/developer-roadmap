# GraphQL

O GraphQL é uma linguagem de consulta para APIs criada pela Facebook, que permite aos clientes solicitar exatamente os dados necessários. Reduz o sobre-carregamento (over-fetching) e o sub-carregamento (under-fetching) em comparação com a REST. É ideal para aplicativos móveis, APIs complexas e requisitos que mudam rapidamente com tipagem forte.
