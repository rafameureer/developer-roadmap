# Modelos HTML

O elemento `<template>` do HTML mantém conteúdo oculto para uso posterior pelo JavaScript. Atua como um modelo reutilizável para a criação de elementos de página dinâmicos. Permite o templating eficiente de conteúdo e padrões de desenvolvimento baseados em componentes em aplicativos web.

Acesse os seguintes recursos para saber mais:

- [@artigo@Usando Templates e Slots - MDN](https://developer.mozilla.org/en-US/docs/Web/Web_Components/Using_templates_and_slots)
