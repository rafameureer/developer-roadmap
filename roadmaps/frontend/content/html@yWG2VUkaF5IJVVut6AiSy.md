# HTML

HTML (Hypertext Markup Language) é o padrão para criar páginas web, estruturar conteúdo com elementos e atributos. Os navegadores interpretam as tags HTML para renderizar as páginas. O HTML5, a versão atual do padrão, adiciona elementos semânticos, suporte a mídia multimídia e controles de formulário. Funciona em conjunto com CSS para estilização e JavaScript para interatividade, formando a base do desenvolvimento web.
