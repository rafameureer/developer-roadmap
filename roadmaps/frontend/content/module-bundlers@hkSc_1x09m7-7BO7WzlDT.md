# Empacotadores de Módulos

Os empacotadores de módulos combinam vários arquivos JavaScript em pacotes otimizados para navegadores. Gerenciam dependências, transformação de código e divisão para melhorar o desempenho. Exemplos: Webpack, Rollup, Parcel. Habilitam recursos modernos do JavaScript, melhoram os tempos de carregamento e streamlinham fluxos de trabalho de desenvolvimento.

- [@oficial@Webpack Website](https://webpack.js.org/)
