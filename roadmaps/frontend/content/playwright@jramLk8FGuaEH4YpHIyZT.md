# Playwright

Playwright é um quadro de automação de testes de teste cruzado da Microsoft que suporta Chromium, Firefox e WebKit em várias plataformas. Funciona com JavaScript, TypeScript, Python e .NET. Ele possui recursos como auto-aguardar, controle de rede e simulação de dispositivos móveis. Excelente para testes de aplicativos web modernos com ferramentas de depuração.
