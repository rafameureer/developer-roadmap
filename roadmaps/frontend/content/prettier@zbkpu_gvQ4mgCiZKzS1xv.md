# Prettier

O Prettier formata automaticamente o código para manter consistência em JavaScript, TypeScript, CSS e outras linguagens. Ele impõe regras de estilo opinativas, eliminando debates sobre estilo e economizando tempo. Integra-se com editores e hooks pre-commit. Popular por manter uma aparência de código uniforme entre equipes.
