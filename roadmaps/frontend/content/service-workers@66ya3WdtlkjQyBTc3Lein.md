# Service Workers

Service Workers são arquivos JavaScript que atuam como servidores proxy entre navegadores da web e servidores web. Eles podem interceptar solicitações de rede, cache recursos e entregar notificações de push, mesmo quando o usuário estiver offline. Isso permite melhor desempenho e capacidades offline para aplicativos web.
