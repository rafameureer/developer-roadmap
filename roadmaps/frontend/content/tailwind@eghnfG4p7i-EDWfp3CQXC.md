# Tailwind CSS

Tailwind CSS é um framework de CSS utilitário que fornece classes pequenas e compostas para o desenvolvimento rápido de designs personalizados. Oferece abordagem mobile-first, remoção automática de estilos não utilizados (purging) e customização flexível. Permite prototipagem rápida de design responsivo sem a necessidade de escrever CSS personalizado.
