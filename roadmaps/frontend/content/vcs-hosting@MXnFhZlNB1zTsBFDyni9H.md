# Serviços de Hospedagem de Repositórios

Serviços de hospedagem de repositórios (GitHub, GitLab, Bitbucket) fornecem plataformas para armazenar, gerenciar e colaborar em projetos de software usando o controle de versão Git. Facilitam a equipe de trabalho, compartilhamento de código, rastreamento de projetos e fluxos de trabalho de desenvolvimento distribuído.

Acesse os seguintes recursos para saber mais:

- [@roadmap@Visite a Estrada do Git & GitHub](https://roadmap.sh/git-github)
- [@oficial@Site oficial do GitHub](https://github.com)
- [@oficial@Site oficial do GitLab](https://about.gitlab.com)
- [@oficial@Site oficial do BitBucket](https://bitbucket.com)
