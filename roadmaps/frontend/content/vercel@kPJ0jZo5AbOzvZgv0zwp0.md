# Vercel

Vercel é uma plataforma projetada para implantar e hospedar aplicativos web, especialmente aqueles construídos com frameworks de frontend modernos e geradores de sites estáticos. Ele oferece recursos como implantações automáticas a partir de repositórios Git, funções sem servidor e uma rede global de entrega de conteúdo (CDN) para garantir desempenho rápido e confiável. Vercel simplifica o processo de levar um projeto de frontend do desenvolvimento para produção.
