# Checkpoint

Agora que você aprendeu git e GitHub, deve estar pronto para trabalhar com outros. Você deve configurar agora seu perfil do GitHub e empurrar todos os projetos que construiu até agora para o seu perfil do GitHub. Aqui estão algumas de minhas recomendações para seu perfil do GitHub:

*   Mantenha os nomes dos repositórios em letras minúsculas e use hífens para separar as palavras, por exemplo, `todo-app` em vez de `TodoApp` ou `Todo-App`.
*   Adicione um arquivo `README.md` a cada repositório que você criar. Este arquivo deve conter uma descrição do projeto. Coloque algum esforço no README e certifique-se de que ele detalhe claramente o que o projeto é sobre e como qualquer pessoa pode executá-lo localmente.
*   Adicione capturas de tela do seu projeto ao arquivo README para que qualquer pessoa possa ver como o projeto parece sem ter que executá-lo localmente.
*   Adicione um arquivo `LICENSE` a cada repositório que você criar. Este arquivo deve conter a licença que deseja usar para o projeto. Você pode usar [choosealicense.com](https://choosealicense.com/) para ajudar a escolher uma licença.

Você pode ver um exemplo de meu perfil do GitHub em [meu perfil do GitHub](https://github.com/nilbuild) e como eu estruturei meus repositórios, bem como como [alguns dos meus arquivos README parecem](https://github.com/nilbuild/aws-cost-cli).
