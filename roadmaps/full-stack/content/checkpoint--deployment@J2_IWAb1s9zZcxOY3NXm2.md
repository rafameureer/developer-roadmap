# Deploy

Agora que você sabe os fundamentos do AWS, você deve ser capaz de implantar sua aplicação no AWS. Você não precisa usar todos os serviços do AWS, aqui está o que você pode provavelmente começar:

*   Configurar uma instância EC2 usando qualquer AMI (por exemplo, a versão mais recente do Ubuntu)
*   SSH na instância EC2 usando a chave de par que criou
*   Instalar Node.js na instância EC2
*   Instalar Git na instância EC2
*   Clonar sua aplicação no GitHub
*   Instalar e configurar banco de dados na instância EC2 (por exemplo, PostgreSQL)
*   Certifique-se de que o grupo de segurança da instância EC2 permita tráfego HTTP e HTTPS
*   Tente acessar sua aplicação usando o endereço IP público da instância EC2
*   Compre ou configure um nome de domínio usando Route53 (ou qualquer outro provedor de nomes de domínio) e aponte-o para o endereço IP público da instância EC2
*   Configurar HTTPS usando [certbot](https://roadmap.sh/guides/setup-and-auto-renew-ssl-certificates)
*   E voilá! Você implantou sua aplicação no AWS!
