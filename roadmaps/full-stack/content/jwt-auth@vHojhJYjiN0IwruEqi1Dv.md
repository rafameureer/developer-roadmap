# JWT

JWT significa Token-based Encryption e é um padrão/método aberto de transferência de informações de forma segura como um objeto JSON. Os clientes e servidores usam JWT para compartilhar informações de forma segura, com o JWT contendo objetos JSON codificados e declarações. JWTs são projetados para serem compactos, seguros de usar em URLs e ideais para contextos de SSO.
