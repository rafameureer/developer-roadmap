# S3

S3 é um serviço que permite armazenar arquivos na nuvem. É um serviço simples que você pode usar para armazenar arquivos e servi-los aos seus usuários.

Acesse os seguintes recursos para saber mais:

- [@official@Amazon AWS S3](https://aws.amazon.com/s3/)
- [@video@Carregando Imagens no S3 a partir do Back End Node](https://www.youtube.com/watch?v=NZElg91l_ms)
- [@video@Hosteio de um Site Estático em um Bucket S3](https://www.youtube.com/watch?v=RoY3ekCCxKc&list=PL0X6fGhFFNTcU-_MCPe9dkH6sqmgfhy_M)
