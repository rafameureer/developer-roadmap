# Tracing Direcional com DirectX

Tracing Direcional com DirectX (DXR) é uma API avançada do Windows introduzida com DirectX 12. Ele entrega renderização em tempo real de qualidade cinematográfica para competir no desenvolvimento de jogos e visualizações profissionais. Ele fornece acesso altamente eficiente e direto à hardware RT Core. DXR adiciona quatro novas conceitos ao DirectX 12: A estrutura de aceleração, O objeto de estado da pipeline de tracção, Tabelas de shader e o método de lista de comandos (DispatchRays). Ele representa um passo significativo em frente pelo Microsoft adotando Tracing como um novo padrão nas pipelines de renderização em tempo real. Para os desenvolvedores, o Tracing Direcional do DirectX é fácil de integrar em motores existentes, dado seu fácil compatibilidade com os modelos de programação DirectX 12 existentes. No entanto, para realmente maximizar o potencial do DXR, uma compreensão profunda tanto dos cargos gráficos quanto dos algoritmos de tracção é necessária.
