# OpenGL ES

OpenGL ES (Open Graphics Library for Embedded Systems) é uma versão simplificada do OpenGL, projetado para uso em sistemas com menor poder computacional, como dispositivos móveis e sistemas embarcados. Apesar de suas simplificações semânticas, OpenGL ES ainda mantém alta versatilidade e capacidade, permitindo gráficos 2D e 3D de alto desempenho nessas menores, menos potentes, plataformas. O OpenGL ES se tornou particularmente popular no desenvolvimento de jogos móveis, com grandes plataformas como Android e iOS fornecendo suporte completo a ele. A API é dividida em várias versões, a mais recente das quais, OpenGL ES 3.2, foi lançada em 2016.
