# OpenGL

O OpenGL, também conhecido como Open Graphics Library, é uma API multi-plataforma e de linguagem cruzada projetada para renderizar gráficos 2D e 3D vetoriais. Como uma interface de software para hardware gráfico, o OpenGL fornece aos programadores a capacidade de criar visuais gráficos complexos em detalhes. Foi inicialmente desenvolvido pela Silicon Graphics Inc. em 1992 e rapidamente se tornou um ferramento altamente popular na indústria de renderização gráfica. O OpenGL é amplamente utilizado em CAD, realidade virtual, visualização científica, visualização de informações e simulações aéreas. Também é usado no desenvolvimento de jogos de vídeo onde o renderizado em tempo real é uma exigência. A API foi projetada para funcionar com um amplo range de hardware de diferentes fabricantes. Como open-source, as capacidades do código do OpenGL podem ser estendidas por qualquer membro da comunidade de software.
