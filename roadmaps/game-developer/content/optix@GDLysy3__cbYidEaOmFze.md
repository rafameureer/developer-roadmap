# OptiX

`OptiX` é um framework de aplicativo desenvolvido pela NVIDIA para obter alta performance em traçado por raios em programação de unidade de processamento gráfico (GPU). Ele está principalmente projetado para uso em aplicações de gráficos em tempo real, simulações científicas e outras aplicações de computação visual. `OptiX` fornece funcionalidades-chave como aceleração hierárquica de objetos, geração de raios programável, esombreamento de materiais e gerenciamento dinâmico de cena para obter renderização rápida e de ponta. Esta API altamente eficiente, escalonável e flexível suporta a codificação de aplicativos não apenas para renderização gráfica, mas também para detecção de colisão e simulação física. Por favor, note que o acesso ao `OptiX` atualmente requer produtos NVIDIA GeForce, Quadro e Tesla com GPUs da geração Kepler, Maxwell, Pascal, Volta, Turing e posteriores.
