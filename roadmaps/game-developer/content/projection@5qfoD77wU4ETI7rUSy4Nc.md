# Projeção

`Projeção` na matemática de jogos geralmente se refere ao método pelo qual imagens tridimensionais são transferidas para um plano bidimensional, típicamente uma tela de computador. Existem dois tipos principais de projeção no desenvolvimento de jogos; `Projeção Ortográfica` e `Projeção Perspectiva`. Na Projeção Ortográfica, os objetos mantêm seu tamanho independentemente da distância deles da câmera. Isso é frequentemente usado em jogos 2D ou jogos 3D onde a perspectiva não é importante. Por outro lado, a Projeção Perspectiva simula a perspectiva do olho humano, onde objetos distantes aparecem menores. Esse método fornece uma renderização mais realista para jogos 3D. É crucial entender projeção no desenvolvimento de jogos porque ela governa como espaços virtuais tridimensionais e objetos são exibidos em plataformas de visualização bidimensional.
