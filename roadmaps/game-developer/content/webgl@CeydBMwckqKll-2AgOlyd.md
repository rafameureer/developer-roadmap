# WebGL

`WebGL` (Web Graphics Library) é uma API em JavaScript usada para renderizar gráficos interativos 2D e 3D dentro de qualquer navegador compatível sem a necessidade de plugins. Ela aproveita o poder da Unidade de Processamento Gráfico (GPU), que fornece renderização de alta eficiência. Os programas WebGL consistem em código de controle escrito em JavaScript e código de shader escrito em OpenGL Shading Language (GLSL), permitindo aos desenvolvedores controlar os detalhes finos da renderização gráfica. Além de sua compatibilidade com HTML5 e sua capacidade de renderizar em qualquer plataforma que suporte a web, WebGL é totalmente integrado em todos os padrões web, facilitando o processamento e efeitos acelerados por GPU.
