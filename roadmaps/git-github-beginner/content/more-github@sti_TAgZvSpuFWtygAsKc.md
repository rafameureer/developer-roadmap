# Recursos Avançados do GitHub

O GitHub vai muito além do simples armazenamento de código na nuvem: é uma plataforma colaborativa completa. Ele oferece ferramentas integradas para gerenciamento de projetos e acompanhamento de tarefas (como *Issues* e *Projects* para relatar bugs e planejar novas funcionalidades). Além disso, recursos como *Pull Requests* viabilizam discussões estruturadas, revisões detalhadas de código (*code review*) e automações completas via *GitHub Actions*.

Visite os seguintes recursos para aprender mais:

- [@roadmap@Acesse o Roadmap Dedicado de Git & GitHub](https://roadmap.sh/git-github)
- [@official@Documentação sobre Gestão de Projetos no GitHub](https://docs.github.com/pt/issues)
- [@official@Guia de Colaboração com Pull Requests](https://docs.github.com/pt/pull-requests)
