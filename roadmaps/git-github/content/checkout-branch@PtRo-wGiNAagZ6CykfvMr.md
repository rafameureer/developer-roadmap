# Checkout Branch

No Git, "checkout" de uma branch significa alternar seu diretório de trabalho para essa branch, tornando-a a branch ativa. Isso atualiza seus arquivos para corresponder ao estado dessa branch e permite que você trabalhe nela.

Acesse os seguintes recursos para saber mais:

- [@official@git-checkout](https://git-scm.com/docs/git-checkout)
- [@article@git-commands-checkout](https://www.git-tower.com/learn/git/commands/git-checkout)
