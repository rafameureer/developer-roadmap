# Colaboração no GitHub

A colaboração no GitHub é uma maneira poderosa para que várias pessoas trabalhem juntas em um mesmo projeto, usando Git como o sistema de controle de versão. O GitHub fornece várias ferramentas e fluxos de trabalho que tornam a colaboração eficiente e organizada.

Acesse os seguintes recursos para saber mais:

- [@oficial@Como colaborar em um projeto do GitHub](https://gist.github.com/neklaf/9002d3acccf6b6e448db5c4c4e8764c0)
- [@artigo@Melhores práticas para colaborar no GitHub](https://www.gitkraken.com/blog/collaborate-on-github)
- [@artigo@Trabalhando com o GitHub no VS Code](https://code.visualstudio.com/docs/sourcecontrol/github)
