# Colaboradores / Membros

No GitHub, colaboradores e membros se referem a indivíduos que contribuem para ou têm acesso ao seu repositório. Os colaboradores são usuários que foram concedidos permissão para contribuir com código, fazer alterações e empurrar atualizações para o seu repositório, enquanto os membros são proprietários de um repositório, incluindo proprietários de organizações que têm controle completo sobre os repositórios da equipe. Os membros podem ser colaboradores individuais ou parte de uma equipe de organização, com diferentes níveis de acesso e permissões baseados em seu papel na equipe.
