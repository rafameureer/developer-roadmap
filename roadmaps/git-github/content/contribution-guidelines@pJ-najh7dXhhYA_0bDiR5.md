# Diretrizes de Contribuição

As diretrizes de contribuição são essenciais para projetos colaborativos no GitHub, pois ajudam a facilitar a colaboração, estabelecer expectativas para as contribuições e manter a qualidade e consistência do projeto.

Acesse os seguintes recursos para saber mais:

- [@oficial@Definindo Diretrizes para Contribuidores de Repositórios](https://docs.github.com/articles/setting-guidelines-for-repository-contributors)
- [@oficial@Diretrizes de Contribuição](https://github.blog/news-insights/contributing-guidelines/)
- [@oficial@Modelos de Diretrizes de Contribuição](https://github.com/nayafia/contributing-template)
- [@artigo@Como Construir um CONTRIBUTING.md](https://mozillascience.github.io/working-open-workshop/contributing/)
