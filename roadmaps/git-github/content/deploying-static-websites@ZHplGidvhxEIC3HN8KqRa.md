# Deploy de Sites Estáticos

Deployar sites estáticos no GitHub Pages envolve carregar e servir conteúdo do site que foi gerado anteriormente, sem funcionalidade dinâmica. Este método permite um deploy rápido, manutenção baixa e melhor segurança.
