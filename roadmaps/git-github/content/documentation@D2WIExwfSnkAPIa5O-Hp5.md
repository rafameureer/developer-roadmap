# Documentação

A documentação abrange os materiais escritos que explicam como um projeto funciona, como usá-lo e como contribuir para ele. Isso inclui arquivos README, wikis e arquivos de citação, todos os quais ajudam usuários e contribuidores a entenderem um repositório sem precisar ler todo o código-fonte. Boa documentação é frequentemente o que determina se um projeto de código aberto será adotado ou contribuído.
