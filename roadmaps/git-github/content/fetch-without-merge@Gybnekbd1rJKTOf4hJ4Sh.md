# Fetch sem Merge

O `git fetch` baixa novos commits, branches e tags de um repositório remoto sem mesclá-los na branch local. Ele atualiza as branches de rastreamento remoto, como `origin/main`, permitindo que o desenvolvedor inspecione as mudanças entrantes antes de decidir se mesclar ou rebase-las. Isso torna o `fetch` uma maneira mais segura de verificar atualizações em comparação com o `git pull`, que baixa e mescla tudo em um passo.
