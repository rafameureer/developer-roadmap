# Git Attributes

Os atributos do Git são configurações armazenadas no arquivo .gitattributes, que controlam como o Git lida com os arquivos em seu repositório. Eles podem influenciar a filtragem (por exemplo, ignorar arquivos específicos), a conversão (formatando ou transformando arquivos durante operações do Git) e formatação (aplicando estilos consistentes). Essas configurações podem ser aplicadas a tipos de arquivo específicos (como \*.txt) ou filtrar arquivos com base em padrões de conteúdo. Os atributos também definem padrões de sujo (realçando diferenças) e ignorar padrões, ajudando a manter um repositório limpo ao aplicar automaticamente configurações intencionais para certos tipos de arquivo.
