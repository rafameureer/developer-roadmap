# git commit --amend

O comando `git commit --amend` é usado para modificar o último commit na história do seu repositório, atualizando sua mensagem, adicionando ou removendo arquivos, ou alterando os metadados do commit. Isso permite que você corrija erros ou melhore a descrição do commit após ele ter sido feito. Ao usar --amend, o Git substituirá o commit existente por um novo que inclua quaisquer mudanças feitas desde o último commit, efetivamente "corrigindo" o commit anterior.
