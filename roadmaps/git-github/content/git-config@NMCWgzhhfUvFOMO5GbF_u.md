# git config
 
`git config` define valores de configuração que controlam como o Git se comporta, como o nome do usuário, o e-mail e o editor padrão. Essas configurações podem aplicar em diferentes níveis: globalmente para todo o sistema, por usuário ou por repositório. O Git anexa essa informação a cada commit, por isso definir um nome e e-mail é uma das primeiras etapas após instalar o Git.
