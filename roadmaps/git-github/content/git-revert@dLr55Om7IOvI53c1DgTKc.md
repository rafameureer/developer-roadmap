# git revert

O `git revert` cria um novo commit que desfaz as alterações feitas por um commit anterior, sem alterar o histórico existente. Isso torna-se uma maneira segura de desfazer alterações em uma branch que outros já puxaram, pois não reescreve nenhum commit. Executar `git revert <hash-do-commit>` aplica a inversão das alterações desse commit e solicita uma nova mensagem de commit.
