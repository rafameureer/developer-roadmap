# Git vs Outros Sistemas de Controle de Versão

O Git é um sistema de controle de versão distribuído, o que significa que cada desenvolvedor tem uma cópia completa da história do projeto em seu próprio computador, não apenas a última captura. Sistemas mais antigos como Subversion (SVN) ou CVS são centralizados, então dependem de um único servidor para a maioria das operações e exigem uma conexão de rede para confirmar alterações. O Git permite que commits, ramificações e navegação pela história aconteçam offline, e sincronização com um servidor remoto ocorre apenas quando empurrar ou buscar.
