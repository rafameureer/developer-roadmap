# GitHub CLI
 
GitHub CLI, ou `gh`, é uma ferramenta de linha de comando que permite aos desenvolvedores interagir diretamente com o GitHub a partir do terminal em vez da interface web. Ele suporta tarefas comuns como criar repositórios, gerenciar problemas e abrir solicitações de pull sem precisar alternar de contexto. Ser scriptável também o torna útil para automatizar tarefas relacionadas ao GitHub em scripts ou pipelines CI.
