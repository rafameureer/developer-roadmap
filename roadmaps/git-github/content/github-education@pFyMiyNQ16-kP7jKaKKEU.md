# GitHub Education

O GitHub Education é um programa que oferece acesso gratuito e descontado aos recursos, serviços e ferramentas do GitHub para estudantes, professores e pesquisadores. Este programa visa apoiar a educação e a pesquisa em desenvolvimento de software, tornando mais fácil para os alunos e educadores aprenderem, colaborarem e construir projetos no GitHub. Ao usar o GitHub Education, os alunos podem obter experiência prática com desafios de codificação do mundo real, enquanto professores podem criar um ambiente de aprendizado mais envolvente e interativo.
