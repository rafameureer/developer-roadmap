# GitHub Models

GitHub Models é uma funcionalidade que permite aos desenvolvedores pesquisar, explorar e usar modelos de IA pré-treinados de várias fontes. Esta plataforma fornece uma maneira de descobrir e experimentar esses modelos, tornando mais fácil integrar capacidades de IA em projetos de software. Ao usar GitHub Models, os desenvolvedores podem encontrar rapidamente e testar diferentes modelos, sem ter que treiná-los do zero.

Acesse os seguintes recursos para saber mais:

- [@oficial@Prototipagem com modelos de IA](https://docs.github.com/en/github-models/prototyping-with-ai-models)
- [@vídeo@Demonstração GitHub Models | Modelos de IA para desenvolvedores no GitHub](https://www.youtube.com/watch?v=WiBB8Lsgl7I)
