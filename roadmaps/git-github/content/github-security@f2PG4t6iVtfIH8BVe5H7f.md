# Segurança do GitHub

A segurança do GitHub cobre as ferramentas integradas que ajudam a identificar e corrigir vulnerabilidades em um repositório, como escaneio de dependências, escaneio de segredos e escaneio de código. Essas funcionalidades podem sinalizar dependências desatualizadas com vulnerabilidades conhecidas ou detectar segredos acidentalmente commitados, como chaves de API. Funcionalidades de segurança podem ser ativadas nas configurações do repositório e muitas vezes integram diretamente com solicitações de pull para sinalizar problemas antes de serem mesclados.
