# Apoiadores do GitHub

O Apoio ao GitHub permite que desenvolvedores e organizações recebam suporte financeiro diretamente dos usuários que querem financiar seu trabalho de código aberto. Os apoiadores podem escolher uma contribuição única ou mensal recorrente, e os mantenedores podem oferecer diferentes níveis de apoio com benefícios específicos. Isso dá aos mantenedores do código aberto uma maneira de ganhar renda por seu trabalho diretamente através da plataforma.

Acesse os seguintes recursos para saber mais:

- [@oficial@Apoiando um contribuidor de código aberto no GitHub](https://docs.github.com/pt-br/sponsors/sponsoring-open-source-contributors/sponsoring-an-open-source-contributor-through-github)
