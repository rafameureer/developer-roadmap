# Gerenciamento de Problemas
 
O GitHub CLI permite criar, listar e fechar problemas diretamente no terminal usando comandos como `gh issue create` e `gh issue list`. Filtros podem restringir os resultados por rótulo, responsável ou estado, semelhante à busca de problemas na web. Isso torna possível triagem ou gerenciamento de problemas sem a necessidade de alternar para um navegador.

Acesse os seguintes recursos para saber mais:

- [@oficial@gh issue](https://cli.github.com/manual/gh_issue)
- [@vídeo@Gerencie Problemas do GitHub a partir da Linha de Comando usando o GitHub CLI](https://www.youtube.com/watch?v=nuCQiP41jU0)
