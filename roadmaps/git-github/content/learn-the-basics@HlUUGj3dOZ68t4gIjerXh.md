# Aprenda os Básicos

Sistema de Controle de Versão (SCV) é uma ferramenta que ajuda os desenvolvedores a gerenciar as alterações em seu código ao longo do tempo. Ele permite que várias versões de um projeto existam simultaneamente, tornando mais fácil colaborar com outros e manter um registro de todas as modificações.

Acesse os seguintes recursos para saber mais:

- [@oficial@Começando - Instalando Git](https://git-scm.com/book/en/v2/Getting-Started-Installing-Git)
- [@oficial@Criando uma conta no GitHub](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github)
- [@artigo@O que é controle de versão?](https://www.atlassian.com/git/tutorials/what-is-version-control)
