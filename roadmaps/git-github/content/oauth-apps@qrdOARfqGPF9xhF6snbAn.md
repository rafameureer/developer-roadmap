# Aplicativos OAuth

Os aplicativos OAuth no GitHub permitem que os desenvolvedores integrem-se ao GitHub usando a autenticação OAuth 2.0. Eles habilitam o acesso seguro, baseado em tokens, a recursos específicos do GitHub como repositórios, problemas e solicitações de pull. Os aplicativos OAuth podem automatizar tarefas, personalizar interações e fornecer notificações em tempo real através de webhooks, tudo enquanto permitem aos usuários aprovar apenas as permissões necessárias sem compartilhar suas credenciais.
