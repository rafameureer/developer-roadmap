# Perfil README
 
O perfil README é um repositório especial cujo nome é baseado no nome de usuário do GitHub e exibe conteúdo personalizado diretamente na página de perfil do usuário. Ele usa o Markdown padrão, então os desenvolvedores podem adicionar texto, imagens, badges e links para mostrar habilidades, projetos ou informações de contato. O GitHub detecta automaticamente esse repositório e renderiza seu README na página de perfil em vez de exigir uma página separada.
