# Reações

Reações no GitHub são uma maneira de usuários expressar suas opiniões ou sentimentos sobre problemas, solicitações de pull, comentários e outras discussões sem adicionar comentários adicionais. Elas são similares a "likes" ou "emojis" em plataformas de mídia social, fornecendo uma forma rápida e não verbal de interagir com o conteúdo.

Acesse os seguintes recursos para saber mais:

- [@oficial@Adicionando Reações a Solicitações de Pull, Problemas e Comentários](https://github.blog/news-insights/product-news/add-reactions-to-pull-requests-issues-and-comments/)
