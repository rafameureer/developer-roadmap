# Armazenamento de Artefatos

Artefatos são arquivos produzidos durante a execução de um fluxo de trabalho, como saídas de build ou relatórios de teste, que podem ser salvos e baixados após a conclusão do fluxo de trabalho. A ação `actions/upload-artifact` armazena esses arquivos, enquanto a ação `actions/download-artifact` os recupera em um trabalho posterior ou para inspeção manual. Artefatos são comumente usados para passar saídas de build entre trabalhos ou para manter logs e relatórios para revisão.

Acesse os seguintes recursos para saber mais:

- [@oficial@Armazenando e compartilhando dados de um fluxo de trabalho](https://docs.github.com/pt-br/actions/configurando-fluxos-de-trabalho/escolhendo-o-que-fazer-com-seu-fluxo-de-trabalho/armazenando-e-compartilhando-dados-de-um-fluxo-de-trabalho)
