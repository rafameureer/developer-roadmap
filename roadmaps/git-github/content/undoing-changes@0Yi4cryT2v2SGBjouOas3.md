# Desfazendo Mudanças

Desfazer mudanças em Git cobre as diferentes maneiras de reverter modificações, independentemente de elas serem não confirmadas, preparadas ou já confirmadas. Dependendo da situação, os desenvolvedores podem usar `git checkout` para descartar edições locais, `git reset` para desfazer ou remover commits, ou `git revert` para desfazer um commit que já foi compartilhado de forma segura. A escolha do método certo depende se a mudança já foi empurrada para um repositório remoto compartilhado.
