# Mudanças Não Preparadas

Para mudanças que ainda não foram preparadas com `git add`, como novos arquivos não rastreados ou arquivos existentes modificados, use `git diff`. Este comando compara o diretório de trabalho (suas alterações atuais) com a área de staging (alterações já preparadas com `git add`). É uma ferramenta útil para revisar as modificações locais antes de decidir se elas devem ser preparadas para futuros commits.
