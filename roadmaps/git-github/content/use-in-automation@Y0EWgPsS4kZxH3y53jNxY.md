# Uso na Automatização

O GitHub CLI pode ser usado dentro de scripts ou pipelines CI/CD para automatizar tarefas como a criação de releases, comentar em issues ou disparar workflows. Como ele suporta autenticação por meio de tokens, ele pode executar em ambientes não interativos sem login manual. Isso o torna uma ferramenta comum para construir automações personalizadas ao redor da plataforma do GitHub sem depender diretamente da API REST.

Acesse os seguintes recursos para saber mais:

- [@official@Documentação do GitHub CLI](https://cli.github.com/manual/)
- [@article@Automatizando seu fluxo de trabalho com o GitHub CLI](https://github.blog/2021-03-11-scripting-with-github-cli/)
