# Webhooks

Os Webhooks do GitHub permitem aos desenvolvedores receber notificações em tempo real sobre eventos ocorrendo dentro de seu repositório, como commits, solicitações de pull e problemas. Esses webhooks permitem que os usuários automatizem tarefas, integrem-se com outros serviços e construam fluxos de trabalho personalizados.

Acesse os seguintes recursos para saber mais:

- [@official@Sobre Webhooks](https://docs.github.com/en/webhooks/about-webhooks)
- [@official@Webhooks documentation](https://docs.github.com/en/webhooks)
