# O que e Por que Usar?

Os submódulos permitem a um projeto fazer referência a outro repositório Git em um commit específico, em vez de copiar seu código diretamente para o projeto principal. Isso é útil quando vários projetos dependem da mesma biblioteca compartilhada e precisam rastrear atualizações a ela independentemente. Usar um submódulo mantém o histórico da dependência separado enquanto ainda vincula-a a um ponto fixo no projeto pai.
