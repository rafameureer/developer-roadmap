# O que é Controle de Versão?
 
O controle de versão é um sistema que rastreia as alterações em arquivos ao longo do tempo, permitindo aos desenvolvedores ver quem alterou o quê e reverter para versões anteriores quando necessário. Ele mantém um histórico de todas as modificações, permitindo que várias pessoas trabalhem no mesmo projeto sem sobrescrever o trabalho umas das outras. Equipes usam ele para colaborar com segurança, experimentar novos recursos isoladamente e recuperar de erros.
