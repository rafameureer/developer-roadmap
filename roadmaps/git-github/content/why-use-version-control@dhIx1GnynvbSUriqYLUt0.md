# Por que usar controle de versão?

O controle de versão permite aos desenvolvedores rastrear todas as alterações feitas em um código-fonte e reverter para um estado anterior se algo falhar. Ele remove a necessidade de backups manuais como pastas renomeadas ou cópias zipadas de um projeto. Várias pessoas podem trabalhar nos mesmos arquivos simultaneamente sem perder as alterações uns dos outros, e cada alteração é documentada com uma mensagem explicando por que foi feita.
