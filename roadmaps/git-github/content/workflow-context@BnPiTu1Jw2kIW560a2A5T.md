# Contexto do Fluxo de Trabalho

O contexto do fluxo de trabalho no GitHub Actions refere-se ao ambiente e variáveis disponíveis para um fluxo de trabalho. Ele inclui informações sobre a execução do fluxo de trabalho, como o evento que o disparou, o repositório e o próprio fluxo de trabalho.

Acesse os seguintes recursos para saber mais:

- [@oficial@Contextos no GitHub Actions](https://docs.github.com/en/actions/concepts/workflows-and-actions/contexts)
- [@oficial@Exemplo de Contextos no GitHub Actions](https://docs.github.com/en/actions/writing-workflows/choosing-what-your-workflow-does/contexts)
- [@vídeo@Trabalhando com contextos no GitHub Actions](https://www.youtube.com/watch?v=16WT_r0zjYE)
