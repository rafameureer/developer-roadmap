# Status do Workflow

O status do workflow indica se uma execução de ações do GitHub foi bem-sucedida, falhou ou ainda está em progresso, sendo exibido diretamente nos commits, solicitações de pull e na guia Ações. Verificações de status podem ser configuradas conforme necessário, bloqueando uma solicitação de pull da fusão até que o workflow passe. Isso dá visibilidade imediata sobre se as alterações quebraram qualquer verificação automatizada antes de serem mescladas.
