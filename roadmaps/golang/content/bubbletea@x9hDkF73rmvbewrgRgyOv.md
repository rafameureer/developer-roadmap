# bubbletea

Bubble Tea é um framework para construir interfaces de usuário do terminal baseadas na Arquitetura Elm. Usa o padrão modelo-atualização-exibição para aplicativos CLI interativos com entrada de teclado, estilo e composição de componentes. Excelente para ferramentas e painéis terminais sofisticados.

Acesse os seguintes recursos para saber mais:

- [@opensource@charmbracelet/bubbletea](https://github.com/charmbracelet/bubbletea)
