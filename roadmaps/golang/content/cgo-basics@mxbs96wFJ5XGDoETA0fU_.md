# Básicos do CGO

CGO permite que programas Go chamem código C e vice-versa usando comentários especiais. Habilita a integração com bibliotecas C, mas desativa a compilação cruzada, reduz o desempenho e complexifica a implantação. Útil para integrações legadas, mas o Go puro é preferido.

Acesse os seguintes recursos para saber mais:

- [@oficial@CGO](https://go.dev/wiki/cgo)
- [@artigo@Entenda Como Usar Bibliotecas C no Go com CGO](https://dev.to/metal3d/understand-how-to-use-c-libraries-in-go-with-cgo-3dbn)
- [@artigo@Chamando Funções C do Go: Um Guia Rápido](https://www.codingexplorations.com/blog/calling-c-functions-from-go-a-quick-guide)
