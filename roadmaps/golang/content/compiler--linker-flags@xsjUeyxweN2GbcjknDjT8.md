# Flags do Compilador e Linker

As flags de build controlam a compilação e o link. As flags comuns incluem `-ldflags` para opções do linker, `-gcflags` para configurações do compilador, `-tags` para tags de build e `-race` para detecção de corrida. Ajuda otimizar builds, reduzir o tamanho da binária e incorporar informações de build.
