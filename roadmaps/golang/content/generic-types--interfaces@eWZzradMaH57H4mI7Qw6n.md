# Tipos Genéricos / Interfaces

Crie estruturas de dados e definições de interface reutilizáveis que funcionam com múltiplos tipos. Defina com parâmetros de tipo como `type Contêiner[T any] struct { valor T }`. Permita contêineres tipados, fatias genéricas, mapas e estruturas personalizadas enquanto mantém o forte tipagem do Go.

Acesse os seguintes recursos para saber mais:

- [@official@Funções Genéricas](https://go.dev/doc/tutorial/generics)
- [@article@Interfaces](https://golangdocs.com/interfaces-in-golang)
- [@article@Entendendo a Potência das Interfaces do Go](https://medium.com/@jamal.kaksouri/understanding-the-power-of-go-interfaces-a-comprehensive-guide-835954101b7e)
