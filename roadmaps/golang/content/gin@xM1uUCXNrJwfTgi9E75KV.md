# gin

Framework web HTTP popular que enfatiza o desempenho e a produtividade. Fundação leve para APIs/web services com minimal boilerplate. Roteamento rápido, middleware, validação de JSON, gerenciamento de erros, renderização integrada. API limpa para serviços RESTful. Inclui vinculação de parâmetros, uploads e arquivos estáticos.
