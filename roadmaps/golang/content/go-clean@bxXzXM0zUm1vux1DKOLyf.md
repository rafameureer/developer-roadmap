# go clean

Remove arquivos de objetos e arquivos em cache do processo de construção. Opções incluem `-cache` para o cache de construção e `-modcache` para downloads de módulos. Útil para resolver problemas de construção, liberar espaço em disco e garantir construções limpas.

- [@official@Limpeza](https://golang.google.cn/cmd/go/internal/clean/)
