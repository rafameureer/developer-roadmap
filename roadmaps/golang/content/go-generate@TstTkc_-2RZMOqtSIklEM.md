# go generate

O comando `go generate` executa comandos especificados em diretivas `//go:generate` para gerar código-fonte Go. Usado para geração de código a partir de modelos, métodos de string, recursos incorporados e ferramentas como compiladores de protobuf para automação de build.

Acesse os seguintes recursos para saber mais:

- [@oficial@go generate](https://go.dev/blog/generate)
- [@artigo@Como usar //go:generate](https://blog.carlana.net/post/2016-11-27-how-to-use-go-generate/)
- [@artigo@Metaprogramação com Go](https://dev.to/hlubek/metaprogramming-with-go-or-how-to-build-code-generators-that-parse-go-code-2k3j)
