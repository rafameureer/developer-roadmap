# gRPC & Protocol Buffers

O gRPC é um framework de RPC de alto desempenho que usa Protocol Buffers para serialização. Oferece streaming, autenticação, balanceamento de carga e geração de código a partir dos arquivos `.proto`. Excelente para microservices com segurança de tipo, formato binário eficiente e compatibilidade entre idiomas.

Acesse os seguintes recursos para saber mais:

- [@official@gRPC package](https://pkg.go.dev/google.golang.org/grpc)
