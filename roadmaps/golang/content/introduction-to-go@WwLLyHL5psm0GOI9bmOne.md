# Introdução ao Go

Linguagem de programação estáticamente tipada e compilada desenvolvida pela Google. Projeta-se para simplicidade, concorrência e desempenho. Características incluem coleta de lixo, tipagem forte, compilação eficiente, concorrência interna com goroutines e canais. Excelente para serviços backend, ferramentas CLI e sistemas distribuídos.

Acesse os seguintes recursos para saber mais:

- [@oficial@Go](https://go.dev/)
- [@oficial@Documentação do Go](https://go.dev/doc/)
- [@oficial@Começando com o Go](https://go.dev/doc/tutorial/getting-started)
- [@artigo@Começando com o Go e a Web](https://dev.to/markmunyaka/getting-started-with-go-and-the-web-hello-world-nal)
