# I/O & Manipulação de Arquivos

O sistema de entrada/saída do Go fornece um tratamento abrangente de arquivos e streams através das interfaces `io` (Reader, Writer, Closer) e operações de arquivo do pacote `os`. O design baseado em interface permite trabalhar com arquivos, conexões de rede e buffers usando padrões consistentes.

Acesse os seguintes recursos para saber mais:

- [@artigo@Construindo pipelines de processamento de arquivos de alta performance no Go](https://dev.to/aaravjoshi/building-high-performance-file-processing-pipelines-in-go-a-complete-guide-3opm)
- [@artigo@Dominando a I/O em Go: Um guia completo](https://thelinuxcode.com/golang-os-open/)
- [@artigo@Fundamentos do Go: Manipulação de arquivos e I/O](https://medium.com/@nagarjun_nagesh/golang-fundamentals-file-handling-and-i-o-502d50b96795)
