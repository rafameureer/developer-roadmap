# make()

Cria e inicializa slices, maps e canais. Diferentemente de `new()`, retorna valores utilizáveis. Exemplos: `make([]int, 5, 10)` para slices, `make(map[string]int)` para maps, `make(chan int)` para canais. Essencial para inicializar tipos de referência.
