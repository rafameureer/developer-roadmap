# Maps

Tipo de dados associativo embutido que mapeia chaves para valores. Tipos de referência criados com `make(map[KeyType]ValueType)` ou literais de mapas. As chaves devem ser tipos comparáveis. Suporta operações de inserção, deleção e pesquisa. Verifique a existência com o idiom vírgula ok: `value, ok := map[key]`.
