# net/http Standard

Pacote de biblioteca padrão para funcionalidades de cliente/servidor HTTP. Fornece um servidor HTTP com roteamento, suporte a middleware, cliente para fazer solicitações. Manipula TLS, HTTP/2, cookies e formulários multipartes. Fundamenta o desenvolvimento web sem frameworks externos.
