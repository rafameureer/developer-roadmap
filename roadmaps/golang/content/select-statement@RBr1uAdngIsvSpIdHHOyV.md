# Seleção de Canais

Multiplexador para operações de canal. Aguarda várias operações de canal simultaneamente, executando a primeira que estiver pronta. Suporta operações de envio/recebimento e o caso padrão para comportamento não bloqueante. Essencial para coordenar múltiplas goroutines e implementar timeouts.
