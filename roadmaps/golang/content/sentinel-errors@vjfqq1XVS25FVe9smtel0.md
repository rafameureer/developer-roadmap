# Erros Sentinel

Valores de erro pré-definidos representando condições específicas, definidos como variáveis de nível de pacote. Verifique usando `errors.Is()` ou comparação direta. Exemplos: `io.EOF`. Habilita APIs previsíveis onde os chamadores lidam com erros específicos de maneira diferente.
