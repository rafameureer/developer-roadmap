# Configurando o Ambiente

Instale o Go no site oficial, configure a variável PATH e defina o espaço de trabalho. Configure um editor com suporte ao Go (VS Code, GoLand, Vim/Emacs). Use módulos para gerenciamento de dependências. Verifique a instalação com `go version` e teste com um programa simples.

Acesse os seguintes recursos para saber mais:

- [@official@Golang](https://go.dev/)
- [@official@Configurando o Ambiente](https://go.dev/doc/install)
- [@article@Como Configurar um Ambiente de Desenvolvimento em Go?](https://medium.com/codex/how-to-set-up-a-go-development-environment-67b4b002182e)
