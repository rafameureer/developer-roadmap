# Restrições de Tipo

Especifique quais tipos podem ser usados como argumentos de tipo para generics. Definidos usando interfaces com assinaturas de método ou conjuntos de tipos. As restrições comuns incluem `any`, `comparable` e restrições personalizadas. Habilita a escrita de código genérico que opera de forma segura nos parâmetros de tipo.
