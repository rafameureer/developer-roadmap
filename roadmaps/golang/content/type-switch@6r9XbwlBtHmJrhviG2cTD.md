# Switch de Tipo

Forma especial da declaração `switch` que opera em tipos em vez de valores. Sintaxe: `switch v := i.(type)`. Usado com interfaces para determinar o tipo concreto subjacente. Cada caso especifica os tipos a serem correspondidos. Essencial para lidar com `interface{}` e código polimórfico.
