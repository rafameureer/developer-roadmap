# Zero Values

Valores padrão para variáveis não inicializadas: `0` para números, `false` para booleanos, `""` para strings e `nil` para ponteiros/slices/maps. Garante um estado inicial previsível e reduz erros de inicialização. Fundamental para código Go confiável.
