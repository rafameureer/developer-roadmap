# Apollo Server

Apollo Server é uma biblioteca de código aberto popular para construir servidores GraphQL em JavaScript. Ele fornece ferramentas para parsing, validação, execução de resolvers e formatação de respostas com recursos integrados para autenticação, autorização, validação de dados e assinaturas em tempo real.
