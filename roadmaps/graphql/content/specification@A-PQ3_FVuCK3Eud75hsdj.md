# Especificação

A especificação do GraphQL é o padrão oficial que define a linguagem de consulta GraphQL, o sistema de tipos, o algoritmo de execução e as regras de validação. Ela garante consistência em diferentes implementações do GraphQL e serve como a referência autoritativa para os desenvolvedores construindo serviços e ferramentas GraphQL.

Acesse os seguintes recursos para saber mais:

- [@official@Especificação do GraphQL](https://spec.graphql.org/)
- [@official@Fundação do GraphQL](https://foundation.graphql.org/)
