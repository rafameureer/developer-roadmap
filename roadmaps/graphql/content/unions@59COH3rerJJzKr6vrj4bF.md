# Uniões

As uniões permitem que os campos retornem múltiplos tipos, permitindo diferentes tratamentos para vários tipos em clientes. Eles fornecem flexibilidade de esquema agrupando tipos juntos, embora não permitam a consulta comum de campos entre tipos como as interfaces fazem.

Acesse os seguintes recursos para saber mais:

- [@oficial@Comece com União no GraphQL](https://graphql.org/learn/schema/#union-types)
