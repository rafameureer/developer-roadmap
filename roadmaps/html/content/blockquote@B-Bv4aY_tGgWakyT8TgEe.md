# blockquote

O elemento `blockquote` em HTML representa uma seção de texto que é citada de outra fonte. Ele é usado para indicar que o conteúdo encerrado é uma citação estendida, geralmente exibida com indentação ou outras dicas visuais para distinguir-se do texto circundante. O atributo `cite` pode ser usado para especificar a URL do documento ou mensagem de origem.
