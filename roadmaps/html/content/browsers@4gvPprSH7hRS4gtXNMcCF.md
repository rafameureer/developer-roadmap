# Navegadores

Os navegadores da web solicitam e exibem sites interpretando HTML, CSS e JavaScript. Use motores de renderização (Blink, Gecko) para a exibição e motores de JavaScript (V8) para a execução de código. Gerenciam segurança, marcadores, histórico e interações do usuário para navegação na web.
