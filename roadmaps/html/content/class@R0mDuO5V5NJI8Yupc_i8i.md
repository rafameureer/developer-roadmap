# Atributo Class

O atributo `class` em HTML é usado para especificar um ou mais nomes de classe para um elemento HTML. Esses nomes de classe podem então ser usados por CSS e JavaScript para estilizar e manipular elementos específicos ou grupos de elementos que compartilham a mesma classe. Em essência, é uma maneira de categorizar e alvo elementos para fins de estilização e scripting.
