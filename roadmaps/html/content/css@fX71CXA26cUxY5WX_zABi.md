# CSS

CSS, ou Folhas de Estilo em Cascata (Cascading Style Sheets), é uma linguagem usada para descrever a aparência e formatação de um documento escrito em HTML. Ele controla aspectos como o layout, cores, fontes e a apresentação geral visual das páginas web, garantindo uma experiência de usuário consistente e atraente em diferentes dispositivos e tamanhos de tela.
