# DNS

DNS (Sistema de Nomes de Domínio) traduz nomes de domínio legíveis por humanos em endereços IP através de uma rede de servidores distribuídos globalmente. Habilita a navegação na internet fácil convertendo nomes como [www.example.com](http://www.example.com) para endereços numéricos que os navegadores podem conectar.
