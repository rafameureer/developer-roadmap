# Uploads de Arquivos

Os uploads de arquivos permitem que os usuários enviem arquivos do seu computador para um servidor web. Isso é geralmente alcançado através de um formulário HTML que inclui um elemento `<input>` com o atributo `type` definido como "file". Quando o formulário é enviado, o(s) arquivo(s) selecionados são enviados ao servidor para processamento e armazenamento.
