# Agrupamento de Texto

O `<div>` e o `<span>` são elementos HTML usados para agrupar outros elementos juntos. O elemento `<div>` é um elemento de nível de bloco, o que significa que ele cria um bloco distinto na página e geralmente começa em uma nova linha. Ele é frequentemente usado para agrupamentos estruturais maiores. Por outro lado, o elemento `<span>` é um elemento embutido, o que significa que ele flui dentro do texto circundante e não cria uma nova linha. É útil para estilizar ou manipular partes específicas do texto sem interromper o layout geral.
