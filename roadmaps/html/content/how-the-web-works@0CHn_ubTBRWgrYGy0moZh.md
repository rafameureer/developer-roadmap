# Como funciona a web

A internet é uma rede global que conecta computadores e dispositivos para o compartilhamento de informações. Permite navegar, enviar e receber e-mails, assistir a streaming e se comunicar através de sistemas interconectados. Atua como estrutura mundial facilitando o acesso a recursos e serviços online.
