# Imagens

As imagens são uma maneira de exibir conteúdo visual em uma página web. Elas são adicionadas a documentos HTML usando a tag `<img>`, que se refere a um arquivo de imagem. Atributos como `src` (fonte), `alt` (texto alternativo), `width` (largura) e `height` (altura) são usados para especificar a localização, descrição e dimensões da imagem.
