# Links

Links, também conhecidos como hiperlinks, são elementos que conectam um recurso web a outro. Eles permitem que os usuários naveguem entre diferentes páginas do mesmo site ou para sites externos. Links são criados usando a tag `<a>` (anchor), e eles podem apontar para vários tipos de recursos, incluindo páginas HTML, imagens, documentos e muito mais.
