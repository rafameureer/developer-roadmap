# Listas e Tipos

As listas em HTML são usadas para apresentar informações de uma maneira estruturada e organizada. Existem principalmente dois tipos principais: listas ordenadas (numeradas) e listas não ordenadas (com marcadores). O HTML também suporta listas de definição, que são usadas para exibir termos e suas respectivas definições. Cada tipo de lista usa tags específicas do HTML para definir a estrutura da lista e seus itens individuais.
