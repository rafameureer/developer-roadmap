# pre

A tag `<pre>` em HTML representa texto pré-formatado. O texto dentro de uma tag `<pre>` é exibido em uma fonte de largura fixa, e ele preserva ambos os espaços e quebras de linha. Isso é útil para exibir trechos de código, arte ASCII ou qualquer outro texto onde a formatação é importante.

Acesse os seguintes recursos para saber mais:

- [@artigo@Tag pre em HTML](https://developer.mozilla.org/pt-BR/docs/Web/HTML/Element/pre)
