# Elemento Span

O elemento `<span>` é um contêiner em linha usado para marcar uma parte de um texto ou uma parte de um documento. Ele é usado para agrupar elementos para fins de estilização ou porque eles compartilham atributos como `lang` ou `dir`. Não representa nada por si só, mas se torna útil quando combinado com CSS ou JavaScript para alvo seções específicas do texto.
