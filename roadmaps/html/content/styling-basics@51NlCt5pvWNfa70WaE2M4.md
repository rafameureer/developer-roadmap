# Básicos de Estilização

Básicos de Estilização em HTML envolvem usar CSS (Folhas de Estilo em Cascata) para controlar a apresentação visual dos elementos HTML. Isso inclui propriedades como cores, fontes, layout e responsividade, permitindo que você personalize o aspecto e o comportamento das suas páginas da web além dos estilos padrão do navegador. Ao aplicar regras de CSS, você pode criar sites visuais atraentes e fáceis de usar.

Acesse os seguintes recursos para saber mais:

- [@artigo@Começando com CSS](https://developer.mozilla.org/pt-BR/docs/Learn_web_development/Core/Styling_basics/Getting_started)
- [@artigo@HTML e CSS – Estilo em Linha, Folha de Estilo Externa, Exemplos de Código CSS](https://www.freecodecamp.org/news/html-and-css-inline-style-external-stylesheet-css-code-examples/)
