# Tag de Título

A tag `<title>` em HTML define o título do documento HTML. Esse título é exibido na barra de título ou aba do navegador, e também é usado para marcar páginas e nos resultados dos motores de busca. Ela é colocada dentro da seção `<head>` do documento HTML.
