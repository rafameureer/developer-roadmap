# Inspetor de Accessibilidade
 
O Inspectador de Accessibilidade é uma ferramenta no Xcode que auditoria elementos da interface do usuário por problemas de acessibilidade. Ele exibe as propriedades de acessibilidade de cada elemento, executa auditorias automatizadas para detectar rótulos ausentes e problemas de contraste baixo, e simula a navegação com VoiceOver. É a ferramenta principal para testar e melhorar a acessibilidade durante o desenvolvimento.
