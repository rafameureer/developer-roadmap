# Alamofire
 
Alamofire é uma biblioteca de rede em Swift construída sobre URLSession que simplifica tarefas comuns de rede. Ele fornece uma API limpa e encadeável para fazer solicitações, lidar com autenticação e serializar respostas. Alamofire é amplamente utilizado em projetos iOS que desejam uma abstração mais alta sobre o URLSession sem dependências de terceiros para componentes individuais.
