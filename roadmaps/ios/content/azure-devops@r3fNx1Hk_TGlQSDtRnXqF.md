# Azure DevOps
 
Azure DevOps é a suíte de ferramentas de desenvolvedor da Microsoft que inclui um serviço de pipeline CI/CD suportando o desenvolvimento iOS. Ele usa agentes hospedados em macOS para executar builds do Xcode e workflows do Fastlane, e integra-se com Azure Repos, GitHub e outros sistemas de controle de versão. O Azure DevOps é comumente usado em organizações corporativas já investidas em ferramentas da Microsoft.
