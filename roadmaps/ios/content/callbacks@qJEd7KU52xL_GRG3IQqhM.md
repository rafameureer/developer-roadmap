# Callbacks
 
Callbacks são funções passadas como argumentos para serem executadas quando uma operação assíncrona for concluída. Em Swift, callbacks são implementados como closures. Eles são usados para manipuladores de conclusão de rede, callbacks de animação e notificações de eventos, especialmente em código que predate o modelo de concorrência async/await do Swift.
