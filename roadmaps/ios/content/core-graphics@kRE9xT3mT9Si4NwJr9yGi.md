# Core Graphics

Core Graphics, também conhecido como Quartz, é um poderoso framework de renderização gráfica 2D no iOS. Ele fornece funções essenciais para desenhar formas, imagens e texto, lidando com operações gráficas de nível baixo com precisão e eficiência. O Core Graphics suporta recursos avançados como gerenciamento de cores, desenho baseado em caminhos e anti-aliasing, permitindo aos desenvolvedores criar gráficos detalhados e visualmente atraentes dentro de suas aplicações.
