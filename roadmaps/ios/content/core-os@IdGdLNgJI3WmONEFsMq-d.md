# Core OS
 
Core OS é a camada mais baixa da arquitetura do iOS, situada diretamente acima do hardware. Ele fornece o kernel Darwin, estruturas de segurança e interfaces de sistema de nível baixo. Estruturas neste nível incluem Segurança, Accelerate para matemática e processamento de sinais, e ExternalAccessory para comunicação com acessórios de hardware.
