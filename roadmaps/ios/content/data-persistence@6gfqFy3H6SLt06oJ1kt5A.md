# Persistência de Dados

A persistência de dados abrange os diferentes mecanismos que os aplicativos iOS usam para armazenar dados no dispositivo em várias sessões do aplicativo. Opções incluem Core Data para gráficos de objetos complexos, User Defaults para preferências simples, Keychain para credenciais sensíveis, SQLite para dados relacionais e o sistema de arquivos para arquivos arbitrários.
