# Sistema de Arquivos
 
O sistema de arquivos do iOS sandboxes cada aplicativo em diretórios privados. O diretório Documents é para arquivos visíveis ao usuário que devem ser backupeados, o diretório Caches é para dados regeneráveis e o diretório tmp é para arquivos temporários que não precisam persistir. Os aplicativos usam FileManager para criar, ler, escrever, mover e deletar arquivos dentro de seu sandbox.
