# Estruturas (Frameworks)

As estruturas no desenvolvimento iOS são pacotes modulares e reutilizáveis de código e recursos que fornecem funcionalidades específicas para aplicativos. Elas oferecem uma estrutura hierárquica contendo código compilado, arquivos de cabeçalho, recursos como imagens e arquivos de localização, e muitas vezes documentação. O iOS fornece numerosos frameworks embutidos, como UIKit para elementos da interface do usuário, Foundation para tipos de dados fundamentais e coleções, e Core Data para gerenciamento de dados.
