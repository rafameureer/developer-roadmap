# HTTP / HTTPS

HTTP e HTTPS são os protocolos de camada de aplicativo usados para comunicação entre apps iOS e servidores web. O iOS impõe App Transport Security (ATS) por padrão, exigindo HTTPS para a maioria das solicitações de rede. Entender métodos de solicitação, códigos de status, cabeçalhos e o ciclo de solicitação-resposta é fundamental para trabalhar com qualquer pilha de rede iOS.

Acesse os seguintes recursos para saber mais:

- [@official@URLSession](https://developer.apple.com/documentation/foundation/urlsession)
- [@article@Dominando URLSession em Swift](https://elamir.medium.com/mastering-urlsession-in-swift-a-comprehensive-guide-d3a3aa740f6e)
