# MVVM
 
O MVVM (Model-View-ViewModel) separa a camada de interface do usuário da lógica de negócios usando um ViewModel que expõe o estado observável. A View se vincula ao ViewModel e é atualizada automaticamente quando o estado muda, usando Combine, RxSwift ou o framework de observação do Swift. O MVVM é amplamente adotado no desenvolvimento iOS e funciona bem com tanto UIKit quanto SwiftUI.
