# Pilhas de Navegação
 
A pilha de navegação no UIKit é gerenciada pelo UINavigationController usando um modelo empurrar-retirar. As exibições controladoras são empurradas para a pilha quando navegando para frente e removidas quando o usuário toca no botão Voltar ou chama popViewController. A barra de navegação reflete automaticamente o topo atual da pilha.
