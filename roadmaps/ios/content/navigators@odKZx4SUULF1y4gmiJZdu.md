# Navegadores

O painel de navegadores contém múltiplos navegadores para diferentes propósitos. O Navegador do Projeto exibe a hierarquia de arquivos, o Navegador de Problemas exibe erros e avisos, o Navegador de Testes lista as Suites de Teste e o Navegador de Depuração mostra o uso de recursos em tempo de execução. A troca entre navegadores é feita usando os ícones no topo do painel.
