# Novo Projeto

Para criar um projeto Xcode para seu aplicativo, selecione um modelo de plataforma como iOS, macOS, watchOS ou tvOS, e escolha o tipo de aplicativo que deseja desenvolver, como uma única vista, jogo ou aplicativo baseado em documentos. Os modelos do Xcode fornecem configuração essencial e arquivos, permitindo que você comece rapidamente a desenvolver seu aplicativo. Esta configuração ajuda a simplificar as etapas iniciais de desenvolvimento de aplicativos.

Acesse os seguintes recursos para saber mais:

- [@oficial@Criando um projeto Xcode para um aplicativo](https://developer.apple.com/documentation/xcode/creating-an-xcode-project-for-an-app)
- [@vídeo@Construa Seu Primeiro Aplicativo iOS Para Iniciantes](https://www.youtube.com/watch?v=nqTcAzPS3oc)
