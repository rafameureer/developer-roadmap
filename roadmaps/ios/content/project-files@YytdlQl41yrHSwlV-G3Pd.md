# Arquivos do Projeto

O Navegador de Projeto organiza todos os arquivos em um projeto Xcode, incluindo arquivos-fonte Swift, ativos, arquivos de configuração e estruturas. Os arquivos são listados hierarquicamente e podem ser adicionados, excluídos ou reorganizados no navegador. O arquivo do projeto (*.xcodeproj) armazena configurações de build, alvos e referências a arquivos.

Acesse os seguintes recursos para saber mais:

- [@oficial@Direitos](https://developer.apple.com/documentation/bundleresources/entitlements)
- [@oficial@Gerenciando a Lista de Propriedades do Informação do Seu Aplicativo](https://developer.apple.com/documentation/bundleresources/information_property_list/managing_your_app_s_information_property_list)
- [@artigo@Extensão .XCODEPROJ](https://fileinfo.com/extension/xcodeproj)
