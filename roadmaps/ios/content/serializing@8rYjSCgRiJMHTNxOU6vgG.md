# Serialização

A serialização converte estruturas de dados Swift em formato JSON ou XML para armazenamento ou transmissão de rede. O JSONEncoder transforma tipos Codable em Data. A serialização adequada lida com formatos de data, estratégias personalizadas de nomeação de chaves e valores opcionais, produzindo saída válida que o servidor ou camada de armazenamento possa interpretar corretamente.

Acesse os seguintes recursos para saber mais:

- [@oficial@Codificação, Decodificação e Serialização](https://developer.apple.com/documentation/swift/encoding-decoding-and-serialization)
- [@oficial@Codable](https://developer.apple.com/documentation/swift/codable)
