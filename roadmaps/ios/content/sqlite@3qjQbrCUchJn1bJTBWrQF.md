# SQLite

SQLite é um motor de banco de dados relacional leve, sem servidor, incorporado no iOS. As apps podem usar SQLite diretamente através da sua API C ou através de wrappers Swift de nível superior como GRDB ou SQLite.swift. O SQLite fornece armazenamento estruturado e consultável e serve como o mecanismo subjacente para Core Data e outros frameworks de dados.
