# Biblioteca Estática

Uma biblioteca estática é um arquivo de arquivos de objeto compilados que são copiados diretamente para o binário da aplicação no momento da vinculação. As bibliotecas estáticas aumentam o tamanho do binário, mas não têm sobrecarga de carregamento em tempo de execução. Eles são distribuídos como arquivos .a e são comumente usados para compartilhar código compilado entre alvos dentro do mesmo projeto Xcode.
