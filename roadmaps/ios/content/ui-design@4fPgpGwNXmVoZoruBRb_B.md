# Design de UI
 
O design de UI para iOS se concentra em como os aplicativos devem parecer e funcionar para se sentir nativos e intuitivos em plataformas Apple. A referência principal é as Diretrizes Humanas da Interface do Usuário (HIG) da Apple, que fornece princípios e orientações específicas sobre padrões de navegação, controles, tipografia, cores e acessibilidade. Aplicar esses princípios resulta em aplicativos que se sentem familiares e polidos para os usuários do iOS.
