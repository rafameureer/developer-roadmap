# Testes de Unidade e UI

As aplicações iOS são testadas em dois níveis: os testes de unidade verificam funções e classes isoladamente, enquanto os testes de interface do usuário verificam o comportamento da aplicação a partir da perspectiva do usuário. O XCTest é o framework para ambos. Os testes de unidade executam na máquina local e são rápidos; os testes de UI iniciam a aplicação completa em um dispositivo ou simulador e simulan interações reais do usuário.
