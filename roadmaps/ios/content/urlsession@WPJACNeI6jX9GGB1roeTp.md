# URLSession

URLSession é a API de rede incorporada da Apple para fazer solicitações HTTP e HTTPS. Ele suporta tarefas de dados para solicitações simples, tarefas de download e upload para transferências grandes e sessões em segundo plano que continuam após o aplicativo ser suspenso. URLSession integra-se com async/await no Swift, permitindo que chamadas de rede sejam escritas como funções assíncronas sequenciais.
