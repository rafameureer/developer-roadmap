# User Defaults

User Defaults é um armazenamento simples de chave-valor para persistir preferências e configurações leves do usuário em várias iniciações do aplicativo. Ele armazena tipos básicos como strings, números, booleanos e datas em um arquivo plist. User Defaults não é adequado para dados sensíveis ou grandes e está destinado apenas a valores de configuração pequenos.
