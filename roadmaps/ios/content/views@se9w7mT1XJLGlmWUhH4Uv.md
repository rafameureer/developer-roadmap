# Views

As views do UIKit são os elementos visuais principais em interfaces iOS, servindo como o quadro para todos os componentes da interface do usuário. Em sua forma mais básica, uma view é uma instância de UIView, representando uma área retangular na tela. As views lidam com a renderização de conteúdo, disposição de subviews e resposta a eventos de toque. Elas podem ser aninhadas para criar layouts complexos, com cada view responsável por desenhar e gerenciar sua própria área. Embora algumas views exibam conteúdo diretamente, outras atuam como contêineres para outras views.
