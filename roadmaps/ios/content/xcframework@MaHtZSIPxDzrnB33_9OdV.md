# XCFramework
 
Um XCFramework é um formato de binário distribuível que agrupa frameworks para múltiplas plataformas e arquiteturas em um único pacote. Ele suporta dispositivos iOS, simulador do iOS, macOS e outras plataformas Apple simultaneamente. XCFrameworks são o formato recomendado para distribuir bibliotecas pré-compiladas de iOS e SDKs.

Visite os seguintes recursos para aprender mais:

- [@official@Criando um pacote binário multiplataforma](https://developer.apple.com/documentation/xcode/creating-a-multi-platform-binary-framework-bundle)
- [@official@Distribuindo pacotes binários como pacotes Swift](https://developer.apple.com/documentation/xcode/distributing-binary-frameworks-as-swift-packages)
