# Abstração

A palavra-chave `abstract` em Java é usada para declarar uma classe ou um método que não pode ser instanciado diretamente ou que deve ser implementado por subclasses, respectivamente. É uma parte crucial do mecanismo de abstração do Java, permitindo aos desenvolvedores definir classes e métodos abstratos que fornecem um esboço para outras classes.

Acesse os seguintes recursos para saber mais:

- [@artigo@Classes Abstratas em Java](https://jenkov.com/tutorials/java/abstract-classes.html)
