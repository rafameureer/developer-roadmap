# Especificadores de Acesso

Os especificadores de acesso (ou modificadores de acesso) em Java são palavras-chave que controlam a visibilidade ou acessibilidade de classes, métodos, construtores e outros membros. Eles determinam de onde esses membros podem ser acessados. O Java fornece quatro especificadores de acesso: `private`, `default` (sem palavra-chave), `protected` e `public`, cada um oferecendo um nível diferente de controle de acesso.
