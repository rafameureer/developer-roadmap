# Tipos de Dados e Variáveis

Em Java, uma variável é um contêiner de dados que armazena valores de dados durante a execução do programa Java. Cada variável é atribuída a um tipo de dado, que designa o tipo e a quantidade de valores que ela pode conter. A variável é um nome de localização de memória do dado. As variáveis em Java têm principalmente três tipos: Locais, Instâncias e Estáticas.

Os Tipos de Dados são divididos em dois grupos -

*   Primitivos - byte, short, int, long, float, double, boolean e char
*   Não-Primitivos - String, Arrays, Classes, Enums e Records
