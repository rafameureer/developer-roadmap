# Injeção de Dependência

A Injeção de Dependência (DI) é um padrão de design onde objetos recebem suas dependências de fontes externas em vez de criá-las por conta própria. Isso significa que uma classe não precisa se preocupar com como obter os objetos necessários para funcionar; em vez disso, esses objetos são "injetados" na classe, geralmente através do seu construtor, métodos setter ou interface. Isso promove a desacoplamento fraco e torna o código mais testável e manterável.
