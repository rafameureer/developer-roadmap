# Encapsulamento

O encapsulamento é um conceito fundamental na programação orientada a objetos, onde os dados e os métodos que operam nesses dados são agrupados em uma única unidade. Essa unidade, geralmente uma classe, oculta o estado interno do objeto do mundo exterior e expõe apenas uma interface controlada para interagir com ele. Isso protege os dados de modificações acidentais e facilita a manutenção e modificação do código.
