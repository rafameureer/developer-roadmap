# Operações de Arquivos

Aprenda como trabalhar com arquivos, isto é, ler, escrever e deletar arquivos e pastas. Além disso, aprenda como fazer chamadas à API, analisar a resposta recebida, etc.

*   `FileWriter` - esta classe é útil para criar um arquivo escrevendo caracteres nele
*   `FileReader` - esta classe é útil para ler dados no formato de caracteres do arquivo
*   `Files.lines(Paths.get("file.txt")))` - processando arquivos como uma stream. Desde Java 8
*   `Files.readString / Files.writeString` - lê o conteúdo completo do arquivo e coloca em uma string - desde Java 11
