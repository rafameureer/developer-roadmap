# Bloco de Inicialização

Um bloco de inicialização em Java é um bloco de código, envolvido por chaves `{}`, que é executado quando uma instância de uma classe é criada. Ele é usado para inicializar variáveis de instância ou realizar tarefas de configuração antes do construtor ser chamado. Existem dois tipos: blocos de inicialização de instância, que são executados toda vez que um novo objeto é criado, e blocos de inicialização estáticos, que são executados apenas uma vez quando a classe é carregada pela primeira vez.
