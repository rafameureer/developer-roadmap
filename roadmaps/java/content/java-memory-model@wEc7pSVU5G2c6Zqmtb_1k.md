# Modelo de Memória do Java

O Modelo de Memória do Java (JMM) define como as threads em Java interagem com a memória. Ele especifica como e quando diferentes threads podem ver gravações em variáveis compartilhadas, abordando problemas como visibilidade de dados e condições de corrida em programas concorrentes. O JMM garante que programas multithreaded do Java se comportem de forma previsível em diferentes arquiteturas de hardware estabelecendo regras para a sincronização e ordenação da memória.
