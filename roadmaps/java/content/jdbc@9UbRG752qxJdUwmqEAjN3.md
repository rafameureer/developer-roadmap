# JDBC em Java

JDBC é uma API (Interface de Programação de Aplicativos) usada em programação Java para interagir com bancos de dados. As classes e interfaces do JDBC permitem que a aplicação envie solicitações feitas pelos usuários ao banco de dados especificado.
