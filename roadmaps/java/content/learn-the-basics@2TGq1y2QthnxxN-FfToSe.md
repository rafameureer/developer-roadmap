# Fundamentos do Java

Java é um idioma de programação e plataforma de computação lançada pela Sun Microsystems em 1995. Java é um idioma de propósito geral, baseado em classes e orientado a objetos, projetado para ter menos dependências de implementação. É uma plataforma de computação para o desenvolvimento de aplicativos. Java é rápido, seguro e confiável. Portanto, ele é amplamente usado para desenvolver aplicativos Java em laptops, centros de dados, consoles de jogos, supercomputadores científicos, telefones celulares, etc.

Saiba sobre os fundamentos do Java como a sintaxe básica, tipos de dados, variáveis, condicionais, funções, estruturas de dados, pacotes, etc.
