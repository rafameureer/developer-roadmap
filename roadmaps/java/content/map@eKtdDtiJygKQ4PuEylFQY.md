# Map

Um Map é uma estrutura de dados que armazena dados em pares chave-valor. Cada chave é única e mapeia a um valor específico. Imagine como um dicionário onde você usa uma palavra (a chave) para procurar sua definição (o valor). Os Maps permitem que você recupere, adicione ou remova valores de maneira eficiente com base em suas chaves associadas.
