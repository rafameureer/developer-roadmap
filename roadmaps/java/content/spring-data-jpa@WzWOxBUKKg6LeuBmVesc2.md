# Spring Data JPA

O Spring Data JPA visa significativamente melhorar a implementação de camadas de acesso a dados reduzindo o esforço ao nível que é realmente necessário. Como desenvolvedor, você escreve suas interfaces de repositório, incluindo métodos de localizador personalizados, e o Spring fornecerá a implementação automaticamente.
