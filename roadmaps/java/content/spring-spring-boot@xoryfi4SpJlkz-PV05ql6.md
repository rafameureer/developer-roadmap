# Spring Boot

O Spring Boot é um framework de Java web de código aberto, baseado em microserviços. O framework do Spring Boot cria um ambiente totalmente pronto para produção que é completamente configurável usando seu código pré-construído dentro de sua base de código. A arquitetura de microserviço fornece aos desenvolvedores uma aplicação totalmente encolhida, incluindo servidores de aplicativos embutidos.
