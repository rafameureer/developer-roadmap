# Básicos de Threads

Um thread em Java é o caminho ou direção que é seguido enquanto um programa está sendo executado. Geralmente, todos os programas têm pelo menos um thread, conhecido como o thread principal, que é fornecido pela JVM ou Máquina Virtual Java no início da execução do programa.

Escrever uma aplicação multithread correta é complexo e é um tópico avançado. Coisas como ParallelStreams, coleções seguras para threads e ExecutorService podem ser úteis.
