# Threads Virtuais

As threads virtuais são threads leves gerenciadas pela Máquina Virtual Java (JVM). Diferentemente das threads do sistema operacional tradicional, que são relativamente caras de criar e gerenciar, as threads virtuais estão projetadas para serem extremamente leves, permitindo a criação de milhões delas. Elas têm como objetivo melhorar a escalabilidade e a concorrência das aplicações Java ao tornar mais fácil escrever código que possa lidar com um grande número de operações concorrentes sem o overhead associado às threads tradicionais.
