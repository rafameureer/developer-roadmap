# Tudo sobre Variáveis
 
As variáveis são contêineres nomeados para armazenar valores de dados em um programa. No JavaScript, as variáveis são declaradas usando `var`, `let` ou `const`, cada uma com regras diferentes de escopo e reatribuição. Escolher a palavra-chave de declaração correta afeta como a variável se comporta ao longo do código.
