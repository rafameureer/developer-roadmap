# Objeto arguments

O objeto `arguments` é um objeto semelhante a um array acessível dentro de funções que contém os valores dos argumentos passados para aquela função, disponíveis em todas as funções não-arrow. Você pode se referir aos argumentos de uma função dentro dela usando seu objeto `arguments`. Ele tem entradas para cada argumento com o qual a função foi chamada, com o índice da primeira entrada sendo 0. Mas, em código moderno, os parâmetros rest devem ser preferidos.
