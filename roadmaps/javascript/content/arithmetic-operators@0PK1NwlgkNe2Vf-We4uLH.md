# Operadores Aritméticos
 
Os operadores aritméticos realizam operações matemáticas em números. Eles incluem `+` (adição), `-` (subtração), `*` (multiplicação), `/` (divisão), `%` (resto) e `**` (exponenciação). O operador `+` também é usado para a concatenação de strings, o que pode causar problemas quando os operandos são tipos mistos.
