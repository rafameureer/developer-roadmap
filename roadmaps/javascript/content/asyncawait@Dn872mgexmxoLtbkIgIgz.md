# Async/Await

`async/await` é uma sintaxe especial para trabalhar com promessas de forma mais confortável. Usamos a palavra-chave `async` para declarar uma função assíncrona que retorna uma Promise, e a palavra-chave `await` faz com que a função espere por uma Promise.
