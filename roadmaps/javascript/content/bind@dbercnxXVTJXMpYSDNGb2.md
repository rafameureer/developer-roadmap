# bind()

O método `bind()` em JavaScript permite criar uma nova função com um contexto específico e opcionalmente argumentos pré-definidos. Diferentemente de `call()` ou `apply()`, `bind()` não invoca imediatamente a função. Em vez disso, ele retorna uma nova função que pode ser chamada mais tarde, seja como uma função regular ou com argumentos adicionais. Isso é particularmente útil quando você deseja garantir que uma função mantenha um contexto específico, independentemente de como ou quando ela for invocada.
