# Fechamentos (Closures)

Os fechamentos são um dos conceitos mais poderosos, mas também mais mal compreendidos, do JavaScript que na verdade são realmente fáceis de entender. Um fechamento se refere a uma função junto com seu ambiente léxico. É essencialmente o que nos permite retornar uma função `A` de outra função `B`, que lembra as variáveis locais definidas em `B`, mesmo após `B` sair. A ideia dos fechamentos é empregada quase em todos os outros programas JavaScript, por isso é crucial para um desenvolvedor de JavaScript entender bem.
