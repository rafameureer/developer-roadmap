# Operadores de Comparação

Os operadores de comparação são aqueles que comparam valores e retornam verdadeiro ou falso. Os operadores incluem: `>`, `<`, `>=`, `<=`, `==`, `===`, `!=` e `!==`

Acesse os seguintes recursos para saber mais:
