# Depurando Problemas

As ferramentas de depuração do DevTools do navegador permitem aos desenvolvedores definir pontos de interrupção, passar por código, inspecionar valores de variáveis e rastrear a pilha de chamadas. O console permite registrar valores e avaliar expressões no escopo atual. Essas ferramentas tornam possível entender o que o código está fazendo em tempo de execução e identificar a origem dos bugs.

Acesse os seguintes recursos para saber mais:

- [@artigo@Depurando JavaScript no painel de fontes](https://developer.chrome.com/docs/devtools/javascript/)
