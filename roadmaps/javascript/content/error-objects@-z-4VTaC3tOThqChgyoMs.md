# Objetos de Erro

JavaScript fornece um conjunto de tipos de erro embutidos que estendem a classe base `Error`. Isso inclui `TypeError`, `RangeError`, `SyntaxError`, `ReferenceError` e outros. Cada um tem uma propriedade `message` e uma rastreamento de pilha. Usar tipos de erro específicos facilita o captura e tratamento de diferentes modos de falha separadamente.

- [@article@Objeto Error - MDN](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Error)
