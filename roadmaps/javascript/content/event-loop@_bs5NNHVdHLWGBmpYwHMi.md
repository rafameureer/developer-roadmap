# Loop de Eventos

O Loop de Eventos é um dos aspectos mais importantes a entender sobre o Node.js. Por que isso é tão importante? Porque ele explica como o Node.js pode ser assíncrono e ter I/O não bloqueante, explicando a "característica killer" do Node.js, que tornou-o tão bem-sucedido.
