# Casting de Tipo Explícito

O casting de tipo significa transferir dados de um tipo de dado para outro explicitamente especificando o tipo para converter os dados fornecidos. O casting de tipo explícito é normalmente feito para tornar os dados compatíveis com outras variáveis. Exemplos de métodos de casting de tipo são `parseInt()`, `parseFloat()`, `toString()`.
