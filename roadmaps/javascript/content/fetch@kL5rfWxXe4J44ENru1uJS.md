# Fetch

O método `fetch()` em JavaScript é usado para solicitar informações ao servidor e carregar as informações nas páginas da web. A solicitação pode ser de qualquer API que retorne dados no formato JSON ou XML. Esse método retorna uma promessa.

Acesse os seguintes recursos para saber mais:

- [@article@Fetch MDN Docs](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API/Using_Fetch)
- [@article@Network request - Fetch](https://javascript.info/fetch)
