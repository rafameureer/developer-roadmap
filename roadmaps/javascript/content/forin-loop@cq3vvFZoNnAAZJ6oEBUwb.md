# Laço for...in

O `for...in` loop itera sobre as propriedades enumeráveis de um objeto, incluindo as herdadas. Ele é principalmente usado para iterar sobre as chaves do objeto. Não é recomendado usar com arrays porque ele itera sobre todas as propriedades enumeráveis, não apenas índices numéricos, e não garante a ordem.
