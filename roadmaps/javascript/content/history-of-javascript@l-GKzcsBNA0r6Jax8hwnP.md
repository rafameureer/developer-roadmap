# História do JavaScript

JavaScript foi inicialmente criado por Brendan Eich da NetScape e foi anunciado pela primeira vez em uma declaração de imprensa pela Netscape em 1995. Ele tem uma história estranha de nomeação; inicialmente, ele foi chamado de Mocha pelo criador, que mais tarde foi renomeado para LiveScript. Em 1996, cerca de um ano depois da liberação, a NetScape decidiu renomear para JavaScript com o intuito de capitalizar na comunidade Java (embora JavaScript não tivesse relação com Java) e lançou a Netscape 2.0 com o suporte oficial do JavaScript.
