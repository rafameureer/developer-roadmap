# Hoisting

Hoisting é o comportamento do JavaScript de mover declarações de variáveis e funções para o topo de seu escopo contendo antes da execução do código. Variáveis declaradas com `var` são levantadas e inicializadas como `undefined`. As declarações de função são totalmente levantadas, o que significa que podem ser chamadas antes de aparecerem no código-fonte. `let` e `const` são levantados mas não inicializados, resultando em uma zona morta temporal.
