# Coleções indexadas

Coleções Indexadas são coleções que têm índices numéricos, ou seja, as coleções de dados que estão ordenadas por um valor de índice. No JavaScript, um array é uma coleção indexada. Um array é um conjunto ordenado de valores com um índice numérico.
