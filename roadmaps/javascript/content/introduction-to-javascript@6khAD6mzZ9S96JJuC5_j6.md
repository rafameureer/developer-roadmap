# Introdução ao JavaScript

JavaScript é um linguagem de programação de alto nível e interpretada criada para adicionar interatividade a páginas da web. Ele roda no navegador e, com o Node.js, também no servidor. É a única linguagem que roda nativamente nos navegadores da web, tornando-se a base do desenvolvimento frontend web.
