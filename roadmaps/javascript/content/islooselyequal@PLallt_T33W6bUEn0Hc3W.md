# isLooselyEqual

A comparação de igualdade abstrata (igualdade relaxada) é o algoritmo por trás do operador `==`. Ele define as regras para como valores de tipos diferentes são coercidos antes da comparação. Por exemplo, `null == undefined` é `true`, mas `null == 0` é `false`. Entender este algoritmo explica muitos dos comportamentos surpreendentes de igualdade do JavaScript.
