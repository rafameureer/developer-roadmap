# Escopo Lexical

Antes de se formar uma intuição sobre fechamentos em JavaScript, é importante primeiro entender o termo '**_ambiente léxico_**'. Em palavras simples, o ambiente léxico para uma função `f` simplesmente refere-se ao ambiente que envolve a definição daquela função no código-fonte.

Acesse os seguintes recursos para saber mais:

- [@artigo@O que é um ambiente léxico? - JavaScript - CodeGuage](https://www.codeguage.com/courses/js/functions-closures#What_is_a_lexical_environment)
- [@artigo@Escopo Lexical - JavaScript - MDN](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript/Fechamentos#escopo_lexical)
