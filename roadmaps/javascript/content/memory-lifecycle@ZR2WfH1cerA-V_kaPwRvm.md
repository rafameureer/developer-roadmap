# Ciclo de Vida da Memória

O ciclo de vida da memória tem três estágios: alocação (a memória é reservada quando um valor é criado), uso (a memória é lida e escrita durante a execução) e liberação (a memória é liberada quando não é mais acessível). No JavaScript, a alocação acontece implicitamente, e a liberação é tratada pelo coletor de lixo.
