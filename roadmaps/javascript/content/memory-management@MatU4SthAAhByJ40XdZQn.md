# Gerenciamento de Memória

Linguagens de nível baixo como C têm primitivas de gerenciamento de memória manual, como `malloc()` e `free()`. Em contraste, o JavaScript aloca automaticamente a memória quando objetos são criados e libera quando não são mais usados (coleta de lixo). Esta automação pode ser uma fonte de confusão: pode dar aos desenvolvedores a impressão falsa de que eles não precisam se preocupar com o gerenciamento de memória.

Acesse os seguintes recursos para saber mais:

- [@artigo@Coleta de Lixo no JavaScript](https://javascript.info/garbage-collection)
- [@artigo@Gestão da Memória no JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Memory_Management)
