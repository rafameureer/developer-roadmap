# number

O tipo `number` representa tanto inteiros quanto valores de ponto flutuante em JavaScript. Ele usa o formato IEEE 754 double-precision, o que significa que todos os números são armazenados como floats. Valores especiais incluem `Infinity`, `-Infinity` e `NaN` (Not a Number), que resultam de certas operações aritméticas.
