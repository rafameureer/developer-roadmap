# Promises

As promises são uma maneira muito melhor de trabalhar com código assíncrono em JavaScript do que a antiga e imprudente abordagem de callbacks. Eles foram introduzidos no JavaScript com ECMAScript 6. Usando promises, podemos gerenciar códigos assíncronos extremamente complexos com uma configuração rigorosa de tratamento de erros, escrever código em um estilo mais ou menos síncrono e nos livrar do tão chamado "inferno dos callbacks".
