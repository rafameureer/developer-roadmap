# Herança Prototipal

A Herança Prototipal é uma característica do JavaScript usada para adicionar métodos e propriedades a objetos. É um método pelo qual um objeto pode herdar as propriedades e métodos de outro objeto. Tradicionalmente, para obter e definir o Protótipo de um objeto, utilizamos `Object.getPrototypeOf` e `Object.setPrototypeOf`.
