# SameValue
 
SameValue é o algoritmo de igualdade usado pelo `Object.is()`. É a comparação de igualdade mais estrita em JavaScript: ele retorna `true` apenas quando dois valores são idênticos, tratando `NaN` como igual a `NaN` e `+0` como não igual a `-0`. Ele é usado em algumas operações internas específicas.

Acesse os seguintes recursos para saber mais:

- [@article@Igualdade de mesmo valor usando Object.is()](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript/Comparação_de_valores_e_igualdade#igualdade_de_mesmo_valor_usando_object.is)
