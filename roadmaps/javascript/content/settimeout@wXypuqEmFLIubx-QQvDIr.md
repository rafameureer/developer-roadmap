# setTimeout

O `setTimeout()` agende uma função para ser executada após um atraso especificado em milissegundos. Ele é assíncrono: o resto do código continua sendo executado enquanto o temporizador roda. Retorna um ID que pode ser usado com `clearTimeout()` para cancelar a execução agendada.
