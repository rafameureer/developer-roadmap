# Switch

A declaração `switch` avalia uma expressão e executa o bloco `case` correspondente. É uma alternativa a uma longa cadeia de declarações `if...else if` quando comparando um valor contra várias opções. Cada `case` geralmente deve terminar com um `break` para evitar que ele se desvie para o próximo caso.
