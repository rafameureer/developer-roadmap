# Simbolos

Simbolos são um tipo de dado primitivo único e imutável em JavaScript, introduzido no ECMAScript 6 (ES6). Eles são frequentemente usados para criar chaves de propriedade únicas para objetos, garantindo que não ocorram colisões de chave de propriedade. Cada valor Simbolo é distinto, mesmo quando múltiplos são criados com a mesma descrição. Simbolos podem ser criados usando a função Symbol(), e seu principal caso de uso é adicionar propriedades ocultas ou especiais a objetos que não interfiram com outras propriedades ou métodos.
