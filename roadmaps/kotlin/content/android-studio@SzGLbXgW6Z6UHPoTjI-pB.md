# Android Studio

Android Studio é o ambiente de desenvolvimento integrado (IDE) oficial para o desenvolvimento de apps do Android, e ele totalmente suporta Kotlin. Ele fornece ferramentas para codificação, depuração, teste e design de interfaces do usuário para aplicativos Android. Com recursos como conclusão de código, refatoração e um editor visual de layout, Android Studio facilita o processo de construção de apps do Android baseados em Kotlin.

Acesse os seguintes recursos para saber mais:

- [@curso@Introdução à programação em Kotlin](https://developer.android.com/courses/pathways/android-basics-compose-unit-1-pathway-1)
- [@oficial@Kotlin para Android](https://kotlinlang.org/docs/android-overview.html)
