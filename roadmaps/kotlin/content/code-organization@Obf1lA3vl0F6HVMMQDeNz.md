# Organização do Código

Em projetos puramente em Kotlin, a estrutura de diretórios recomendada segue a estrutura de pacotes, omitindo o pacote raiz comum. Por exemplo, se todo o código do projeto estiver no pacote `org.example.kotlin` e seus subpacotes, arquivos com o pacote `org.example.kotlin` devem ser colocados diretamente sob a raiz de origem, e arquivos em `org.example.kotlin.network.socket` devem estar na subdiretória `network/socket` da raiz de origem.

Visite os seguintes recursos para aprender mais:

- [@official@Organização do código](https://kotlinlang.org/docs/coding-conventions.html#source-code-organization)
