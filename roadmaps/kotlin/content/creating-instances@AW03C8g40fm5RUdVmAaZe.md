# Criando Instâncias

No Kotlin, criar uma instância de uma classe é simples. Basta usar o nome da classe seguido por parênteses, similar a chamar uma função. Isso invoca o construtor da classe, que inicializa o objeto. Se a classe tiver um construtor primário, você precisará fornecer os argumentos necessários dentro dos parênteses. Se não houver um construtor explícito definido, Kotlin fornece um padrão.
