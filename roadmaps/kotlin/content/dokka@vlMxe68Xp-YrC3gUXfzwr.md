# Dokka

Dokka é um gerador de documentação para Kotlin, semelhante ao Javadoc para Java. Ele gera documentação da API em vários formatos (como HTML, Markdown e mais) a partir do código-fonte Kotlin. Dokka usa comentários KDoc dentro do seu código para criar uma documentação abrangente e navegável, tornando mais fácil para os desenvolvedores entender e usar suas bibliotecas e aplicativos Kotlin.
