# Enum Class

Uma classe de enumeração em Kotlin é um tipo especial de classe que representa um conjunto fixo de valores possíveis, geralmente chamados de "enumerações". Pense nele como uma lista de constantes nomeadas. Cada constante na classe de enumeração é uma instância dessa classe. Eles são úteis quando você precisa representar um número limitado de escolhas, como dias da semana, direções (Norte, Sul, Leste, Oeste) ou códigos de status (por exemplo, Sucesso, Pendente, Falha).
