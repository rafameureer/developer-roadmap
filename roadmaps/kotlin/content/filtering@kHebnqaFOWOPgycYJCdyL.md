# Filtragem em Coleções do Kotlin

A filtragem em coleções do Kotlin envolve selecionar elementos de uma coleção com base em uma condição específica. Esse processo cria uma nova coleção contendo apenas os elementos que atendem ao predicado fornecido, deixando a coleção original inalterada. O Kotlin oferece várias funções internas para realizar operações de filtragem de maneira eficiente e concisa.
