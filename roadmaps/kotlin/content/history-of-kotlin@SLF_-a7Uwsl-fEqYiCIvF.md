# História do Kotlin

O Kotlin é um linguagem de programação moderna e tipada estaticamente desenvolvida pela JetBrains. Foi concebido inicialmente como um novo idioma para a JVM, com o objetivo de abordar algumas das limitações do Java enquanto mantinha a total interoperabilidade. O projeto começou em 2010 e foi open source desde muito cedo. A primeira versão oficial 1.0 foi lançada em fevereiro de 2016. O design da linguagem enfatiza concisão, segurança e versatilidade, tornando-o adequado para uma ampla gama de aplicações, incluindo desenvolvimento Android, aplicativos do lado do servidor e mais.
