# Iteradores

Iteradores são objetos que permitem você percorrer os elementos de uma coleção (como uma lista ou um conjunto) um por um. Eles fornecem uma maneira de acessar cada item na coleção sequencialmente, sem precisar saber a estrutura subjacente da coleção. Você pode usar iteradores para ler os elementos e, em alguns casos, remover elementos da coleção à medida que itera.
