# Kotlin Notebook

O Kotlin Notebook é um ambiente interativo para escrever e executar código Kotlin, semelhante ao Jupyter Notebook para Python. Ele permite combinar código, texto e visualizações em um único documento, tornando-o ideal para exploração de dados, prototipagem e criação de tutoriais interativos. Você pode executar snippets de código (células) individualmente e ver os resultados imediatamente, facilitando experimentação e desenvolvimento rápido.
