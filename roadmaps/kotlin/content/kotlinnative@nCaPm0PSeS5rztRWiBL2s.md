# Kotlin/Native

O Kotlin/Native é uma tecnologia para compilar código Kotlin em binários nativos, que podem ser executados sem uma máquina virtual. Isso permite usar o Kotlin para desenvolver aplicativos para plataformas onde uma JVM não é adequada ou disponível, como sistemas embarcados, iOS, macOS, Windows, Linux e WebAssembly. Ele atinge isso usando a infraestrutura do compilador LLVM para traduzir código Kotlin em código de máquina.
