# Kotlin/WASM

O Kotlin/WASM permite que você compile código Kotlin para WebAssembly (WASM), um formato de instrução binária projetado para execução eficiente em navegadores da web e outros ambientes. Isso habilita os desenvolvedores do Kotlin a criar aplicativos de alto desempenho que podem ser executados diretamente no navegador, aproveitando as características e ferramentas do Kotlin para o desenvolvimento web. Oferece uma alternativa ao JavaScript para o desenvolvimento de clientes da web e também abre possibilidades para usar Kotlin em outros ambientes compatíveis com WASM.
