# Ktor

O Ktor é um framework para construir aplicativos de servidor assíncrono, aplicativos de cliente e muito mais, em sistemas conectados. Ele é construído usando Kotlin e coroutines, fornecendo uma maneira simples e eficiente de lidar com concorrência e construir aplicativos de rede escaláveis. O Ktor permite aos desenvolvedores criar aplicativos web, APIs HTTP, microservices e outros aplicativos de rede com facilidade.
