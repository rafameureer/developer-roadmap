# Maven

Maven é uma poderosa ferramenta de automação de build principalmente usada para projetos Java, mas também funciona perfeitamente com Kotlin. Ele simplifica a gestão de dependências permitindo que você declare as bibliotecas externas necessárias pelo seu projeto e o Maven baixa automaticamente e inclui-as. O Maven usa um arquivo de Modelo do Objeto do Projeto (POM), típicamente nomeado `pom.xml`, para descrever a configuração, dependências e processo de build do projeto, tornando as construções de projetos consistentes e reproduzíveis em diferentes ambientes.
