# Operadores de Adição e Subtração em Coleções Kotlin

Os operadores `plus` e `minus` em coleções do Kotlin oferecem uma maneira concisa de criar novas coleções adicionando ou removendo elementos de coleções existentes. O operador `plus` (+) combina duas coleções ou adiciona um único elemento a uma coleção, retornando uma nova coleção contendo todos os elementos. Por outro lado, o operador `minus` (-) remove elementos de uma coleção, especificando indivíduos elementos ou outra coleção de elementos a serem removidos, também retornando uma nova coleção.
