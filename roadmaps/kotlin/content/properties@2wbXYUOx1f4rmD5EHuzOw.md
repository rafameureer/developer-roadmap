# Propriedades em Classes Kotlin

As propriedades em classes Kotlin são variáveis declaradas diretamente dentro de uma classe. Elas representam o estado de um objeto. Cada propriedade tem um nome, um tipo e pode opcionalmente ter um getter e um setter. Os getters são usados para ler o valor da propriedade, enquanto os setters são usados para modificá-la. Se você não definir explicitamente eles, Kotlin fornece automaticamente getters padrão e setters para propriedades mutáveis (declaradas com `var`) e um getter padrão para propriedades de leitura única (declaradas com `val`).
