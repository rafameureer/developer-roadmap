# Recuperando partes de uma coleção

A biblioteca padrão do Kotlin contém funções de extensão para recuperar partes de uma coleção. Funções como `slice()`, `take()`, `drop()` e `chunked()`, fornecem várias maneiras de selecionar elementos para a coleção de resultados: listando suas posições explicitamente, especificando o tamanho do resultado e outros.

Acesse os seguintes recursos para saber mais:

- [@official@Recuperar partes da coleção](https://kotlinlang.org/docs/collection-parts.html)
- [@video@Recuperando partes de uma Coleção | slice | drop | chunked | windowed](https://www.youtube.com/watch?v=mALsyqRUfMI)
