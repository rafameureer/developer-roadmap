# Retorno em funções do Kotlin

No Kotlin, a declaração `return` é usada dentro de uma função para parar sua execução e enviar um valor de volta ao chamador. O valor retornado deve corresponder ao tipo de retorno declarado da função. Se uma função não retornar explicitamente um valor (seu tipo de retorno for `Unit`), a declaração `return` é opcional no final da função; caso contrário, ela é necessária para fornecer um valor do tipo correto.

Acesse os seguintes recursos para saber mais:

- [@official@Funções com retorno `Unit`](https://kotlinlang.org/docs/functions.html#unit-returning-functions)
