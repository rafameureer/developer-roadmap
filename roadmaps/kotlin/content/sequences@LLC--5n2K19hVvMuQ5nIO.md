# Sequências

As sequências em Kotlin fornecem uma maneira de realizar operações em coleções de dados de forma preguiçosa. Em vez de processar cada elemento imediatamente, as sequências avaliam operações apenas quando o resultado final for necessário. Isso pode levar a melhorias significativas de desempenho, especialmente ao lidar com grandes conjuntos de dados ou transformações complexas, pois coleções intermediárias são evitadas. Eles são particularmente úteis quando você tem uma cadeia de operações a realizar em uma coleção.
