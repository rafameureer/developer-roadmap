# Configurando o Ambiente Kotlin

Configurar o ambiente Kotlin envolve instalar as ferramentas necessárias e configurar seu sistema para compilar e executar código Kotlin. Isso geralmente inclui a instalação de um Java Development Kit (JDK), o download do compilador Kotlin e, opcionalmente, a configuração de um Ambiente de Desenvolvimento Integrado (IDE) como IntelliJ IDEA ou Android Studio com plugins em Kotlin para uma experiência de desenvolvimento mais fluída. O processo de configuração garante que você tenha os componentes necessários para escrever, compilar e executar programas Kotlin.

Acesse os seguintes recursos para saber mais:

- [@official@Começando com Kotlin](https://kotlinlang.org/docs/getting-started.html#install-kotlin)
