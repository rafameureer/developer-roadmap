# Spring

Spring é um popular e de código aberto framework de aplicativos para construir aplicações Java robustas e escaláveis. Ele oferece suporte integral à infraestrutura para desenvolver aplicativos empresariais, lidando com preocupações como injeção de dependência, programação orientada a aspectos, acesso a dados e gerenciamento de transações. O Spring utiliza as funcionalidades do Kotlin para oferecer APIs mais concisas, começando da versão 5.0. O gerador de projeto online permite que você gere rapidamente um novo projeto em Kotlin.

Acesse os seguintes recursos para saber mais:

- [@official@Spring Docs](https://docs.spring.io/spring-framework/reference/index.html)
