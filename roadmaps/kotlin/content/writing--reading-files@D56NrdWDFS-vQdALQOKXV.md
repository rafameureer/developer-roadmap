# Escrevendo e Lendo Arquivos

Escrever e ler arquivos em Kotlin envolve o uso de classes do pacote `java.io`. Para escrever em um arquivo, você geralmente cria um objeto `File` e depois usa classes como `FileWriter` ou `BufferedWriter` para escrever dados. Ler de um arquivo é semelhante, usando `File` junto com classes como `FileReader` ou `BufferedReader` para ler o conteúdo do arquivo linha por linha ou como um todo. Essas operações permitem que você persista os dados no disco e os recupere mais tarde.
