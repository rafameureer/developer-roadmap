# Controladores Personalizados

Controladores personalizados no Kubernetes automatizam a gestão de recursos personalizados que não são suportados nativamente pelo Kubernetes. Eles são implementados como controladores do Kubernetes que monitoram recursos personalizados e reagem a mudanças em seu estado. Recursos personalizados são criados estendendo a API do Kubernetes com novos tipos de recurso específicos às necessidades da organização. Controladores personalizados podem ser desenvolvidos usando várias linguagens de programação e frameworks, como o Operator Framework. O Operator Framework fornece ferramentas e práticas recomendadas para desenvolver, testar e implantar controladores personalizados.
