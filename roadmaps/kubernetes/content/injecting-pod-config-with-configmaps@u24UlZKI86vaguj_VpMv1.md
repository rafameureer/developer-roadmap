# ConfigMaps

ConfigMaps são uma maneira de armazenar dados de configuração que podem ser usados por aplicativos em execução na grade. Um ConfigMap é um repositório chave-valor que pode conter dados de configuração como URLs de banco de dados, credenciais, chaves API ou qualquer outro dado de configuração do aplicativo que possa ser usado pelo aplicativo.
