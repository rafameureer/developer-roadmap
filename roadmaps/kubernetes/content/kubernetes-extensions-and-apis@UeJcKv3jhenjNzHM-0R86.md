# Extensões e APIs do Kubernetes

As extensões e APIs do Kubernetes são usadas para personalizar o comportamento do Kubernetes e adicionar novas capacidades ao sistema. As extensões do Kubernetes, incluindo Definições de Recursos Personalizados (CRDs), Controladores Personalizados, Extensores do Agendador Personalizado e APIs de Métricas Personalizadas, aumentam a funcionalidade do Kubernetes. As APIs do Kubernetes são usadas para gerenciar recursos em um cluster do Kubernetes e interagir com o sistema. Juntas, as extensões e APIs do Kubernetes fornecem uma poderosa ferramenta de personalização e extensão do Kubernetes, permitindo aos usuários construir componentes e APIs personalizados que otimizam as operações no Kubernetes.
