# Autorização

A autorização é o processo de determinar se um usuário tem permissão para acessar um recurso específico ou realizar uma ação particular. Ela verifica se um usuário autenticado está permitido fazer o que está tentando dentro de uma aplicação. Isso envolve verificar as funções, permissões e políticas do usuário em relação ao recurso ou ação solicitada.
