# Controladores Básicos

Os controladores são blocos fundamentais em aplicativos web que lidam com solicitações de entrada e orquestram a resposta da aplicação. Eles atuam como intermediários entre a interface do usuário (ou ponto final da API) e os dados e lógica da aplicação. Um controlador recebe uma solicitação, processa-a interagindo com modelos ou outros serviços e, em seguida, retorna uma resposta, como uma exibição, dados JSON ou um redirecionamento.
