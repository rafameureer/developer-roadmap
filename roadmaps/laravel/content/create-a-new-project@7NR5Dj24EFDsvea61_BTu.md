# Criando um Novo Projeto em Laravel

Para iniciar um novo projeto em Laravel, você geralmente usará Composer, uma ferramenta de gerenciamento de dependências para PHP. Abra seu terminal ou prompt de comando, navegue até o diretório onde deseja criar seu projeto e, em seguida, execute o comando `composer create-project laravel/laravel nome-do-seu-projeto`. Substitua `nome-do-seu-projeto` pelo nome desejado para seu projeto. Este comando baixa o Laravel e todas as suas dependências, configura a estrutura básica do projeto e prepara sua aplicação de desenvolvimento.
