# Diretório de Banco de Dados em Projetos Laravel

O diretório `database` em um projeto Laravel abriga todos os arquivos relacionados às interações do seu aplicativo com o banco de dados. Isso inclui migrações, que definem a estrutura das tabelas do seu banco de dados; seeders, que preenchem o banco de dados com dados iniciais; fábricas, que geram dados falsos para testes; e qualquer lógica personalizada relacionada ao banco de dados que você possa implementar. Ele serve como um local central para gerenciar e controlar a versão do esquema do seu banco de dados e dos dados iniciais.

Acesse os seguintes recursos para saber mais:

- [@oficial@Diretório de Banco de Dados](http://laravel.com/docs/structure#the-database-directory)
