# Criptografia & Hash

A criptografia e o hashing são técnicas de segurança fundamentais usadas para proteger dados sensíveis. A criptografia transforma dados em um formato inlegível usando um algoritmo e uma chave, tornando-os indescifráveis para partes não autorizadas; a descriptografia reversa esse processo para restaurar os dados originais. Por outro lado, o hashing cria uma representação fixa de tamanho (hash) de dados, tornando-o adequado para verificar a integridade dos dados e armazenar senhas com segurança, pois o dado original não pode ser recuperado do hash.
