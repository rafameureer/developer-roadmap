# Inertia

O Inertia.js permite que você crie aplicativos de página única (SPAs) usando roteamento e controladores do lado do servidor. Em vez de construir uma API e um frontend separado, o Inertia usa seu framework de lado do servidor existente (como Laravel) para ambos. Ele atinge isso renderizando visões do lado do servidor e depois usando JavaScript para melhorar progressivamente a experiência do usuário, criando um sentimento de SPA sem complexidade do desenvolvimento tradicional de SPAs.
