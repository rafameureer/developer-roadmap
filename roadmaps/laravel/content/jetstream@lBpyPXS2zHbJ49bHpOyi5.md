# Jetstream

Jetstream é um pacote de estruturação para aplicativos Laravel. Ele fornece um ponto de partida robusto para seu próximo projeto Laravel, com funcionalidades-chave como registro do usuário, login, verificação de e-mail, autenticação em duas etapas, gerenciamento de sessão, suporte à API via Laravel Sanctum e gerenciamento de equipes. Está projetado para ser uma solução completa para a construção rápida de aplicativos web modernos com autenticação e recursos comuns já implementados.
