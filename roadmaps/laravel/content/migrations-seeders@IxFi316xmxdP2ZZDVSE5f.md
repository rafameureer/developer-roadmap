# Migrações e Sementes do Banco de Dados

As migrações são como o controle de versão para a estrutura do seu banco de dados, permitindo que você modifique e compartilhe a estrutura do banco de dados de uma maneira estruturada e organizada. As sementes, por outro lado, são usadas para preencher o banco de dados com dados iniciais, como contas de usuário padrão ou categorias, tornando mais fácil começar a trabalhar com sua aplicação. Elas funcionam juntas para garantir uma configuração do banco de dados consistente e reproduzível em diferentes ambientes.
