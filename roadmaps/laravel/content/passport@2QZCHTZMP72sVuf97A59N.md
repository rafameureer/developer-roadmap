# Autenticação de API OAuth 2.0 com Laravel Passport

Passport é uma implementação completa do servidor OAuth 2.0 para sua aplicação Laravel, fornecendo um modo seguro e padrão de autenticação de usuários e concessão de acesso à sua API. Ele permite que os usuários autorizem aplicativos terceiros a acessar seus dados sem compartilhar suas credenciais, usando tokens para representar a autorização. Isso simplifica o processo de construção de APIs que podem ser consumidas por diversos clientes, como aplicativos móveis ou outras aplicações web.
