# Framework de Testes Pest

Pest é um elegante framework de testes PHP com foco em simplicidade e experiência do desenvolvedor. Ele fornece uma sintaxe limpa e expressiva para escrever testes, visando tornar o teste mais agradável e eficiente. Pest se baseia no PHPUnit, aproveitando suas funcionalidades poderosas enquanto oferece uma API mais streamlinhada e intuitiva.
