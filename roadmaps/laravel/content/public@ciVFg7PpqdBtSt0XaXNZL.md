# Diretório Público

O diretório `public` serve como a raiz do documento para sua aplicação Laravel. É o único diretório que deve ser acessível diretamente pela web. Esse diretório contém o arquivo `index.php`, que é o ponto de entrada para todas as solicitações HTTP que entram em sua aplicação, bem como ativos como imagens, CSS e arquivos JavaScript.

Acesse os seguintes recursos para saber mais:

- [@official@O Diretório Público](https://laravel.com/docs/structure#the-public-directory)
