# Query Builder

O Query Builder oferece uma interface conveniente e fluente para criar e executar consultas de banco de dados. Ele permite interagir com o seu banco de dados sem escrever SQL bruto, oferecendo uma maneira mais legível e manterável de realizar operações comuns no banco de dados como seleção, inserção, atualização e exclusão de dados. Ele suporta vários sistemas de banco de dados e protege contra vulnerabilidades de injeção SQL.
