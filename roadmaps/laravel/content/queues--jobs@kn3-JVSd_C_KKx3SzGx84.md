# Filas e Trabalhos

As filas e trabalhos fornecem um mecanismo para adiar o processamento de tarefas demoradas, como enviar e-mails, processar grandes conjuntos de dados ou realizar cálculos complexos, para um tempo posterior. Em vez de executar essas tarefas imediatamente dentro de uma solicitação web, elas são empurradas para uma fila. Um processo trabalhador então recupera e executa esses trabalhos em segundo plano, liberando o servidor web para lidar com solicitações de entrada de forma mais eficiente e melhorando a resposta da aplicação.
