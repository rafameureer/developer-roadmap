# Ligação de Modelo de Rota

A ligação de modelo de rota é uma maneira de injetar automaticamente instâncias de modelos em seus manipuladores de rota com base nos parâmetros da rota. Em vez de consultar manualmente o banco de dados por um modelo dentro do método do controlador usando o ID passado na rota, Laravel pode resolver automaticamente a instância do modelo para você, tornando seu código mais limpo e legível. Isso simplifica o processo de obter dados associados a um modelo específico com base nos parâmetros da rota.
