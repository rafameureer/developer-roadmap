# Diretório de Armazenamento no Laravel

O diretório `storage` no Laravel é onde o framework armazena arquivos gerados durante a execução da aplicação. Isso inclui modelos Blade compilados, sessões baseadas em arquivo, arquivos de cache e logs. Está estruturado em subdiretórios `app`, `framework` e `logs` para organizar esses diferentes tipos de dados. O diretório `app` pode ser usado para armazenar qualquer arquivo gerado pela sua aplicação, enquanto o `framework` é principalmente usado pelo próprio Laravel. O diretório `logs` contém os arquivos de log da aplicação, que são essenciais para a depuração.
