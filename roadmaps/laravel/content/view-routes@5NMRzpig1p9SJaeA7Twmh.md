# Rotas de Exibição

As rotas de exibição oferecem uma maneira simples de retornar uma exibição diretamente de uma rota sem a necessidade de um controlador completo. Em vez de definir um método do controlador para carregar e retornar uma exibição, você pode usar o método `Route::view`. Isso é particularmente útil para rotas simples que só precisam exibir conteúdo estático ou uma exibição básica sem nenhuma lógica complexa. Você especifica a URI, a exibição a ser renderizada e opcionalmente um array de dados a ser passado para a exibição.
