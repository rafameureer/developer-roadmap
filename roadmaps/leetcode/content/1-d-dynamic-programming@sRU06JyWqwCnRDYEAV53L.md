# Programação Dinâmica 1-Dimensional

A programação dinâmica é a técnica de dividir um problema em subproblemas sobrepostos, resolver cada um uma única vez e armazenar o resultado para evitar recálculo. Na programação dinâmica unidimensional, cada estado depende apenas de um número fixo de estados anteriores, então a solução constrói um único array da esquerda para a direita. O primeiro passo sempre é identificar a recorrência: o que a resposta na posição i depende? Os problemas aqui cobrem os padrões de DP centrais que você verá repetidamente: sequências lineares, decisões de mochila e segmentação de strings. Os problemas de DP são notoriamente difíceis de reconhecer, e a única maneira confiável de se tornar melhor em eles é resolver muitos e estudar a estrutura das suas recorrências.
