# 3Sum

Dado um array de inteiros, encontre todos os triplos únicos que somam zero. Você primeiro ordena o array, em seguida para cada elemento usa dois ponteiros para encontrar pares que completam o triplo. A ordenação mais os dois ponteiros traz isso de O(n³) para O(n²). Este problema ensina a você estender a técnica de dois ponteiros além dos pares e introduz como a ordenação habilita uma navegação mais inteligente.
