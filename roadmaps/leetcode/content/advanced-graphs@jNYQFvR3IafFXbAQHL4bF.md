# Grafos Avançados

Problemas de grafos avançados envolvem arestas pesadas, que requerem algoritmos mais sofisticados do que BFS simples ou DFS. O algoritmo de Dijkstra encontra o caminho mais curto em um grafo pesado usando uma min-heap. Os algoritmos de Prim e Kruskal encontram a árvore geradora mínima, conectando todos os nós com custo total mínimo. Esses algoritmos são mais complexos do que qualquer coisa vista até agora, e os problemas aqui muitas vezes combinam o algoritmo com uma restrição adicional, como um limite no número de passos ou uma função de custo não padrão. Entender as condições sob as quais cada algoritmo se aplica é tão importante quanto saber como implementá-lo.
