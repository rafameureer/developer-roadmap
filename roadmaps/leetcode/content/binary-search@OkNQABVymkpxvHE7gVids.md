# Busca Binária

A busca binária não é apenas para encontrar um elemento em uma matriz ordenada. É uma técnica geral para eliminar metade do espaço de pesquisa a cada passo, e ela se aplica sempre que você pode definir uma condição que divida as possíveis respostas em uma metade válida e outra inválida. Os problemas nesta fase vão da versão texto do livro até aplicações criativas: busca em arrays rotacionados e busca binária na própria resposta em vez de no input. Ter a busca binária certa sob pressão, com as condições de limite corretas, é uma habilidade que requer prática deliberada.
