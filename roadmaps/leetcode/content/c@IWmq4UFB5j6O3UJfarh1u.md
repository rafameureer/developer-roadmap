# C++

C++ é a linguagem de escolha para programadores competitivos e é comum em empresas onde desempenho bruto importa, como sistemas, jogos ou negócios de negociação de alta frequência. Ele tem o tempo de execução mais rápido entre todas as linguagens comumente usadas na entrevista e lhe dá acesso direto à biblioteca padrão de modelos, que inclui uma heap, set, map e muitas outras estruturas úteis. O trocadilho é a verbosidade e o overhead de gerenciar memória manualmente em alguns casos. Se você já é proficiente em C++, ele é uma excelente linguagem para entrevistas. Se você está começando do zero, a curva de aprendizado é pronunciada.
