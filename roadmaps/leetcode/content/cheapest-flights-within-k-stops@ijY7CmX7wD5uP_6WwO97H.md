# Menos Custo de Vôos Dentro de K Paradas

Dado um grafo de voos com preços, encontre a rota mais barata do ponto de partida para o destino usando no máximo k paradas. Este é um problema modificado do Dijkstra ou Bellman-Ford onde a restrição está no número de arestas, não apenas no custo total. Este problema ensina como adicionar uma dimensão extra (número de etapas) a um algoritmo de caminho mais curto.
