# Clonar Gráfico

Dado um gráfico não direcionado conectado, retorne uma cópia profunda dele. Você usa DFS ou BFS e um mapa de hash para rastrear quais nós já foram clonados, então você não cria cópias duplicadas quando revisitar os nós. Este problema ensina como lidar com gráficos que têm ciclos durante a travessia, o que requer rastrear os nós visitados desde o início.
