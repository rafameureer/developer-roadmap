# Contagem de Bits

Dada um inteiro n, retorne uma matriz onde cada elemento é o número de bits 1 em sua representação binária de 0 a n. Você pode usar DP: o número de bits em i é igual a um mais os bits em i com seu bit menos significativo removido. Este problema ensina você a combinar manipulação de bits com DP para evitar recalcular tudo do zero para cada número.
