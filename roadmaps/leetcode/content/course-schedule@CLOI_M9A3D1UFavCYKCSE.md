# Cronograma do Curso

Dada uma lista de cursos e pré-requisitos, determine se é possível concluir todos os cursos. Este é um problema de detecção de ciclo em um gráfico direcionado: se qualquer ciclo existir, o cronograma é impossível. Você pode resolver com DFS rastreando nós no caminho atual da recursão. Este problema ensina a pensar na ordenação topológica e é uma ponte para todos os problemas de grafo baseados em dependência.
