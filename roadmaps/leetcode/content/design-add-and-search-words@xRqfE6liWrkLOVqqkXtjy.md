# Estrutura de Dados para Adicionar e Buscar Palavras

Construa uma estrutura de dados que suporte a adição de palavras e a busca por palavras onde um ponto pode corresponder a qualquer letra. Caracteres exatos navegam normalmente pela trie, enquanto um ponto gera uma DFS em todos os nós filhos. Este problema ensina como combinar a navegação na trie com o backtracking para correspondência de curingas.
