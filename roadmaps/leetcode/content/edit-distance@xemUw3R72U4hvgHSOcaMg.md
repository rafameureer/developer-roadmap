# Distância de Edição

Dadas duas strings, encontre o número mínimo de inserções, exclusões ou substituições necessárias para transformar uma em outra. Uma tabela DP bidimensional rastreia o custo de converter cada prefixo da primeira string em cada prefixo da segunda. Este problema ensina a escolha trilhada em cada célula (inserir, excluir, substituir) e é um exemplo fundamental de DP em duas sequências.
