# K Pontos Mais Próximos à Origem

Dada uma lista de pontos, retorne os k mais próximos à origem. Uma heap máxima de tamanho k mantém as k menores distâncias vistas até agora, descartando qualquer ponto mais longe que o atual k-ésimo mais próximo conforme você itera. Este problema mostra como adaptar o padrão top-k a uma comparação personalizada e é bom treinamento para problemas de heap com chaves personalizadas.
