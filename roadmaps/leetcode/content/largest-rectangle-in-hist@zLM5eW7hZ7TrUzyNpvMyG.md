# Retângulo Mais Grande em Histograma

Dado um array de alturas de barras, encontre a área do retângulo mais grande que se encaixa no histograma. Uma pilha monótona rastreia as barras em ordem crescente de altura, e cada vez que uma barra mais curta é encontrada, os retângulos estendidos das barras anteriores são resolvidos. Este é um dos problemas de pilha mais difíceis e ensina a usar uma pilha para resolver cálculos pendentes quando uma condição quebra.
