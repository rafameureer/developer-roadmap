# Mesclar Intervalos

Dada uma lista de intervalos, mesclar todos os que se sobrepõem. Você ordena por hora de início e itera, estendendo o intervalo atual quando o próximo se sobrepõe, ou iniciando um novo quando não faz isso. Este é o problema fundamental de intervalo e ensina que ordenar pela hora de início reduz a verificação de sobreposição para uma única comparação com o final do intervalo anterior.
