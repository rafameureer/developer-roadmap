# Custo Mínimo para Conectar Todos os Pontos

Dada uma lista de pontos, encontre o custo mínimo para conectar todos eles, onde o custo é a distância Manhattan entre dois pontos. Este é um problema de árvore geradora mínima resolvido com o algoritmo de Prim usando uma min-heap, sempre escolhendo a aresta mais barata para um nó não visitado.
