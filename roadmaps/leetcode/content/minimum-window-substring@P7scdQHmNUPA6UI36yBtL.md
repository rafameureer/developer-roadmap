# Menor Substring Contendo Todos os Caracteres

Dadas as strings s e t, encontre a menor substring de s que contenha todos os caracteres de t. Expanda o ponteiro direito até ter uma janela válida, em seguida, reduza do lado esquerdo o máximo possível mantendo-a válida. Este é um dos problemas mais difíceis de janelas deslizantes e ensina a gerenciar um mapa de frequência de caracteres conforme a janela muda.
