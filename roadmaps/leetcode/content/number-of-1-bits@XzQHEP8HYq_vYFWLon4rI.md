# Número de Bits 1

Dado um inteiro de 32 bits, conte quantos bits estão definidos como 1. Você pode verificar o último bit com uma operação AND bitwise e deslocar à direita repetidamente, ou usar a dica n & (n-1) que limpa o bit mais baixo definido, contando até que n se torne zero. Este problema ensina você a inspecionar e limpar bits individuais, uma habilidade fundamental de manipulação de bits.
