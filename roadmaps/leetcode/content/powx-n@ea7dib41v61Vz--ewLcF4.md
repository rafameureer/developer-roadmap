# Pow(x, n)

Implemente a função de potência que eleva x à n-ésima potência, incluindo expoentes negativos, em O(log n). Você usa a exponenciação rápida: ao quadrado a base e dividir o expoente por dois em cada etapa, lidando com expoentes ímpares multiplicando por um fator extra. Este problema ensina backtracking recursivo em uma computação numérica, e é o método padrão para implementar a potência de forma eficiente.
