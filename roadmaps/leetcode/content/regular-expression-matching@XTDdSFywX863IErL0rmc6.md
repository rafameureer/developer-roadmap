# Correspondência de Expressão Regular

Dada uma string e um padrão com curingas de ponto e asterisco, determine se o padrão corresponde à toda a string. Uma tabela DP bidimensional rastreia se cada prefixo da string corresponde a cada prefixo do padrão, com tratamento especial para o operador asterisco. Este é um dos problemas mais difíceis de DP bidimensional e ensina você como lidar com repetição opcional em DP, onde um caractere pode aparecer zero ou mais vezes.
