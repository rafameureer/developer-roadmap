# Busca em Array Rotacionado

Um array ordenado foi rotacionado em um índice desconhecido. Encontre um valor-alvo em O(log n). A cada passo, uma das duas metades deve estar ordenada, e você pode usar isso para decidir qual metade procurar. Este problema ensina a aplicar busca binária mesmo quando a entrada não está perfeitamente ordenada, adicionando uma condição para identificar a metade ordenada.
