# Two Sum II

Dado um array ordenado, encontre dois números que somam um valor-alvo e devolva suas posições. Como o array está ordenado, você pode usar dois ponteiros a partir de cada extremidade e movê-los com base em se a soma atual for muito grande ou muito pequena. É aqui onde o padrão two pointers clica para a maioria dos aprendizes, pois a ordem ordenada dá uma regra clara sobre qual ponteiro mover.
