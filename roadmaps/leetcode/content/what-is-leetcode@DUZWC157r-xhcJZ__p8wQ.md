# O que é LeetCode

LeetCode é uma plataforma online com centenas de problemas de codificação usados por engenheiros de software para se prepararem para entrevistas técnicas. Empresas como Google, Meta, Amazon e Microsoft usam problemas semelhantes em seu processo de contratação para avaliar como os candidatos pensam em desafios algorítmicos. Você não precisa resolver milhares de problemas para estar pronto. O que importa é entender bem o padrão por trás dos problemas para aplicá-los a aqueles que você nunca viu antes. LeetCode é o terreno de treinamento, não o objetivo.

Acesse os seguintes recursos para saber mais:

- [@oficial@LeetCode](https://leetcode.com/)
