# Quebra de Palavras

Dada uma string e um dicionário de palavras, determine se a string pode ser segmentada em uma sequência de palavras do dicionário. Você usa DP onde cada posição armazena se a substring até esse ponto pode ser formada, verificando todas as possíveis últimas palavras. Este problema ensina como usar um array booleano DP para rastrear a alcançabilidade, um padrão que aparece em muitos problemas de segmentação de string.
