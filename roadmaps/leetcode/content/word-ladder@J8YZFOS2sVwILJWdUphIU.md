# Ladder de Palavras

Dada uma palavra inicial e uma palavra final, encontre a sequência de transformação mais curta onde cada passo muda exatamente uma letra e toda palavra intermediária deve existir em uma lista de palavras dadas. BFS dá o caminho mais curto, e os vizinhos de cada palavra são encontrados substituindo cada caractere por todas as letras. Este é o problema de gráfico mais difícil nesta fase e ensina a modelar um problema abstrato como um problema de gráfico de caminho mais curto.
