# Adicionando Discos

Adicionar discos em Linux envolve particionamento, criação de sistemas de arquivos e montagem. Use `lsblk` para listar dispositivos, `fdisk /dev/sdX` para criar partições, `mkfs.ext4 /dev/sdX1` para criar sistemas de arquivos e `mount /dev/sdX1 /ponto/montagem` para montar. Esse processo prepara novos dispositivos de armazenamento para uma integração suave na hierarquia do sistema de arquivos Linux.
