# Arquivamento e Compactação

Arquivar agrupa vários arquivos em um único arquivo, geralmente usando `tar`, enquanto compactar reduz o tamanho desse arquivo usando ferramentas como `gzip` ou `bzip2`. Um padrão comum combina ambos os passos de uma só vez, como `tar -czvf archive.tar.gz folder/`, que arquiva e compacta uma pasta em um único comando. Essas ferramentas são amplamente utilizadas para backups, transferência de múltiplos arquivos como um único arquivo e distribuição de pacotes de software.
