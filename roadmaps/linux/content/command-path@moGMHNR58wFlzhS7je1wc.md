# Caminho do Comando no Shell

O caminho do comando é uma variável usada pelo shell para determinar onde procurar pelos arquivos executáveis para executá-los. Os comandos Linux são nada mais que programas residindo em diretórios específicos. Mas, não há necessidade de navegar nesses diretórios toda vez para executar esses programas. O caminho do comando vem à rescate!
