# Discos e Sistemas de Arquivos

O Linux usa vários sistemas de arquivos para organizar, armazenar e recuperar dados de dispositivos de armazenamento. Sistemas de arquivos populares incluem EXT4 (robusto para volumes do Linux), FAT32 (compatível com todos os SO para mídias removíveis), NTFS e Btrfs. Cada um tem vantagens específicas e casos de uso. Use o comando `df -T` para exibir tipos de sistema de arquivos, uso de espaço em disco e informações sobre dispositivos montados.
