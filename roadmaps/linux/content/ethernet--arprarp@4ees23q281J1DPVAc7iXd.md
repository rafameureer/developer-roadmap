# Ethernet, ARP e RARP

Três componentes de rede Linux cruciais: o Ethernet permite a comunicação entre dispositivos da LAN, o ARP (Protocolo de Resolução de Endereços) traduz endereços IP em endereços MAC para comunicação direta na rede, e o RARP (Reverse ARP) converte endereços MAC em endereços IP quando os dispositivos sabem seus endereços MAC mas precisam de seus IPs. Essencial para diagnosticar e gerenciar problemas de rede Linux.
