# NL (Number Lines)

O comando `nl` numeriza linhas em arquivos de texto, fornecendo uma visão da localização das linhas. Por padrão, ele numera apenas linhas não-vazias, mas esse comportamento pode ser modificado. Sintaxe: `nl [opções] [nome_do_arquivo]`. Se nenhum arquivo for especificado, o nl lê de stdin. Valioso para processamento de texto quando números de linha são necessários para referência ou depuração.
