# Gestão de Serviços

A gestão de serviços controla os serviços (daemon) do Linux durante os processos de inicialização e desligamento. Comandos comuns do systemctl incluem start, stop, restart, reload, status, enable/disable. O sistema moderno Linux usa o systemd enquanto sistemas mais antigos usam SystemV ou Upstart. Exemplo: `sudo systemctl start sshd` inicia o serviço SSH. Habilidade essencial para administradores de sistemas Linux e manutenção de sistemas seguros e estáveis.
