# Programação em Shell

Programação em shell (scripting) automatiza tarefas administrativas, operações repetitivas e monitoramento de sistemas no Linux. Bash é o shell padrão e linguagem de script em maioria das distribuições. Os scripts são arquivos de texto executados pelo shell, excelentes para automação do sistema. Exemplo: `#!/bin/bash echo "Hello, World!"` cria um simples script que imprime saída no terminal.
