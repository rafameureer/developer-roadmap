# Snap

O Snap é um sistema de gerenciamento de pacotes moderno do Linux criado pela Canonical, que fornece pacotes autônomos com todas as dependências incluídas. Os Snaps funcionam consistentemente em diferentes distribuições do Linux, podem ser instalados a partir da loja Snapcraft e atualizam automaticamente. As atualizações são transacionais e têm rollback automático em caso de falha. Instale pacotes usando o comando `sudo snap install [nome-do-pacote]`.
