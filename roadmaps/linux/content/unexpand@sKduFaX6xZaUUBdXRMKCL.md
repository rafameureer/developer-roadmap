# Unexpand

O comando `unexpand` converte espaços em tabulações em arquivos de texto, tornando os documentos mais coesos e organizados. Comumente usado em scripts de programação onde a indentação com tabulação é preferida. Use `unexpand -t 4 file.txt` para substituir cada quatro espaços por uma tabulação. O oposto do comando `expand`, útil para padronizar o formato de indentação em arquivos de código.
