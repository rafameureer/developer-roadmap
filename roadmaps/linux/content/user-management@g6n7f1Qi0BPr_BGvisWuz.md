# Gerenciamento de Usuários

O gerenciamento de usuários no Linux permite que múltiplos usuários interajam com o sistema de forma independente. Inclui a criação, exclusão, modificação de usuários e grupos, atribuição de permissões e propriedade. Comandos-chave: `adduser`/`useradd` cria usuários, `deluser`/`userdel` remove usuários, `passwd` gerencia senhas, `su` alterna entre usuários. Essencial para fornecer acesso adequado e manter a segurança do sistema Linux.
