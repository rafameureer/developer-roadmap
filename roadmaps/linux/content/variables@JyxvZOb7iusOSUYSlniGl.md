# Variáveis

As variáveis de shell armazenam dados do sistema ou definidos pelo usuário que podem mudar durante a execução de scripts. Existem duas categorias: Variáveis do Sistema (PATH, HOME, PWD) criadas pelo Linux e Variáveis Definidas pelo Usuário criadas pelos usuários. Defina variáveis com o operador `=` e recupere valores com o prefixo `$`. Exemplo: `MY_VARIABLE="Hello World"` então `echo $MY_VARIABLE` imprime o valor.
