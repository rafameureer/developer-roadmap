# Mecanismos de Atenção

Desenvolvidos por pesquisadores da Google, os mecanismos de atenção permitem que uma rede neural se concentre nas partes mais relevantes dos dados de entrada ao fazer previsões. Em vez de processar toda a entrada uniformemente, os mecanismos de atenção atribuem pesos a diferentes partes da entrada, indicando sua importância. Esses pesos são então usados para criar uma média ponderada da entrada, que é usada para o processamento subsequente. Isso permite que o modelo selecioneivamente atenda às partes mais informativas da entrada, melhorando desempenho, especialmente em tarefas envolvendo dados sequenciais como texto ou imagens.
