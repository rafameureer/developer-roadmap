# Conceitos Básicos de Probabilidade

A probabilidade é uma maneira de quantificar a possibilidade de um evento ocorrer. Ela fornece uma medida numérica, variando de 0 a 1, representando a chance de um resultado específico acontecer. Uma probabilidade de 0 indica impossibilidade, enquanto uma probabilidade de 1 significa certeza. Entender probabilidade envolve conceitos como variáveis aleatórias, distribuições de probabilidade e eventos, que são essenciais para fazer previsões e decisões em ambientes de incerteza.
