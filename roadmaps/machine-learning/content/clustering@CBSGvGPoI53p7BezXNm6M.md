# Agrupamento

O agrupamento é uma maneira de agrupar automaticamente pontos de dados semelhantes juntos. Imagine que você tenha uma série de objetos espalhados e quer organizá-los em pilhas com base em quão semelhantes eles são. Algoritmos de agrupamento fazem isso encontrando padrões nos dados, agrupando pontos de dados que estão próximos uns dos outros de alguma forma e separando-os dos pontos de dados mais distantes. O algoritmo decide qual ponto de dados pertence a qual grupo, sem você dizer a ele quais grupos devem ser.
