# Condições

As instruções condicionais em Python permitem que você execute diferentes blocos de código com base em uma condição específica sendo verdadeira ou falsa. As instruções condicionais mais comuns são `if`, `elif` (else if) e `else`. Uma declaração `if` verifica uma condição, e se for verdadeira, o bloco de código abaixo dela é executado. O `elif` permite que você verifique condições adicionais se a condição inicial do `if` for falsa. Finalmente, o `else` fornece um bloco de código para executar se nenhuma das condições anteriores (`if` ou `elif`) for verdadeira. Essas instruções permitem que os programas tomem decisões e respondam de maneiras diferentes a várias entradas ou situações.
