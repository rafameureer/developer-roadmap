# Formatos de Dados

Os formatos de dados definem a estrutura em que os dados são organizados e armazenados. Esses formatos determinam como as informações são codificadas, permitindo que computadores interpretem e processem efetivamente essas informações. Exemplos comuns incluem CSV (Valores Separados por Vírgula) para dados tabulares, JSON (Notação de Objeto JavaScript) para dados estruturados com pares chave-valor, e formatos de imagem como JPEG e PNG para dados visuais. A escolha do formato de dados afeta a eficiência de armazenamento, acessibilidade dos dados e compatibilidade com diferentes ferramentas e algoritmos de aprendizado de máquina.
