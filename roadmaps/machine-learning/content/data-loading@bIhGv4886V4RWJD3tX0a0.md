# Carregamento de Dados no Scikit-learn

Carregamento de dados no Scikit-learn refere-se ao processo de importar conjuntos de dados em um formato que possa ser usado para tarefas de aprendizado de máquina. Isso envolve ler dados de várias fontes, como arquivos CSV, bancos de dados ou até mesmo diretamente de arrays NumPy, e estruturar esses dados em um formato que os algoritmos do Scikit-learn possam entender, geralmente arrays NumPy ou DataFrames Pandas. Os dados carregados são então normalmente divididos em recursos (variáveis independentes) e uma variável-alvo (variável dependente) para treinamento e avaliação de modelos de aprendizado de máquina.
