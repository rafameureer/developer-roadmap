# Escalação de Atributos & Normalização

A escalação de atributos é uma técnica de pré-processamento em aprendizado de máquina que transforma os atributos numéricos para uma escala comum, garantindo que eles contribuam igualmente ao modelo, evitando que os atributos com maiores intervalos dominejam, o que é particularmente importante para algoritmos sensíveis à escala dos atributos como métodos baseados em descida de gradiente. Métodos-chave incluem a Standardização (transformando dados para uma média de 0 e um desvio padrão de 1, geralmente melhor para outliers) e Normalização (escalando dados para um intervalo fixo, geralmente entre 0 e 1).
