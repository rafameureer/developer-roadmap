# Validação Cruzada K-Fold

A Validação Cruzada K-Fold é uma técnica usada para avaliar como bem um modelo de aprendizado de máquina se generalizará a um conjunto de dados independente. Ela funciona dividindo os dados disponíveis em _k_ conjuntos ou subconjuntos de igual tamanho. O modelo é então treinado _k_ vezes, cada vez usando _k-1_ conjuntos como o conjunto de treinamento e o conjunto restante como o conjunto de validação. As métricas de desempenho de cada uma das _k_ iterações são então médias para fornecer uma estimativa geral do desempenho do modelo.
