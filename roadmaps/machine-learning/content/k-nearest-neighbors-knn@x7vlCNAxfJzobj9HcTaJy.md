# K-Nearest Neighbors (KNN)

O K-Nearest Neighbors (KNN) é um algoritmo simples usado para classificar pontos de dados com base em sua proximidade a outros pontos de dados. Dado um novo, não-classificado ponto de dados, o KNN identifica os 'K' pontos de dados mais próximos (vizinhos) do conjunto de dados de treinamento. A classe que aparece com mais frequência entre esses 'K' vizinhos é então atribuída como a classe do novo ponto de dados.
