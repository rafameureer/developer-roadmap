# Regressão Linear

A regressão linear é um método simples usado para encontrar a melhor linha reta que descreve a relação entre uma variável dependente (a que você está tentando prever) e uma ou mais variáveis independentes (as que você está usando para fazer a previsão). Funciona encontrando a linha que minimiza a soma dos quadrados das diferenças entre os valores reais e os valores previstos pela linha. Esta linha pode então ser usada para prever a variável dependente para novos valores da variável independente.
