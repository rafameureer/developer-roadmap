# Outros Formatos de Dados

Além dos formatos comuns como CSV, Excel, JSON e Parquet, os dados podem existir em uma variedade de outras estruturas. Isso inclui formatos otimizados para aplicativos específicos ou tipos de dados. Por exemplo, imagens são frequentemente armazenadas como JPEGs ou PNGs, enquanto dados de áudio podem estar no formato WAV ou MP3. Bancos de dados relacionais armazenam dados em tabelas estruturadas acessíveis através do SQL. Além disso, formatos especializados como HDF5 são usados para conjuntos de dados grandes e complexos, especialmente em computação científica, e Protocol Buffers oferecem uma maneira eficiente de serializar dados estruturados. Os dados também podem ser não estruturados, existindo como texto plano, arquivos de log ou até mesmo dados em streaming provenientes de sensores.
