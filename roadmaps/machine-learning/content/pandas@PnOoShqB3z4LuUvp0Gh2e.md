# Pandas

Pandas é uma biblioteca escrita para o idioma de programação Python para manipulação e análise de dados. Em particular, oferece estruturas de dados e operações para manipular tabelas numéricas e séries temporais.

Acesse os seguintes recursos para saber mais:

- [@oficial@pandas - Biblioteca de Análise de Dados do Python](https://pandas.pydata.org/)
- [@vídeo@Tutorial Completo de Pandas em Ciência de Dados com Python! (Edição Atualizada de 2025)](https://www.youtube.com/watch?v=2uvysYbKdjM)
