# Regressão Polinomial

A regressão polinomial é um tipo de algoritmo de aprendizado supervisionado usado quando a relação entre as características de entrada e a variável de saída é não-linear. Em vez de ajustar uma linha reta, ele ajusta uma equação polinomial aos dados. Isso permite que o modelo capture curvas e relações mais complexas, potencialmente levando a melhores previsões quando um modelo linear é insuficiente. O grau do polinômio determina a complexidade da curva que pode ser ajustada.
