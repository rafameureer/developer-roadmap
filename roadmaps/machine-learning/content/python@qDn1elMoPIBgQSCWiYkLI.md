# Python

Python é um linguagem de programação interpretada, de alto nível e de propósito geral. Sua filosofia de design enfatiza a legibilidade do código com seu uso significativo da indentação. Suas construções de linguagem, assim como seu abordagem orientada a objetos, têm como objetivo ajudar os programadores a escrever código claro e lógico para projetos pequenos e grandes. Python é dinamicamente tipado e coletor de lixo. Ele suporta múltiplos paradigmas de programação, incluindo estruturados (especialmente, procedimentais), orientados a objetos e funcional. Python é frequentemente descrito como uma "linguagem com baterias inclusas" devido à sua biblioteca padrão abrangente.
