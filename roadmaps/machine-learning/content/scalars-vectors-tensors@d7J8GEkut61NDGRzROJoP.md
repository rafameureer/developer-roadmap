# Escalares, Vetores e Tensores

Escalares, vetores e tensores são blocos fundamentais para representar dados na aprendizagem de máquina. Um escalar é um único valor numérico, como uma leitura de temperatura. Um vetor é uma array ordenada de números, representando um ponto no espaço ou um conjunto de características para uma única instância de dados. Um tensor é uma generalização de vetores e matrizes para dimensões mais altas; pode ser pensado como um array multidimensional, útil para representar imagens, vídeos ou conjuntos de dados complexos com várias características e relações.
