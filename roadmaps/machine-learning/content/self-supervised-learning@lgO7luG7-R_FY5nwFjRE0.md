# Aprendizagem Autossuficiente

A aprendizagem autossuficiente é um tipo de aprendizado de máquina onde o modelo aprende com dados não rotulados criando seus próprios sinalizadores supervisórios. Isso é feito ocultando partes dos dados de entrada e treinando o modelo para prever as partes ocultas com base nos dados restantes. Em essência, os próprios dados fornecem rótulos, permitindo que o modelo aprenda representações úteis sem a necessidade de anotação humana explícita.
