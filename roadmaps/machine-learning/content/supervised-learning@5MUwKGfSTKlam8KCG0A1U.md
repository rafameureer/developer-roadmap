# Aprendizagem Supervisionada

A aprendizagem supervisionada é um tipo de aprendizado de máquina onde um algoritmo aprende de um conjunto de dados rotulado. Isso significa que cada ponto de dados no conjunto está associado a uma saída correta correspondente, ou "rótulo". O objetivo do algoritmo é aprender uma função que mapeia entradas para saídas, de modo que quando for fornecido novos, não vistos, entradas, ele possa prever a saída correta com base nos padrões aprendidos dos dados rotulados.
