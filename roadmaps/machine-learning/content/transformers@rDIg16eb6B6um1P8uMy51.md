# Transformadores

Transformadores são uma arquitetura de rede neural que dependem de mecanismos de atenção para pesar a importância de diferentes partes dos dados de entrada. Diferentemente das redes neurais recorrentes (RNNs) que processam os dados em sequência, os transformadores podem processar todo o conjunto de dados de uma vez, permitindo paralelização e capturando dependências a longo prazo de forma mais eficaz. Essa arquitetura é particularmente adequada para tarefas envolvendo dados sequenciais, como o processamento de linguagem natural, onde entender o contexto das palavras dentro de uma frase é crucial.
