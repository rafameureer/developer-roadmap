# Aprendizado Não Supervisionado

O aprendizado não supervisionado é um tipo de aprendizado de máquina onde o algoritmo aprende padrões a partir de dados não rotulados. Diferentemente do aprendizado supervisionado, não há respostas corretas pré-definidas ou variáveis-alvo fornecidas para guiar o processo de aprendizagem. Em vez disso, o algoritmo explora os dados para descobrir estruturas ocultas, relações e agrupamentos por conta própria. Tarefas comuns no aprendizado não supervisionado incluem clustering, redução de dimensionalidade e detecção de anomalias.
