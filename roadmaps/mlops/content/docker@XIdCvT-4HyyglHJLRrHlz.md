# Docker

Docker é uma plataforma que usa a virtualização de nível do sistema operacional para entregar software em pacotes chamados contêineres. Esses contêineres isolam o software de seu ambiente e garantem que ele funcione uniformemente, independentemente das diferenças entre os ambientes de desenvolvimento e produção. O Docker simplifica o processo de construção, envio e execução de aplicativos empacotando todas as dependências, bibliotecas e configurações em uma única unidade.
