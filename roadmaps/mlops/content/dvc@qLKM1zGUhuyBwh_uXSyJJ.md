# DVC

DVC (Data Version Control) é uma ferramenta de código aberto projetada para trazer princípios de controle de versão para projetos de aprendizagem automática, especificamente para dados e modelos. Ele estende as capacidades do Git para lidar com arquivos grandes, conjuntos de dados e modelos de aprendizado de máquina, que geralmente não são bem-sucedidos em sistemas de controle de versão tradicionais. O DVC rastreia alterações em dados e modelos, permitindo que você reproduza experimentos, reverter para versões anteriores e colaborar efetivamente em projetos baseados em dados.
