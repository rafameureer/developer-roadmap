# GitHub

GitHub é uma plataforma baseada na web construída sobre o Git que oferece controle de versão, ferramentas de colaboração e recursos de gerenciamento de projetos para desenvolvimento de software. Ele permite que os desenvolvedores hospedem repositórios Git, colaborem no código através de solicitações de pull e revisem e rastreiem alterações. GitHub também oferece funcionalidades adicionais como controle de problemas, integração contínua, fluxos de trabalho automatizados e hospedagem de documentação. Com seu ambiente de codificação social, o GitHub promove contribuições open source e colaboração em equipe, tornando-se um centro de muitos projetos de desenvolvimento de software.
