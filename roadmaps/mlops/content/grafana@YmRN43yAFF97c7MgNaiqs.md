# Grafana

Grafana é uma ferramenta de visualização e monitoramento de dados de código aberto. Ele permite que os usuários consultem, visualizem, alertem sobre e explorem métricas, logs e rastreamentos. O Grafana se conecta a várias fontes de dados, como Prometheus, Graphite, Elasticsearch e InfluxDB, para criar painéis personalizáveis que exibem dados em tempo real e tendências históricas.
