# SHAP

SHAP (SHapley Additive exPlanations) é um método usado para explicar a saída de qualquer modelo de aprendizado de máquina. Ele usa conceitos do teorema dos jogos para atribuir a cada recurso um valor representando sua contribuição para a previsão. Esses valores, conhecidos como SHAP values, indicam o grau em que cada recurso contribuiu para a saída do modelo para uma instância específica, facilitando uma compreensão mais profunda do processo de tomada de decisão do modelo.
