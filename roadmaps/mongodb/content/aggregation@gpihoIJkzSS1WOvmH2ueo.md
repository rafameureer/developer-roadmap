# Agregação

A agregação no MongoDB é um poderoso framework para o processamento e transformação de dados usando uma pipeline de etapas. Cada etapa realiza operações específicas como filtragem, agrupamento, classificação ou cálculo de valores, permitindo análises complexas de dados e relatórios. A pipeline de agregação oferece operadores para cálculos matemáticos, manipulação de strings, operações com datas e transformações avançadas de dados.
