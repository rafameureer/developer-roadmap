# Tipo Double

O tipo de dados Double no MongoDB armazena números de ponto flutuante de 64 bits conforme o padrão IEEE 754, fornecendo alta precisão para cálculos decimais. É o tipo numérico padrão para números JavaScript e lida com inteiros e decimais. Os Doubles suportam operações matemáticas em consultas e pipelines de agregação, embora limitações de precisão possam ocorrer com números muito grandes ou cálculos repetidos que requerem representação exata decimal.
