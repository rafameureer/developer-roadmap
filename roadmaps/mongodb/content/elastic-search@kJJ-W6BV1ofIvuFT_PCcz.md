# Elasticsearch

O conector do MongoDB para Elasticsearch habilita uma integração suave entre o MongoDB e o Elasticsearch, permitindo que você sincronize automaticamente dados de coleções do MongoDB para índices do Elasticsearch para capacidades de pesquisa de texto completo poderosas, análise e visualização. Este conector transmite alterações de dados em tempo real usando as streams de mudança do MongoDB, transforma documentos conforme necessário e mantém a consistência dos dados entre os dois sistemas, tornando-o ideal para aplicativos que precisam tanto da armazenamento flexível de documentos do MongoDB quanto das funcionalidades avançadas de pesquisa e agregação do Elasticsearch. Ele é especialmente útil para construir aplicativos pesados em busca, sistemas de análise de logs e painéis de inteligência empresarial que exigem capacidades complexas de pesquisa de texto, busca faceta e análise de dados em tempo real.
