# Objetos e Arrays Aninhados

Os objetos e arrays aninhados no MongoDB permitem armazenar dados relacionados em um único documento, eliminando a necessidade de coleções separadas e junções. Este padrão de design melhora o desempenho das consultas e mantém a localização dos dados. Estruturas aninhadas suportam consultas aninhadas, operações de array e relações de dados complexas enquanto mantêm a atomicidade do documento e permitem a recuperação eficiente de entidades completas.
