# $eq

O operador `$eq` no MongoDB corresponde a documentos onde o valor de um campo é igual a um valor especificado. Ele realiza uma comparação de igualdade exata e é o comportamento padrão ao usar a sintaxe campo: valor. O `$eq` suporta todos os tipos de dados BSON, incluindo documentos e arrays aninhados, permitindo correspondências precisas em consultas. É fundamental para filtrar documentos por valores específicos de campo em operações de busca.
