# Índices Geoespaciais

Os índices geoespaciais no MongoDB permitem a consulta eficiente de dados de coordenadas geográficas usando os tipos de índice 2d, 2dsphere e geoHaystack. Eles suportam consultas baseadas em localização como encontrar pontos dentro de uma distância específica, interseção de polígonos e buscas de vizinhos mais próximos. Esses índices funcionam com objetos GeoJSON e pares de coordenadas legados para aplicativos de mapeamento e serviços de localização.
