# Int32

O tipo de dados Int32 no MongoDB armazena inteiros assinados de 32 bits, variando de -2.147.483.648 a 2.147.483.647. Esse tipo fornece representação exata de inteiros sem problemas de precisão de ponto flutuante e ocupa menos espaço de armazenamento do que os doubles. O Int32 é ideal para contadores, IDs e números inteiros onde a precisão é crítica e o intervalo de valores se encaixa dentro dos limites de 32 bits.
