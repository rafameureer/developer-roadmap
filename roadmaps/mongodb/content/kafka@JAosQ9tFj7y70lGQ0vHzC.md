# Kafka

Apache Kafka é uma plataforma de streaming de eventos distribuída projetada para alta taxa de transferência, tolerância a falhas e escalabilidade em fluxos de dados. Ele é principalmente usado para construir pipelines de dados em tempo real e aplicativos de streaming. O Kafka permite que você publique e se inscreva em fluxos de registros, armazene esses registros de forma resiliente e processe-os em tempo real.
