# Básicos do MongoDB

O MongoDB é um popular banco de dados NoSQL projetado para armazenar e gerenciar grandes volumes de dados não estruturados ou semi-estruturados. Diferentemente dos bancos de dados relacionais tradicionais que usam tabelas e linhas, o MongoDB usa um modelo de dados orientado a documentos, onde os dados são armazenados em documentos flexíveis, semelhantes ao JSON, chamados BSON (Binary JSON). Isso permite um esquema dinâmico, o que significa que os documentos dentro da mesma coleção podem ter estruturas diferentes, tornando mais fácil adaptar-se a requisitos de dados em mudança. O MongoDB suporta capacidades de consulta ricas, incluindo filtragem, classificação e agregação, permitindo aos desenvolvedores realizar consultas complexas eficientemente.
