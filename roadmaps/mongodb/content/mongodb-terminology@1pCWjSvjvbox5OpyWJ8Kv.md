# Terminologia do MongoDB

A terminologia do MongoDB inclui conceitos-chave: os bancos de dados contêm coleções (equivalente a tabelas), que armazenam documentos (equivalente a linhas) compostos por pares campo-valor. Outros termos incluem índices para otimização de desempenho, conjuntos de réplicas para alta disponibilidade, fragmentação para escalabilidade horizontal, pipelines de agregação para processamento de dados e ObjectIds para identificadores únicos de documentos. Compreender esses termos é fundamental para o desenvolvimento do MongoDB.
