# $or

O operador `$or` no MongoDB realiza uma operação lógica OR em múltiplas expressões de consulta, retornando documentos que atendam a pelo menos uma das condições especificadas. Ele aceita um array de expressões de consulta e permite critérios de correspondência alternativos. O `$or` é essencial para consultas flexíveis quando os documentos podem corresponder a qualquer uma de várias condições ou combinações de campos.
