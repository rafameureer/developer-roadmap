# $project

A etapa `$project` nos pipelines de agregação do MongoDB é usada para reformatar documentos, incluindo, excluindo ou transformando campos, permitindo que você controle exatamente quais dados são passados para as etapas subsequentes do pipeline. Ela pode realizar a seleção de campos (análogo ao `SELECT` do SQL), criar campos computados usando expressões, renomear campos, estruturar ou desestruturar as estruturas de documentos e aplicar várias transformações como operações matemáticas, manipulações de strings ou formatação de data.

Acesse os seguintes recursos para saber mais:

- [@oficial@Pipeline de Agregação](https://www.mongodb.com/docs/manual/core/aggregation-pipeline/)
- [@oficial@$project](https://www.mongodb.com/docs/manual/reference/operator/aggregation/project/)
