# Consistência de Leitura e Escrita

A consistência de leitura e escrita no MongoDB controla a consistência dos dados e os níveis de reconhecimento para operações. As preocupações de escrita especificam requisitos de reconhecimento dos membros do conjunto réplica, enquanto as preocupações de leitura determinam garantias de consistência dos dados para consultas. As opções variam desde escritas não reconhecidas até confirmação pela maioria, e de leituras locais até leituras causalemmente consistentes, equilibrando o desempenho com os requisitos de confiabilidade dos dados.
