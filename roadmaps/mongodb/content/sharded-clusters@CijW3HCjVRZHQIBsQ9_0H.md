# Clusters Fragmentados

Os Clusters Fragmentados permitem o escalonamento horizontal distribuindo os dados em vários servidores com base em uma chave de fragmentação. O MongoDB particiona automaticamente as coleções e equilibra a distribuição dos dados entre os fragmentos, permitindo que os bancos de dados lidem com conjuntos de dados massivos e cargas de trabalho de alta taxa de transferência. A fragmentação inclui servidores de configuração para gerenciamento de metadados e roteadores mongos para a distribuição de consultas no cluster.
