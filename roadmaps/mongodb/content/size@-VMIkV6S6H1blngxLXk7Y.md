# $size

O operador `$size` no MongoDB corresponde a documentos onde um campo de array tem exatamente o número especificado de elementos. Ele funciona apenas com arrays e requer uma correspondência exata, não consultas de faixa. O `$size` é útil para validar comprimentos de arrays, filtrar documentos por dimensões de array e garantir a consistência dos dados em estruturas de documento baseadas em arrays.
