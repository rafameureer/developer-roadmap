# Spark

Spark refere-se à integração do Apache Spark, um poderoso motor de processamento de dados, com o MongoDB, um banco de dados NoSQL. Essa integração permite que os usuários realizem análises e processamento de dados em tempo real no MongoDB usando as capacidades do Spark, permitindo a manipulação e análise eficientes dos dados sem a necessidade de processos ETL extensos.

Acesse os seguintes recursos para saber mais:

- [@official@Apache Spark™ - Motor Unificado para Análise de Dados em Escala](https://spark.apache.org/?ref=producthunt)
- [@official@Conector do MongoDB para Spark](https://www.mongodb.com/docs/spark-connector/current/)
