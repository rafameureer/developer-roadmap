# update() e Métodos Relacionados

Operações de atualização modificam documentos existentes usando os métodos `updateOne()`, `updateMany()` e `replaceOne()` com operadores de atualização como `$set`, `$unset`, `$inc` e `$push`. Esses métodos suportam operações upsert, modificações de arrays, atualizações de campos e operações atômicas. Recursos avançados incluem `findOneAndUpdate()` para operações de leitura-modificação-gravação atômica e pipelines de atualização para transformações complexas usando operadores de agregação.
