# APIs

Uma API (Interface de Programação de Aplicativos) é uma interface padrão que permite que aplicativos de software e ferramentas de automação comuniquem-se com dispositivos de rede e serviços programaticamente, sem a necessidade de um usuário digitar comandos manualmente em uma CLI. Na engenharia de redes, as APIs são a base da automação moderna: quando um script Python configura um roteador, quando o Ansible envia uma alteração para um roteador ou quando o Terraform cria uma rede na nuvem, todos estão se comunicando com dispositivos e plataformas por trás de uma API.
