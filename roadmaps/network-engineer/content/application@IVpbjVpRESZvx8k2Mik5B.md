# Aplicação

A Camada de Aplicação é a sétima e camada superior do modelo OSI, onde o software do usuário interage com a rede. Ela fornece serviços de rede diretamente para aplicativos, habilitando funções como navegação na web, email, transferência de arquivos e resolução de nomes de domínio. Protocolos como HTTP, FTP, SMTP e DNS todos operam nesta camada.
