# CIDR

CIDR, ou Classless Inter-Domain Routing, é um método de alocação de endereços IP e roteamento que substituiu o sistema mais antigo baseado em classes. Em vez de classes fixas (A, B, C), CIDR usa uma notação com barra (ex: 192.168.1.0/24) para indicar quantos bits são usados para a parte da rede do endereço. Isso permite um uso mais flexível e eficiente do espaço de endereços IP e é o método padrão usado em redes modernas.
