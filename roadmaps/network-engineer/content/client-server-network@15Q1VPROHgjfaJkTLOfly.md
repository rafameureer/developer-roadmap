# Rede Cliente-Servidor

Uma rede cliente-servidor é um modelo onde um ou mais servidores centrais fornecem recursos ou serviços, e múltiplos dispositivos clientes solicitam e consomem esses recursos. O servidor gerencia os recursos compartilhados como arquivos, bancos de dados ou aplicativos, enquanto os clientes interagem com eles através da rede. Esse modelo é amplamente utilizado em ambientes corporativos porque centraliza a gestão, melhora a segurança e torna mais fácil escalar.
