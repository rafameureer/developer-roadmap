# Camada de Dados

A Camada de Dados é a segunda camada do modelo OSI, responsável por transferência de dados entre nós e detecção de erros em um único segmento de rede. Ela organiza bits crus da Camada Física em quadros e usa endereços MAC para identificar dispositivos na rede local. Esta camada é dividida em duas subcamadas: o Controle de Link Lógico (LLC) e o Controle de Acesso à Mídia (MAC).
