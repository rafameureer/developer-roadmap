# DHCP

DHCP, ou Protocolo de Configuração Dinâmica de Hosts (Dynamic Host Configuration Protocol), é um protocolo de gerenciamento de rede que atribui automaticamente endereços IP e outros parâmetros de configuração da rede a dispositivos quando eles se juntam à rede. Sem DHCP, administradores precisariam configurar manualmente o endereço IP, máscara de sub-rede, gateway e configurações DNS em cada dispositivo. O DHCP simplifica o gerenciamento da rede lidando com essas atribuições dinamicamente a partir de um servidor ou roteador central.
