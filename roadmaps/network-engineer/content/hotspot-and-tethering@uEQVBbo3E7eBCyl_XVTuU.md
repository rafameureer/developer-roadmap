# Hotspot e Tethering

Um hotspot é um local físico ou dispositivo que fornece acesso à Internet sem fio a outros dispositivos, geralmente compartilhando uma conexão de dados móveis. O tethering é o ato de conectar um dispositivo, como um laptop, a uma conexão de dados móveis de um smartphone via Wi-Fi, USB ou Bluetooth para acessar a Internet. Ambos os conceitos são relevantes para engenheiros de rede ao projetar soluções de conectividade móvel ou resolver cenários de acesso remoto.
