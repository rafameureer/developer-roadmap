# ipconfig / ifconfig

O ipconfig (no Windows) e o ifconfig (no Linux e macOS) são ferramentas de linha de comando usadas para exibir e gerenciar a configuração da rede dos adaptadores de rede de um dispositivo. Eles mostram informações como o endereço IP atribuído, a máscara de sub-rede, a porta de saída padrão e o endereço MAC de cada adaptador de rede. São uma das primeiras ferramentas usadas ao diagnosticar problemas de conectividade no nível do dispositivo, confirmando se o dispositivo tem uma configuração de rede válida.
