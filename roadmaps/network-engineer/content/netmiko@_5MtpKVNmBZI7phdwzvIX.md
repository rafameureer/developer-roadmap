# Netmiko

Netmiko é uma biblioteca de código aberto em Python que simplifica as conexões SSH a dispositivos de rede de várias marcas, incluindo Cisco, Juniper, Aruba e muitas outras. Ele lida com a complexidade de estabelecer sessões SSH, enviar comandos e capturar saída de uma maneira consistente, independentemente do tipo de dispositivo subjacente, eliminando a necessidade de escrever código de conexão personalizado para cada fabricante. Netmiko é uma das bibliotecas Python mais amplamente usadas na automação de redes e é frequentemente o primeiro ferramenta que engenheiros de rede aprendem ao começar a automatizar interações baseadas em CLI com dispositivos.
