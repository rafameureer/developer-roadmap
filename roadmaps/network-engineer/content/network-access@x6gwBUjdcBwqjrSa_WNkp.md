# Acesso à Rede

A camada de Acesso à Rede é a camada mais baixa do modelo TCP/IP, combinando as funções da camada Física e de Enlace de Dados da OSI. Ela lida com como os dados são fisicamente transmitidos pela rede, incluindo enquadramento, endereçamento MAC e detecção de erros no nível de hardware. Os protocolos Ethernet e Wi-Fi operam nesta camada.
