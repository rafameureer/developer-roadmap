# Rede

A Camada de Rede é a terceira camada do modelo OSI, responsável por endereçamento lógico e roteamento de pacotes de dados entre dispositivos em diferentes redes. Ela usa endereços IP para determinar o melhor caminho para que os dados viajem da fonte ao destino. Os roteadores operam nesta camada, tomando decisões de encaminhamento com base em tabelas de roteamento e protocolos.
