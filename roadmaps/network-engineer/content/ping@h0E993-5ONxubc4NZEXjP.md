# ping

O ping é um dos ferramentas de diagnóstico de rede mais básicas e amplamente utilizadas, enviando pacotes ICMP Echo Request para um host de destino e medindo se uma resposta é recebida e quanto tempo leva. É geralmente a primeira ferramenta usada ao resolver problemas de conectividade, rapidamente confirmando se um dispositivo está acessível na rede. Os resultados mostram o tempo de viagem em redor (RTT) e a perda de pacotes, fornecendo uma indicação imediata de existência de um caminho entre dois dispositivos e sua estabilidade.
