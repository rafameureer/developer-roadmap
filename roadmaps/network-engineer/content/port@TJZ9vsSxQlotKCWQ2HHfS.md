# Porta

Uma porta é um identificador numérico usado para direcionar o tráfego de rede para um aplicativo ou serviço específico em execução em um dispositivo. Enquanto um endereço IP identifica o dispositivo, o número da porta identifica qual programa no dispositivo deve lidar com os dados recebidos. Por exemplo, o tráfego web geralmente usa a porta 80 para HTTP e a porta 443 para HTTPS.
