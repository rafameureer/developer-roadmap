# Prometheus

Prometheus é uma ferramenta de monitoramento e alerta de código aberto originalmente construída na SoundCloud e agora amplamente adotada no setor. Ele coleta métricas raspando dados dos alvos configurados em intervalos regulares, armazena-os em um banco de dados de séries temporais e fornece uma linguagem de consulta poderosa chamada PromQL para analisar e visualizar os dados. Embora não seja específico da rede, o Prometheus é comumente usado na infraestrutura moderna para monitorar dispositivos de rede, serviços e aplicativos, frequentemente em conjunto com o Grafana para visualização e alertas.
