# RESTCONF

RESTCONF é um protocolo de gerenciamento de rede que expõe os mesmos dados modelados em YANG como NETCONF, mas através de uma interface RESTful HTTP/HTTPS, tornando-o mais acessível para desenvolvedores e ferramentas já familiarizadas com APIs da web. Em vez de XML por SSH, RESTCONF usa métodos HTTP como GET, POST, PUT, PATCH e DELETE, e suporta tanto JSON quanto XML como formatos de dados. É mais fácil de usar e integrar que NETCONF para muitos casos de automação, embora fique sem algumas das funcionalidades transacionais avançadas do NETCONF, tornando os dois protocolos complementares em vez de substituições diretas um pelo outro.
