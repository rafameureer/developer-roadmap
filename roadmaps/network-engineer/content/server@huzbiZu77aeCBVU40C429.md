# Servidor

Um servidor é um computador ou sistema de software que escuta solicitações de clientes e responde fornecendo recursos, dados ou serviços. Servidores podem hospedar sites, armazenar arquivos, gerenciar e-mails ou executar aplicativos que muitos usuários acessam simultaneamente. Eles são geralmente projetados para estar sempre disponíveis, lidando com várias conexões de cliente ao mesmo tempo.
