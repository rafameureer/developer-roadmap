# SNMP

SNMP, ou Protocolo Simples de Gerenciamento de Rede, é um protocolo amplamente utilizado para monitorar e gerenciar dispositivos de rede como roteadores, switches, servidores e impressoras. Ele permite que um sistema de gestão central consulte dispositivos por dados de desempenho — como uso da CPU, estatísticas de interface e contagens de erros — e também pode receber alertas não solicitados chamados traphs quando certas condições ocorrem. SNMP é uma ferramenta fundamental em centros de operações de rede (NOCs) para manter a visibilidade em largas infraestruturas.
