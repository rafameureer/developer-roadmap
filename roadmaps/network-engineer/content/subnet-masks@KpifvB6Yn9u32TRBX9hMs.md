# Máscaras de Sub-rede

Uma máscara de sub-rede é um número de 32 bits usado junto com um endereço IP para determinar qual parte do endereço identifica a rede e qual parte identifica o host individual. Funciona aplicando uma operação AND bit-a-bit com o endereço IP para extrair o endereço da rede. Por exemplo, uma máscara de sub-rede de 255.255.255.0 significa que os três primeiros octetos representam a rede e o último octeto identifica hosts nessa rede.
