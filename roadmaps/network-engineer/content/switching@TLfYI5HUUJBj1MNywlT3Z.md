# Switching

Switching é o processo de encaminhar quadros de dados dentro de uma rede local com base em endereços MAC. Um switch de rede recebe quadros de entrada e os envia apenas para a porta conectada ao dispositivo de destino pretendido, diferentemente de um hub, que difunde para todas as portas. O switching forma a base da designação moderna de LANs e pode ser melhorado com funcionalidades como VLANs, STP e agregação de links.
