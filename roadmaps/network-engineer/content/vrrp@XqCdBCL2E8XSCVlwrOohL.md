# VRRP

VRRP, ou Virtual Router Redundancy Protocol, é um protocolo de padrão aberto que fornece a mesma função de redundância de gateway que o HSRP, mas funciona em equipamentos de qualquer fabricante. Um grupo de roteadores compartilha uma endereço IP virtual, com um eleito como mestre e os outros como reservas prontos para assumir o controle se o mestre ficar indisponível. Por ser neutral em relação aos fabricantes, VRRP é a escolha preferida em ambientes de rede multi-fabricante.
