# Aplicativo Web

Um Firewall de Aplicativos da Web (WAF) é uma ferramenta de segurança especializada projetada para filtrar, monitorar e bloquear o tráfego HTTP/HTTPS entre aplicativos web. Ele protege contra ataques comuns baseados na web como injeção SQL, cross-site scripting (XSS) e cross-site request forgery (CSRF) ao inspecionar o tráfego de camada de aplicativo em relação a um conjunto de regras ou políticas. WAFs podem ser implantados como hardware, software ou serviços na nuvem e são uma camada essencial de defesa para qualquer aplicativo web acessível publicamente.
