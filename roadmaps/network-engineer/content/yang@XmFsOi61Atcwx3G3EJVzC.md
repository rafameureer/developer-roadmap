# YANG

O YANG é um idioma de modelagem de dados usado para definir a estrutura, sintaxe e semântica dos dados que os dispositivos de rede trocam através de protocolos de gerenciamento como NETCONF e RESTCONF. Ele descreve exatamente quais configurações e dados operacionais um dispositivo suporta de uma maneira que tanto humanos quanto máquinas possam entender. Os modelos YANG são a base da automação moderna de redes: antes de um script ou ferramenta ser capaz de configurar um dispositivo via NETCONF ou RESTCONF, ele precisa saber o modelo YANG para aquele dispositivo para entender como estruturar suas solicitações corretamente.
