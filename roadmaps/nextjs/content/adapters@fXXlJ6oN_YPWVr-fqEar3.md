# Adaptador

O Next.js pode ser adaptado para funcionar em diferentes plataformas, suportando suas capacidades de infraestrutura, incluindo AWS Amplify Hosting, Cloudflare, Deno Deploy, Netlify e Vercel.

Acesse os seguintes recursos para saber mais:

- [@official@Implantação com Adaptadores](https://nextjs.org/docs/app/getting-started/deploying#adapters)
