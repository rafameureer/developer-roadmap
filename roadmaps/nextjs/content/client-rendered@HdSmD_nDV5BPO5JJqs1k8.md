# Renderização do Lado do Cliente em Next.js

A Renderização do Lado do Cliente (CSR) significa que o navegador recebe uma página HTML mínima do servidor. O navegador, em seguida, baixa o código JavaScript, responsável por renderizar toda a interface do usuário. O código JavaScript busca os dados e gera dinamicamente o conteúdo HTML no navegador. Este método desloca a carga de trabalho de renderização do servidor para o navegador do cliente.
