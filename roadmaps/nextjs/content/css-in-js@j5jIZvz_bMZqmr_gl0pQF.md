# CSS in JS

É possível usar qualquer solução existente de CSS-in-JS em suas aplicativos e páginas Next.js existentes. O CSS-in-JS é uma técnica onde os estilos CSS são escritos em arquivos JavaScript em vez de arquivos CSS separados. Esse abordagem permite que você use as capacidades dinâmicas do JavaScript para gerenciar e escopar seus estilos, frequentemente usando bibliotecas que geram CSS em tempo de execução ou build time. Oferece benefícios como estilização por componente, temas dinâmicos e uma gestão mais fácil das dependências de CSS.
