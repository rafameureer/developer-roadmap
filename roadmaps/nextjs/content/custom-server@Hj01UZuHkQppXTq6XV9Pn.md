# Como configurar um servidor personalizado no Next.js

O Next.js inclui seu próprio servidor com `next start` por padrão. Se você tiver um backend existente, ainda pode usá-lo com o Next.js (isso não é um servidor personalizado). Um servidor personalizado do Next.js permite que você inicie programaticamente um servidor para padrões personalizados. A maioria das vezes, você não precisará deste abordagem. No entanto, ele está disponível se você precisar de "eject".

Acesse os seguintes recursos para saber mais:

- [@official@Como configurar um servidor personalizado no Next.js](https://nextjs.org/docs/app/guides/custom-server)
