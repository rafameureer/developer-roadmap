# Fetching Location

A obtenção de dados no Next.js permite que você renderize seu conteúdo de diferentes maneiras, dependendo do caso de uso da sua aplicação. Por padrão, layouts e páginas são Componentes Servidor, o que lhe permite buscar dados e renderizar partes da interface do usuário no servidor, opcionalmente cachear o resultado e streamizá-lo para o cliente. Quando você precisa de interatividade ou APIs do navegador, você pode usar Componentes Cliente para adicionar funcionalidades.

Isso inclui pré-renderização com Renderização do Lado do Servidor (SSR) ou Geração Estática Estática, e atualizar ou criar conteúdo em tempo real com a Regeneração Incremental de Conteúdo Estático.
