# Estilo Global

O Next.js oferece várias maneiras de estilizar sua aplicação usando CSS. Um exemplo é o Estilo Global, que se refere a estilos CSS que são aplicados em toda a sua aplicação. Isso significa que os estilos definidos em um arquivo de estilo global afetarão todos os elementos em cada página do seu site, a menos que especificamente sobrescritos por regras de CSS mais específicas. É uma maneira de estabelecer um visual consistente ao longo do seu projeto.

Acesse os seguintes recursos para saber mais:

- [@official@Estilo Global](https://nextjs.org/docs/app/getting-started/css#global-css)
