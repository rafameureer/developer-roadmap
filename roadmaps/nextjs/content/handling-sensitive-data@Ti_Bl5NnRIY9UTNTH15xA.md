# Lidando com Dados Sensíveis

Dados sensíveis, como chaves de API ou credenciais de usuário, requerem gerenciamento cuidadoso para evitar exposição. No Next.js, você deve evitar incorporar diretamente tais dados no código do cliente ou commitá-los em seu repositório. Em vez disso, utilize variáveis de ambiente e lógica do lado do servidor para acessar e utilizar informações sensíveis de forma segura, garantindo que permaneçam protegidas da acesso não autorizado.

Acesse os seguintes recursos para saber mais:

- [@official@Como pensar em segurança de dados no Next.js](https://nextjs.org/docs/app/guides/data-security#data-fetching-approaches)
- [@article@Como Pensar na Segurança no Next.js](https://nextjs.org/blog/security-nextjs-server-components-actions)
