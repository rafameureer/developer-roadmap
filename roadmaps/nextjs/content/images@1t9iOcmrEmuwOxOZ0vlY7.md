# Imagens

Imagens ocupam uma grande porcentagem do peso típico de uma página de site e podem ter um impacto significativo na performance LCP (First Contentful Paint) da sua aplicação. O componente Image do Next.js estende o elemento HTML <img> com recursos para otimização automática de imagens, incluindo:

* Otimização de Tamanho: Serve automaticamente imagens corretamente dimensionadas para cada dispositivo, usando formatos de imagem modernos como WebP e AVIF.
* Estabilidade Visual: Previne a mudança de layout automaticamente quando as imagens estão sendo carregadas.
* Carregamento Rápido da Página: As imagens são carregadas apenas quando entram na viewport usando o carregamento lazy nativo do navegador, com placeholders de borracha opcional.
* Flexibilidade de Ativos: Redimensionamento de imagem sob demanda, mesmo para imagens armazenadas em servidores remotos
