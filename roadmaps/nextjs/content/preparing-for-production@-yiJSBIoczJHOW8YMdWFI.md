# Preparação para a Produção

Antes de levar o aplicativo Next.js à produção, existem algumas otimizações e padrões que você deve considerar implementar para o melhor desempenho, experiência do usuário e segurança. O Next.js fornece uma lista de práticas recomendadas ao construir seu aplicativo e antes de ir para a produção. Além disso, é importante estar ciente das otimizações automáticas do Next.js.

Acesse os seguintes recursos para saber mais:

- [@oficial@Como otimizar o seu aplicativo Next.js para a produção](https://nextjs.org/docs/app/guides/production-checklist)
