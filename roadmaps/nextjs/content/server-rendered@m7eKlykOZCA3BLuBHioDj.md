# Renderização no Lado do Servidor (SSR)

A Renderização no Lado do Servidor (SSR) é uma técnica onde a inicialização de um aplicativo web em HTML é gerada pelo servidor em resposta a uma solicitação do usuário. Este HTML pré-renderizado é então enviado ao navegador do cliente, permitindo que o usuário veja o conteúdo imediatamente, mesmo antes da execução completa do código JavaScript. Este abordagem contrasta com a Renderização no Lado do Cliente, onde o navegador baixa uma página HTML mínima e depois usa JavaScript para renderizar o conteúdo.
