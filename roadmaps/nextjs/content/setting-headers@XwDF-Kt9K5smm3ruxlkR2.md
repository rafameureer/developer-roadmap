# Definindo Cabeçalhos no Middleware do Next.js

O middleware no Next.js permite que você execute código antes de uma solicitação ser concluída. Definir cabeçalhos dentro do middleware habilita você a modificar os cabeçalhos de resposta HTTP, controlando aspectos como caching, políticas de segurança ou informações personalizadas passadas ao cliente. Isso fornece uma maneira flexível de gerenciar o comportamento da resposta com base em solicitações recebidas.

Acesse os seguintes recursos para saber mais:

- [@official@Definindo Cabeçalhos para o App Router](https://nextjs.org/docs/app/api-reference/file-conventions/middleware#setting-headers)
- [@official@Definindo Cabeçalhos para o Pages Router](https://nextjs.org/docs/pages/api-reference/file-conventions/middleware#setting-headers)
