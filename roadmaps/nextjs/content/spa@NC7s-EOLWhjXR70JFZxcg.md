# Renderização de Aplicação de Página Única (SPA)

Uma Aplicação de Página Única (SPA) é uma aplicação web que carrega uma única página HTML e atualiza dinamicamente essa página conforme o usuário interage com a aplicação. Isso é feito usando JavaScript para manipular diretamente o DOM (Modelo de Objeto do Documento), em vez de solicitar novas páginas HTML do servidor para cada interação. Esse método fornece uma experiência do usuário mais fluida e responsiva, pois o navegador não precisa recarregar toda a página para cada mudança.
