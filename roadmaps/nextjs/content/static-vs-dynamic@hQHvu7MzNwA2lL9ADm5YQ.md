# Static vs Dynamic API Endpoints

Os endpoints de API no Next.js permitem que você crie funções do lado do servidor para lidar com solicitações. Esses endpoints podem ser estáticos ou dinâmicos, dependendo da definição de suas rotas e como processam os dados. Os endpoints de API estáticos têm rotas pré-definidas e geralmente retornam a mesma resposta para todas as solicitações, enquanto os endpoints de API dinâmicos usam parâmetros em suas rotas para lidar com diferentes solicitações e gerar respostas com base nesses parâmetros.
