# Tailwind CSS

O Next.js suporta o Tailwind CSS para estilizar suas aplicações. O Tailwind CSS é um framework de CSS utilitário que fornece um conjunto de classes CSS pré-definidas que você pode usar para estilizar diretamente seus elementos HTML em seu código de marcação. Em vez de escrever regras CSS personalizadas, você compõe estilos aplicando essas classes utilitárias, permitindo o desenvolvimento rápido da interface do usuário e uma design consistente. Este abordagem promove um fluxo de trabalho mais streamlinado ao reduzir a necessidade de alternar entre arquivos HTML e CSS.

Acesse os seguintes recursos para saber mais:

- [@official@Tailwind CSS](https://tailwindcss.com/)
- [@official@Tailwind CSS no Next.js](https://nextjs.org/docs/app/getting-started/css#tailwind-css)
