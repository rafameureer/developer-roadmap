# Por que usar Next.js?

Next.js é um framework do React que oferece funcionalidades e otimizações além das que o próprio React fornece. Quando escolhendo um framework baseado em React, Next.js destaca-se porque simplifica o desenvolvimento com recursos como roteamento embutido, renderização no lado do servidor e geração de sites estáticos. Essas capacidades melhoram a performance, SEO e a experiência geral do desenvolvedor em comparação com a criação de uma aplicação React do zero ou o uso de outros frameworks que requerem mais configuração manual.
