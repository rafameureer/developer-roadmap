# App Router

O App Router no Next.js é um novo sistema de roteamento baseado em React Server Components, oferecendo flexibilidade e desempenho aprimorados em comparação com o tradicional Pages Router. Antes do Next.js 13, o Pages Router era a maneira principal de criar rotas no Next.js. Ele ainda é suportado nas versões mais novas do Next.js, mas o Next.js recomenda migrar para o novo App Router para aproveitar as últimas funcionalidades do React.

Acesse os seguintes recursos para saber mais:

- [@artigo@Next.js: App Router vs Pages Router](https://dev.to/dcs-ink/nextjs-app-router-vs-pages-router-3p57)
